# 如何合法获取教材

本课程以 Richard Szeliski 的《Computer Vision: Algorithms and Applications（第 2 版）》为底本。

## 官方渠道

作者主页提供免费 PDF 与在线版：

- <https://szeliski.org/Book>

请从上述官方渠道自行下载。不同印次的页码可能略有偏移，课程中的页码以第 2 版印刷页码为准。

## 为什么仓库里没有 PDF

教材版权归作者与出版方所有。本仓库只放课程原创内容（讲义、幻灯片、代码、重绘示意图），不转发教材 PDF，也不使用教材原图。

## 没有书能学吗

可以。每集幻灯片和口播稿是自足的；页码只是方便对照原书。遇到公式推导，优先看幻灯片里的重绘示意图和 `code/` 里的数值实验。
