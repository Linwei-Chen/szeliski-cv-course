# E078 口播稿 · 全景大战役 Ⅱ：柱面/球面投影与投影函数选型

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集把多张图的姿态一起对齐了，可对齐好的图还摊在各自的小画框里。这一集解决下一步：把它们投到同一个曲面上，再展开成一张大图。柱面像一圈纸，球面像一个球。选哪个，决定了全景能拍多大，边缘会不会拉变形。对齐解决谁对谁，投影解决往哪放。两件事都做对，全景才站得住。据我观察，手机全景默认多半是柱面；要拍天和地，就得上球面。先看原书为什么说先投影，再对齐。这一步决定后面的对齐怎么做。

书上第 523 页给了一个替代方案：不直接估单应，而是先把图像投到柱面坐标，再用纯平移模型对齐。这相当于把转动相机变成平移图片。转动本来难对齐，平移却很好办。但原书紧接着提醒：这个办法只适用于两种拍摄方式，相机保持水平，或者倾角已知。因为柱面坐标假定相机的竖轴始终竖直。一旦相机歪了，竖线在柱面上也会弯。先记住这个前提，后面选型才不会用错。这是柱面法的边界条件。

为了把公式写清楚，书上第 523 页先假设相机在规范位置：旋转矩阵是单位阵，光轴对准 z 轴，y 轴竖直向上。这样，一个像素 (x, y) 对应的三维射线就是 (x, y, f)，f 是焦距。这一步只是把相机摆正，方便算角度。真实相机歪了，可以先用已知的倾角把它转正。射线从光心出发，穿过像素，指向场景。投影要做的，就是把这根射线的方向，换成一个角度和一个高度。射线方向才是投影要处理的量。

把流程摊开：像素射线先投到曲面。柱面记角度 θ 和高度 h，球面记 θ 和 φ。再把曲面展开成平面图，最后做纯平移对齐、接缝和曝光。投影不是把图贴到曲面上，而是把每个像素的射线方向，重新记成曲面上的坐标。展开之后，相邻图之间只剩水平平移，对齐就退化成一行一行的配准。本集只讲投影这一步，接缝和曝光下一集讲。投影选错，后面接得再准，边缘也会拉花。顺序错了，后面的融合也会跟着错。

书上第 524 页把柱面写成单位半径的曲面，点用角度 θ 和高度 h 表示，并给出对应关系：三维方向正比于 (sinθ, h, cosθ)，也正比于像素射线 (x, y, f)。由此得到两个映射：横坐标是 s 乘 θ，θ 等于反正切 x 除以 f；纵坐标是 s 乘 h，h 等于 y 除以根号下 x 平方加 f 平方。θ 管左右转了多少度，h 管上下偏了多少。两者都不再直接是像素坐标。s 是柱面半径，稍后讲怎么选。两个角度都不再是线性缩放。

书上第 524 页说，s 是任意缩放因子，有时叫柱面半径。把它设成等于焦距 f，可以让图像中心附近的畸变或缩放最小。s 就像把柱面卷多大。卷得越大，展开后的图越宽，但中心附近越接近原图。原书还给了逆变换：已知柱面坐标，可以反算回像素坐标；横坐标用 f 乘正切，纵坐标再乘正割。正变换和逆变换成对出现，才能把图投过去，也能把结果查回来。s 不是越小越好，要看输出分辨率。逆变换用来查表，不用逐像素重算。

如果全景不只一圈，而是要把头顶和脚底都包进来，柱面就不够了。书上第 524 页说，图像也可以投到球面，适合最终全景包含完整球面或半球视野，而不只是一条柱面条带。球面用两个角度：θ 管经度，φ 管纬度。三维方向是 (sinθcosφ, sinφ, cosθcosφ)。柱面只卷一圈，上下是开口的；球面把上下也封起来，所以能装下天和地。代价是公式多一个角度，展开后越靠近极点，横向越挤。极点附近是球面展开最挤的地方。

看这两张曲线。左边横轴是像素 x，蓝线是柱面展开后的横坐标，绿虚线是平面横坐标。柱面按角度走，边缘被压紧；平面按像素走，边缘一路拉出去。右边纵轴是高度或角度：红线是柱面高度 h，等于 φ 的正切；蓝线是球面角度 φ。柱面的 h 会越拉越长，球面的 φ 却始终有界，最多到九十度。所以柱面适合水平一圈，球面适合全球。这不是审美，是公式决定的。视野越宽，这个差别越明显。读图时先看横轴，再看纵轴。

书上第 525 页说，柱面拼接最常用的场景，是相机保持水平、只绕竖直轴转动。在这种条件下，不同转角拍到的图，在柱面上只差一个纯水平平移。小量的竖直倾斜，有时可以用竖直平移补偿。相机只转头、不抬头，画面在柱面上就像一条长卷。第二张只是往旁边挪了一段。这就是柱面好用的原因：把二维配准问题，降成了一维平移。但前提仍然是水平。歪了，就不是纯平移。

专业全景摄影师常用全景云台。它能控制俯仰，还能在特定角度卡住；电动转头也常用于大范围拍摄。书上第 526 页说，这些设备不仅保证覆盖均匀、重叠合适，还让图像可以用柱面或球面坐标加纯平移来拼。用的时候，要先用已知的俯仰和转动角度，把像素坐标转正，再投到柱面或球面。角度大致已知，对齐就不用大海捞针，搜索范围能缩小很多。设备的价值不只是稳，更是把未知变成已知。

书上第 526 页还提了最后一种映射：极坐标映射。它的北极不在竖直方向，而在光轴上。公式里用半径 r 和角度 θ、φ 表示。当 x、y 很小时，映射近似成 x 方向乘 s 除以 z。这正好是鱼眼镜头的模型：中心附近接近透视，越往边缘越卷。所以极坐标既是一种全景显示面，也是理解鱼眼畸变的好工具。它不属于柱面、球面二选一，而是另一类投影函数。选型时先问：你要的是长卷、全球，还是鱼眼观感？

我们的实验做了十一项断言，全部通过。重点看这几个数：柱面和球面的正反变换，往返误差都在十的负十三次方量级。纯偏航之后，柱面横坐标整体平移，偏差在机器精度；高度几乎不变。柱面高度 h 始终大于球面角度 φ。把 s 设成 f，中心缩放正好是一。半视角六十度时，平面从中心到边缘的整体距离比约为一点六五，柱面保持一。这个比值不是边缘一点的局部放大率。这些数说明公式自洽，也说明柱面压边缘、平面拉边缘，不是感觉，是算出来的。实验只验证几何，不验证接缝和曝光。

把选型收成一张表：只想拍水平一圈，用柱面；要包天包地，用球面；视野窄、又想保留直线，用平面。柱面是长卷，球面是地球仪，平面是普通照片。别拿长卷去装天，也别拿地球仪去拍一张证件照。还要看拍摄方式：相机水平或倾角已知，柱面、球面加纯平移最省事。如果相机乱晃、场景又有近处物体，纯平移假设就不成立，要回到单应或全局对齐。选型不是选最复杂，是选假设最匹配。

工程上按五步走。第一，确认相机水平，或者记录倾角。第二，留足重叠，别让相邻图擦边。第三，估焦距；f 不准，柱面展开就会整体伸缩。第四，选柱面还是球面，再定 s。第五，投影完再做接缝和曝光。顺序别反：先正相机，再投影，再对齐，最后才修缝。投影阶段就把几何做对，后面融合才不用反复补锅。f 和 s 是这一步最容易被忽略的两个数。

再说边界。柱面和球面加纯平移，靠的是相机只转、不平移。一旦相机走动，近处和远处的相对位置会变，纯平移就解释不了，画面会出现视差重影。书上第 523 页的限制说得清楚：要么水平，要么倾角已知。不满足，就别硬套。投影函数只负责把方向记到曲面上，不负责解决视差。遇到视差，要回到单应、分层或三维重建。先认清假设，再选工具。

这一集把投影讲完了。柱面用 θ 和 h，球面用 θ 和 φ。水平转动在柱面上变成纯平移。s 设成 f，能让中心畸变最小。极坐标还能解释鱼眼。实验里，往返误差在十的负十三次方，纯偏航偏差在机器精度，平面边缘拉伸约一点六五倍。下一集处理拼接的最后一道关：相邻图亮度不一样，接缝看得见，怎么用曝光补偿和多频段混合藏起来。投影把图放对位置，融合才让缝消失。
