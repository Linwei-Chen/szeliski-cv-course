# E087 口播稿 · 深度学习接管光流：RAFT 与端到端的胜利

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集 KLT 只在几十个特征点上跟。这一集要每个像素都有一个位移，也就是稠密光流。手工方法要设计特征、窗口、平滑项；深度学习换了个办法：给网络看大量带真值的合成视频，让它自己学。KLT 是做小窗口搜索，深度光流是把整张图的配对关系摆出来，再让网络反复修。这一集从 FlowNet 一路看到 RAFT，重点在看清每一代在解决什么问题，网络名不用背。

书上第 584 页说，过去十年，深度神经网络已经成为所有高性能光流算法的必要组件。早期代表是 DeepFlow：它用非学习的卷积和池化算多尺度匹配代价，再交给经典的能量最小化框架优化。DeepFlow 是手工特征加深度结构，还不是端到端学习；它证明了多层聚合对匹配有用，但参数还是人定的。

书上第 584 页说，第一个用完整端到端学习的编码器-解码器网络是 FlowNetS，训练数据是作者合成的 FlyingChairs。同一篇还提出 FlowNetC，用相关网络，也就是局部代价体。FlowNetS 是两帧进、光流出，中间不用人写规则；FlowNetC 先把两幅特征做相关，告诉网络哪里像哪里。这两条路，直接回归和先算相关，后来一直被沿用。

书上第 584 页说，FlowNet 2.0 先用初始光流把图像 warp 一下，再用级联的编码器-解码器网络细化。第一遍先猜个大概，把第二帧按猜测挪过去，两张图就更像；第二遍只学还差多少。这就是由粗到细在深度学习里的版本：把问题变简单再算，不靠换更大的网络。

书上第 584 页说，另一条路用图像金字塔和光流金字塔，配合由粗到细的 warp 和细化，不把全分辨率网络串起来；SPyNet 最早系统探索了这条路。先把图缩小，在小图上估大运动；再逐层放大，每层只修一点。这和上一集 KLT 的金字塔是同一个直觉，只是把搜索换成了网络预测。

书上第 584 到 585 页讲 PWC-Net：先给每帧算特征金字塔，用上一层插值来的光流 warp 第二组特征，再把两组特征按正负四像素的位移做点积，得到代价体。当前层的光流由一个多层 CNN 细化，输入是代价体、图像特征和上一层光流。最后还有一个上下文网络，用膨胀卷积扩大感受野。PWC 把特征、warp、代价体、上下文拆成四个清楚的积木，和经典由粗到细几乎一一对应。

书上第 585 页说，IRR 在每一层复用同一套结构和卷积权重，不再级联一堆不同的网络，所以可以画成卷起来的循环网络；参数更少，精度反而更好。作者还把它加倍，同时算前向、后向光流和遮挡。同一个修图师傅反复修同一张图，每轮都基于上一轮的结果，而不是每层换一个师傅。权重共享是深度学习里很划算的归纳偏置。

书上第 585 页说，Jonschkowski 等人拿 PWC-Net 当基础，系统研究无监督训练的各组件。没有真值光流，只用真实视频；他们比较光度损失、遮挡估计、自监督和平滑约束，还分析预训练、分辨率、数据增强和批大小，并提出四点改进：代价体归一化、遮挡梯度停止、原生分辨率平滑、自监督图像缩放。没有真值，就用按光流挪过去应该长得像当老师；这让训练数据可以无限多，但老师本身也会犯错。

书上第 586 页说，另一个趋势是给光流建模不确定性，尤其是同质区域和遮挡区域带来的不确定。HD3 在多个分辨率上建模对应分布，LiteFlowNet3 用代价体调制和光流场变形模块，以很小代价显著提精度。光流不是每个像素都同样可信；平坦区、遮挡边、快速运动处，网络应该学会说这里我不确定。会报不确定，比盲目给一个数更有用。

书上第 586 页说，Teed 和 Deng 的 RAFT 建立在循环网络的想法上，但不再 warp 特征图，改成预先算一个完整的、宽乘高再平方的多分辨率相关体；每次迭代根据当前光流去查这个相关体。以前是每猜一次就把图挪一次再算，RAFT 是把所有配对一次算好，猜到哪里就查哪里。全配对的好处是保留了所有候选，不会因为粗层看不到就永久丢掉；代价是内存大。

书上第 586 页说，如果只给每个参考特征存最近的 k 个匹配，稀疏相关体还能进一步加速。在 Robust Vision Challenge 这类聚合基准上，RAFT、IRR、PWC 的变体都表现很好。全相关体把所有候选都查一遍；稀疏版只记最可能的前几个，快很多，但可能漏掉正确答案。选型不能只看榜单，还要看你的数据、分辨率和延迟预算。

书上第 586 页说，除了看榜单，更靠谱的是按实际用途评估，并尽可能在问题专用数据上微调。Xue 等人把 SPyNet 在合成退化的 Vimeo-90K 上微调，得到任务导向光流，在插帧、视频去噪、视频超分三个任务上超过更高精度的网络，甚至超过真值光流。光流适合下游任务，比单纯精度更重要；下游要的是插帧不抖，不是排行榜多一分。

本集实验：六十四见方的图，全相关体有一千六百七十七万多个元素，单精度约六十七点一兆字节；只存每像素前五个匹配的稀疏版不到零点零八二兆，省八百一十九倍。相关体峰值在真值附近，亚像素误差零点零零九像素。重复纹理会出两个几乎一样高的峰，峰值比一点零一零，正好提醒你这里不可信；唯一纹理峰值比二点五二，可信得多。相关体把像不像变成一张可查的表；稀疏化省内存，但省掉的可能正是正确答案。这个账只算相关值的存储，实际还要存匹配位置索引，内存会高一些，但仍然省几百倍。

本集实验：从零位移出发，迭代误差六点二八像素；第一轮降到二点四一，第二轮降到零点零零九，之后保持。亮度乘一点六再加零点一，归一化相关的峰仍然稳，误差零点零零七像素。RAFT 的迭代不每轮重新算全图，它拿当前光流去相关体里查，再修一点；相关体不变，变的是查询位置。这就是全配对加循环细化的分工：一次建表，多次查表。

书上第 585 页脚注提醒，和所有由粗到细的 warp 方法一样，这些算法对快速运动的细结构会吃力，因为细结构在粗层可能根本看不见。大运动加细纹理，是光流的老大难；全相关体缓解了粗层丢结构，但没有消灭遮挡、无纹理和域偏移。选型时先问：你的场景有没有真值，能不能微调，延迟和内存预算多少；再决定用 PWC 这类轻量级网络，还是 RAFT 这类全相关体。

这一集收成三件事。深度光流把特征、相关、warp、细化拆成可学习的积木；相关体是配对关系的查找表，RAFT 用全配对加循环细化把表用到极致；选型要看任务和数据，不只看榜单。下一集走到应用：视频防抖、慢动作和插帧，都是拿光流场去补时间或稳画面。光流准不准，最后会变成画面抖不抖、边缘糊不糊。下一集见。
