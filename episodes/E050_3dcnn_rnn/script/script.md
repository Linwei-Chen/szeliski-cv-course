# E050 口播稿 · 从 2D 到 3D：视频卷积与循环网络

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集看网络怎么自学。这一集进入书上 5.5 节，更复杂的模型。这一节分两步。第一步，把卷积从二维平面搬到三维时空。第二步，让网络沿着时间传信息。书上第 317 页说，深度网络早先都在二维图像上干活，如今医疗影像、视频序列这些三维数据也用上了，还能把一串网络按时序首尾相接。

三维数据指哪些？书上第 317 页点了三个去处：越来越多的视频要理解，从深度数据建出来的占用地图，还有三维的医学影像。这三个去处背后的章节，这门课都还没走到。先记住视频和立体数据两个词，它们就是这一集的主角。

先做个辨析。卷积网络早就见过三维了。前面讲过的那些网络，每层感受野本来就是长宽加通道的三维盒子。书上第 317 页也提醒，乍看之下，前面讲过的网络好像已经在做三维卷积。可那个第三维是通道，是并列的特征，不是空间。三维卷积本身要沿时间再开一维，让同一组核在时间上也共享权重。书上第 318 页接着说，与其把滑窗、分组卷积硬塞进二维网络，不如整个三维体一起算。

怎么把一段视频喂给网络？书上第 318 页借一张经典图，列了四种时序融合的路数。屏幕上这张程序生成的框图照着画了三种：单帧，每帧单独分类；晚融合，头尾两帧各提特征，最后合起来判；早融合，把相邻几帧叠成多通道，塞进普通二维卷积。书上还有第四种，三维卷积，原图里没画，这里替它补上：直接在时间和空间上一起滑核。早融合叠通道看着省事，可书上点破了要害：跨时间的互动，没有卷积那种权重共享和时间平移不变性。

三维卷积长什么样？书上第 318 页给了最简版本：三乘三乘三的核，长宽各三格，时间也三格。特兰等人的 C3D 网络就靠这么朴素的核加深，效果更好，被称作三维卷积世界的 VGG。屏幕上这张程序生成的示意图，左边是熟悉的二维感受野，长宽加通道；右边是时空窗，时间维也进来了。实验档算过这笔账：核从二维换三维，参数只乘时间格数这一倍，因为同一组核在时间上共享。要是每帧各配一套核，参数就得乘帧数。书上第 318 页还有齐瑟曼那篇双流对比：像素一路、光流一路，并行通路一起提特征。那是视频理解章节的内容，这里先眼熟名字。

三维卷积不只吃视频。书上第 318 页转到体积数据：从深度数据建模形状、做识别，两个早期代表是 3D ShapeNets 和 VoxNet，把物体切成小方块体素再卷积。书上第 319 页还点了医学影像分割：三维卷积网络在深脑影像上分割病灶，这类工作在医学影像章节细讲。视频是时间维的三维体，医学影像是空间本身的三维体，同一套卷积两头都能用。

三维卷积有个现实代价：又吃计算又吃内存。书上第 319 页列了一串提速招法。最出名的是双流慢快网：一条慢路低帧率看整体，一条快路高帧率看细节，但通道砍半，两路合起来用。还有把时空卷积拆成先空间后时间的通道分离卷积，用搜索自动找架构，甚至借多网格技术加速训练。这一串都是工程手段。名字记不住没关系，记住慢路看大势、快路看动作。

这一小节换了个舞台：点云和网格。除了规整的三维体，网络还想从一张平面图直接推出三维模型。书上第 320 页摆了三条路：预测每个像素的深度；用体积密度重建完整三维；还有点云、网格这些做法。紧接着书上给了一句提醒：新近实验怀疑，一些三维推理网络可能只是认出了物体类别，再做一点小修小补的拟合。这句质疑值得记住。看到一个端到端结果，先问它到底学到了三维，还是背下了形状。

点云这条线，书上说研究得非常热闹，一篇综述一口气回顾了两百多篇论文。更成型的玩法是网格：从深度图或普通照片里，先检测三维物体，再把它变成三角面片拼成的网格。书上第 320 页配的 Mesh R-CNN 示意图就是这么一套流水线：检测骨干之外挂两条三维推理支路，一条出粗坯体素，一条细磨成网格。想动手的同学，原书脚注指了 PyTorch3D 工具库。这半节点到为止，几何重建是后面章节的内容。

第一步走完，第二步：让网络沿时间传信息。图像和三维体之外，还有一整类数据是序列：连续的视频帧、一段音频、一句话。书上第 321 页说，把上一时刻提取的特征喂给下一时刻的处理，这路架构叫循环神经网络，简称 RNN。屏幕上这张程序生成的展开图：同一层被摊开成时间上的一长串，上一步的输出是下一步的输入。书上配的教科书示意图也是这么画的：一边卷起来看，一边摊开看，两幅图是同一个网络。

循环网络有个巧妙的设定：时间上每一步，用的都是同一组权重。书上第 321 页说，这有点像三维卷积核在时间上的共享。第一步刚讲过这笔账：同一组核走遍所有帧，参数不用随帧数膨胀。实验档也实算过：四步也好，八步也好，一个四单元的小循环层，可训练参数恒定三十六个。训练怎么办？把展开图当成深网络，对每个时间步求导再求和，这就是沿时间反传。

沿时间反传有个隐患：梯度要一路往回走很远。书上第 321 页提醒，梯度可能消失，也可能爆炸，就像残差网络出现之前那些深网络的老毛病。先交代一句，下面这条曲线是教学简化：实验档把 tanh 关掉了，它的导数顶多是一，真实的 RNN 只会衰减得更快，这样十二步内就看得见两头。屏幕上这条程序生成的曲线是实验档实算：权重缩到一半，梯度传十二步缩水四千多倍；权重放大一点八倍，同样的十二步放大一千多倍。一头灭掉，一头炸掉。前面讲残差连接时说过同一个毛病，只是发作的位置不同。

怎么办？书上第 321 页提出，可以加带门的单元，调节信息在帧与帧之间怎么流。两个代表：门控循环单元 GRU，还有长短期记忆网络，名声更响的缩写是 LSTM。书上第 322 页开头接署出处：霍赫赖特和施密德胡伯，1997 年。门可以想成水闸：该记的放行，该忘的关闸，梯度就有了专门的通道，不会一路走一路漏。

循环网络都用在哪儿？书上第 322 页数了一串：视频理解里融合时间信息，语言建模，看图说话，还有视觉问答。偶尔也客串立体视觉，把多个视角的信息缝在一起，或者把迭代光流算法做成可训练的版本。语言和视觉这两站都在第六章，这门课还没走到，先把名字混个脸熟。

收尾前预告一个重点：注意力。书上第 322 页说，循环网络有个天生限制：想回看很早以前的信息，信息都得挤在隐藏状态里一站站传。注意力给了另一条路：存一串键和值，拿查询去对，按对得上号的程度加权取值。这门课没有细讲它的来源核回归，你只要记住查询对键、加权取值八个字。注意力既能向后看自己的历史，这叫自注意力；也能看图像的不同部位。以前它跟循环网络搭伙干活；如今一条序列可以整个并行处理。这一步的跨越，就是下一集的主角：Transformer。

盘点这一集。第一步到三维去：感受野辨析、四种时序融合、三乘三乘三的时空核、体素与点云网格，外加慢快双流的工程提速。第二步沿时间传：循环网络摊开成串、同一组权重走遍所有时间步，梯度会消失会爆炸，所以有了门控的 GRU 和 LSTM。书上第 322 页收束说，这半节只是浅尝，想深学去看教科书第八到第十章。留两道思考题：第一道，展开图摊开十步，可训练的权重矩阵有几组？第二道，权重缩到一半，梯度传十二步还剩几成？答案都在实验档里。下一集，Transformer 与视觉 Transformer，5.5.3 节见。
