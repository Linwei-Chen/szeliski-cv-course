# E064 口播稿 · 习题课：识别章精选题目精讲（含延伸阅读导读）

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

前几集把识别这一章从头走到尾：分类、人脸、检测、分割、视频、语言。书上第 409 到 416 页是章末的阅读指南和习题。这一集做两件事：先给一张阅读地图，再把十三道题挑重点讲透。书上第 409 页的阅读指南按主题把代表工作排了一遍；第 413 页的习题从预训练网络一直排到整部电影的理解。地图告诉你接下来读什么，题目告诉你现在会不会用；两样合起来，这一章才算收尾。先看地图，是为了知道这一章还有哪些线没走；再做题目，是为了确认方法真的会用。两件事一件管方向，一件管检验。

书上第 409 页说，和机器学习、深度学习不一样，图像识别和场景理解没有一本最新的专门教材或综述。老一点的综述和经典文集，比如 Pinz、Andreopoulos 与 Tsotsos、Ponce、Dickinson 等人的，讲的是深度学习之前的路子；这十年变化太大，很多技术已经不用了。要找最新材料，除了这一章和大学课程，就看 ICCV、CVPR、ECCV 这些大会的教程。表 6.1 到 6.4 里那些还在维护排行榜的数据集，也是找新论文的好入口。教材给基础，教程和排行榜给最新进展，两条路一起走。综述和文集能补历史，教程和排行榜能补现在，各管一段。

书上第 409 到 410 页讲实例识别。它认的是静态人造物体：外观变化不大，但三维姿态会变；常用办法还是找二维兴趣点，再用对视角不变的描述子描述。这几年注意力转到更难的实例检索，也叫基于内容的图像检索，要搜的图可以非常多。下一章 7.1.4 节会讲这些技术，Zheng 等人的综述也可以看。这条线还连着视觉相似搜索，也就是 6.2.3 节讲过的内容。从认出这个杯子，走到在千万张图里找到同款杯子，后者才是真实应用。检索规模一大，关键点匹配和索引结构就成了主要开销。

书上第 410 页说，特征法整图分类有一大批综述和课程笔记。有的用词袋或关键点，有的看轮廓，比如形状上下文。很多算法用部件分解，让模型对关节和姿态更稳；Carneiro 和 Lowe 讲过部件识别的图模型，包括树、星形、k 扇和星座。经典识别还爱用场景上下文；机器学习和大规模人工标注库也成了关键部件。先看局部像什么，再看部件怎么摆，最后看整幅场景合不合理；三层证据一起投票，比只盯一个特征稳。局部、部件、场景三层信息互补，单看一层都容易误判。

还是第 410 页。AlexNet 在 2012 年拿下突破，把类别识别的研究重心从手工特征转到深度网络。识别准确率的快速提升，主要靠更深的网络、更好的训练算法，也部分靠更大的无标注数据。第 410 到 411 页说，人脸识别走了类似的路：早期比特征距离，后来比灰度图在低维子空间里的投影，再后来用形状和姿态变形模型，比如主动形状模型、三维形变模型、主动外观模型。社区转向深度后，形状模型还用来做正面化，也有人用数据增强造多姿态。第 411 页说，Masi 等人的教程把深度人脸识别讲得很全。方法换了三代，把姿态摆正、把光照抹平这个目标一直没变。网络更深以后，人脸对齐和光照归一化仍是预处理里的常客。数据变大，网络才敢变深。

书上第 411 页说，整图分类越来越解决之后，注意力转到多物体的分割和标注。检测最早按具体类别研究：人脸、行人、汽车；人脸有 Viola 与 Jones 等代表工作。第 411 到 412 页说，现代检测器通常先用区域提议选区域，再送进多路分类器，于是有了 R-CNN、Fast R-CNN、Faster R-CNN 和 FPN。另一条路是单阶段网络，一次输出多个位置，比如 SSD、RetinaNet 和 YOLO。两阶段像先找人问路，再挨家敲门；单阶段像一眼扫过去，边看边报。区域提议负责找候选，分类器负责认类别，两步各管一件事。

书上第 412 页说，像素级标注比框更有用，比如修图。它分几种：语义分割问这是什么材质，实例分割问这是哪一个可数物体，全景分割问这是材质还是物体。早期办法是先把图预分割成块，再拿块去匹配模型部件；另一条流行路线是条件随机场，当年在 PASCAL VOC 分割挑战上拿过很好的结果。现代语义分割用金字塔式全卷积结构，把输入像素映射成类别。实例分割通常把检测器和逐物体分割合起来，Mask R-CNN 是代表作；语义和实例合到逐像素，就是全景分割。语义铺满、实例数清、全景两样都要。三种任务问的问题不同，输出也就不同。

书上第 412 到 413 页回顾视频与语言。视频理解，更具体说是人体动作识别，研究能追到 1990 年代；综述有 Aggarwal 与 Cai、Poppe 等人。这十年视频理解转用深度网络。把词和图像关联起来研究了一阵，但用完整句子描述图像，是 2010 年代初才持续升温；后来系统加上注意力。再往后是视觉问答。书上第 413 页说，CVPR 2020 的描述教程把 Transformer 描述、视频描述、视觉-语言预训练都串了起来。这一章从认出一个物体，走到用一句短话说清一段视频；语言把前面任务串成了应用。动作识别先解决有没有动，描述再解决怎么用语言说。

书上第 413 页开始是习题，一共十三道。第 6.1 题先让你找一张预训练网络，看它最常犯什么错；第 6.2 题再动手重训练。第 414 页的第 6.3、6.4 题玩图像扰动和层归一化；第 6.5、6.6 题考分割和类别编码。第 415 页的第 6.7 到 6.9 题比较检测器、分类标签与描述、还有分布漂移；第 6.10 到 6.12 题是自监督、视频跟踪、冻结浅层；第 6.13 题问整部电影怎么理解。十三道题可以分成四类：诊断、训练、任务、分析。有的要开电脑，有的只要一支笔，但每一道都要能说清为什么。十三道题覆盖本章每个主题，做一遍等于把全章复习一次。先做哪道都行，重要的是把过程和结论写下来。

书上第 413 页，第 6.1 题：先找一个预训练网络，做分类、分割，或者人脸识别、行人检测都行；跑完之后，看它最常犯哪几类错误。做一张混淆矩阵，标清哪些类别被认成了哪些类别；再换自己的数据，网页搜的，或者你手机相册里的，看看有没有意外的结果。作者自己最爱用的是 Detectron2，书里全景分割的结果就是它跑出来的；Colab 笔记本改一下图片地址就能试。先别急着训模型，先看它怎么错；错误分布比总分更能告诉你下一步该改什么。混淆矩阵的行是真实类别，列是预测类别，对角线越亮越对。

书上第 414 页，第 6.2 题：分析完预训练网络，再拿它原来的数据重训练，改层数、通道数、训练参数，或者加样本，看能不能更合你的意。很多在线教程，包括刚说的 Detectron2 笔记本，都教你怎么从头在别的数据上训。你也可以自建数据集：网页搜索加上标注；低成本但不太准的办法，是直接信搜索结果当标签。Russakovsky、Kovashka 等人的论文讨论过拿准标签有多难。最后把训练过程、架构优化、踩过的坑和发现写下来。这道题练的是实验记录；同样的模型，记录清楚的人才能复现、才能改进。实验记录写清数据、参数和失败尝试，别人才能顺着复现。标签不准，后面的训练和评估都会跟着偏。

书上第 414 页，第 6.3 题：下载 ImageNet 或者更小的 Imagenette；在每张图左上角贴一个小方块，方块颜色按类别唯一；然后用 ResNet、EfficientNet 或 ViT 从零训练。看模型会不会只认方块颜色，把图的其他部分忽略了；评估时再对抗地把不同类别的颜色互换。第 6.4 题：用同一份数据，拿 ViT 把中间层的归一化全去掉，看还能不能训练；再用 Li 等人 2018 年的办法，把有无归一化的损失地形画出来比，就像在山脉里找最低的谷底。一道题考模型有没有偷懒，一道题考归一化到底帮了什么忙。损失地形把优化过程画成地形图，谷底越平滑越好走。

书上第 414 页，第 6.5 题：说清实例分割、语义分割、全景分割三者的区别；再想，每一种能不能通过后处理变成另外两种。书上第 415 页，第 6.6 题：神经网络的类别输入，比如一个词或一个物体，可以用 one-hot 向量编码；但常见做法是再把 one-hot 乘一个嵌入矩阵，输出送进损失函数。题目问，向量嵌入比 one-hot 好在哪里。分割题练任务之间能不能互转，编码题练表示为什么重要；一个考任务边界，一个考特征空间。两题都在提醒：模型看到的表示，决定了它能学到什么。one-hot 只表示是哪一个，嵌入还能表示类别之间的相似。两种编码的差别，最后会落在类别之间的关系上。

书上第 415 页，第 6.7 题：比较 DETR、Faster-RCNN、YOLOv4 的参数量；在 MS COCO 上各训一遍，看谁训得最慢，再看单张图推理要多久。第 6.8 题：图像分类用类别标签和用自然语言描述，至少说出两点显著差异。第 6.9 题：拿几个在 ImageNet 上预训练的模型，不做任何微调，直接去 ImageNet Sketch 上评，看分布漂移让性能掉多少。这三题分别问工程代价、监督信号、泛化边界。参数量与速度决定能不能上线，标签形式决定能问多细的问题，分布漂移决定模型出了训练集还灵不灵。参数量看显存，训练时间看算力，推理时间看延迟，三者要分开量。

书上第 415 页，第 6.10 题：给静态图像、视频、视觉-语言三种数据，各举几个自监督的预训练任务。第 6.11 题：很多视频理解任务想跟踪一个物体穿过时间；假设推理速度不是问题，为什么跟踪可能比逐帧独立预测更好？第 6.12 题：拿一个做物体分类的骨干，改成 YOLO 变体做检测，微调一个新头；为什么值得把浅层冻结？自监督题问标签从哪来，跟踪题问时间上要不要记住，冻结题问哪些知识可以复用。三道题都在讲一件事：别从零开始，先想清楚哪些信息已经在了。自监督先在海量无标注数据上预训练，再把学到的特征迁移到下游。预训练任务设计得好，下游就少标很多数据。

书上第 415 到 416 页，第 6.13 题：现在大多数视频理解网络只吃短片段；要处理整部电影这样的长序列，需要改什么？第 416 页收束。十三道题没有标准答案，但每一道都能落回这一章的一个方法；先写清假设，再动手，最后把结果和书上说法对一遍。这一章从分类出发，经过人脸、检测、分割、视频，最后走到语言；每一站都在回答看懂了多少。下一章换一个问题：两张图里的同一个点，怎么找、怎么对。特征点是跟踪、配准和检索共同的基础。下一集，我们从为什么需要特征点开始。长序列的关键是记忆和分段，短片段网络没有为这两件事设计。十三道题做完，这一章的重点也就过了一遍。
