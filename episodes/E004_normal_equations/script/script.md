# E004 口播稿 · 矩阵求导与最小二乘：一行抵万行

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集结尾，我们给直线拟合求偏导、令零，得到两条方程。两个参数，手算还行；可真实问题动辄上千个参数，一个一个写偏导就太傻了。今天做一次彻底升级：把求导、展开、令零，全部搬进矩阵。升级的终点是一行字——正规方程。原书附录 A.2 开篇写道：最小二乘拟合问题，在计算机视觉里无处不在。这一集把它一次讲透，后面很多章都会回来取用。

它到底撑起多少东西？原书九百二十七页一口气点了四个名：基于特征点匹配的图像对齐，最小化的是平方距离目标，式 8.2；大规模运动恢复结构，可能涉及上千个变量；连图像滤波三点四点一节和正则化四点二节，也都可能归结为最小化平方误差和。附录 A.2 从这些大问题里切下最小的一块——四个点的直线拟合——但工具是通用的。

现在矩阵化：把每个数据点的 x 坐标和 1 打包成一行，n 个点摞成 n 行 2 列的设计矩阵 A；观测值立成一列，叫 b；待求的 m 和 b 立成一列，叫 x。每行产生一个残差：行乘 x 减观测。总误差一行写完：E 等于 Ax 减 b 的范数平方，原书式 A.28。脚注 5 提醒：这里的 x 是参数向量，不是横坐标 x。还有个撞名要交代：向量 b 是观测列，截距也叫 b——原书的记号本来就挤，读的时候多留神。

什么问题配用这一套？原书原话：函数本身不必是线性的，只要求它对未知参数是线性的。多项式拟合，式 A.26：把 x 的各次幂当输入列，系数照样线性。正弦拟合，式 A.27：振幅相位未知不要紧，展开成 B 倍正弦加 C 倍余弦——只要频率已知，它对 B 和 C 就是线性的。讲者的判定口诀：模型是不是一堆已知积木的加权组合？是，就归正规方程管；不是——比如频率自己也是未知数——就得等后面的非线性方法。

第一个灵魂时刻：把平方展开。类比：标量世界的 x 平方，进到矩阵世界就是 x 转置 C x。Ax 减 b 的范数平方展开成三块：x 转置 A 转置 A x，减 2 倍 x 转置 A 转置 b，加 b 的范数平方，原书式 A.29。推导两步：平方和写成转置自乘，混合项配对合并——讲者已推了一遍，欢迎暂停验算。两个新面孔：A 转置 A 是 2×2 对称方阵，A 转置 b 是向量。旧拟合问题被包成一个新碗——讲者的类比：最小二乘就是找碗底。

碗底怎么求？上一集结论直接搬：梯度为零。对 x 转置 C x 减 2 倍 x 转置 d 求梯度，得 2Cx 减 2d；令其为零，约掉 2，只剩：A 转置 A 乘 x 等于 A 转置 b——正规方程，原书式 A.30。跟上一集两条手算偏导方程完全等价——矩阵记号把两条方程压成了一行。记牢两个名字：C 等于 A 转置 A，海森矩阵——讲者的类比：碗的曲率，严格说 E 的海森是它两倍，方向一样；d 等于 A 转置 b，式 A.32，数据揉成的目标向量。

解正规方程，原书首选乔列斯基。C 对称正定——讲者补充：至少两个不同的 x，C 就对称正定——对称正定矩阵可以开平方根：把 C 拆成 R 转置乘 R，R 上三角，式 A.31。再解两个三角方程，式 A.33：先 R 转置 z 等于 d，前代；再 R x 等于 z，回代。为什么不求逆？讲者的纪律：永远别求逆——慢、贵、稳定性还差。它利用对称性——讲者补充，相对 LU：约快一倍、省一半内存；不正定当场报错——讲者管这叫自带体检。

更稳的选手：QR 分解。讲者从正规方程推出：把 A 写成 Q 乘 R——Q 列正交（瘦 QR），转置自乘为单位阵；R 上三角。A 转置 A 约掉中间两个，剩 R 转置 R；A 转置 b 变 R 转置 Q 转置 b。R 可逆（至少两个不同 x），约掉 R 转置，得 R x 等于 Q 转置 b——一次回代，原书式 A.34。原书 929 页备注：这里的 R 与乔列斯基对角取正时相同；数值上 QR 更稳——对舍入误差不敏感些，慢一个常数因子。更稳有多重要？上实验。

实验。四个含噪数据点，真斜率 0.8、截距 1.5，噪声幅度 0.3。四种方法同台：正规方程直接解、乔列斯基两次回代、lstsq——基于正交分解（SVD）——还有上一集的梯度下降，从原点出发，步长取稳定上限的 0.85 倍。谁对？看图。

左图：四条拟合线完全重叠，四个方法收敛到同一个解——斜率 0.8213、截距 1.5235。条条大路通正规方程。右图量偏差：正规方程和乔列斯基与参考解只差 10 的负 14 次方量级，机器精度级别；梯度下降走了 165 步，才追到约 7 乘 10 的负 10 次方。一次矩阵分解抵得上上百次下山——讲者总结：这就是直接法的威力。但它有个软肋，叫病态。

软肋压场。把四个点的 x 平移十万：形状一点没变，噪声还缩到 0.001，两列几乎长成同一列，条件数从 14 飙到 8 乘 10 的 19 次方。左图量斜率偏差，基准 = 双精度 lstsq 参考解：float32 的正规方程解出 20.5——真值才 0.8；float32 的 lstsq 只偏约万分之五，与统计误差同量级；float64 的正规方程偏差约千万分之二，低于统计地板，无害。右图放大：float32 正规方程的拟合线，斜率错了 25 倍，直接飞出画面。

病态不是绝症，原书 928–929 页两味处方。预防：病态一般应当避免——加足正则化或先验，附录 A.3。治疗：绕开 A 转置 A，直接 QR/SVD。讲者再补：中心化（x 减均值）——条件数从 8 乘 10 的 19 次方降到 1.25；挪回原点立刻回 14。病的是坐标系，不是数据。最后是截距：平移十万坐标里截距就估不准——参考解算出负 52，真值 1.5；不是舍入误差，是外推放大：斜率误差乘十万是几十。中心化后，截距 = 均值处高度。

收个尾。一行抵万行：A 转置 A 乘 x 等于 A 转置 b——碗的曲率，乘上参数，等于数据推来的力。配两条讲者的纪律：解正规方程，用分解、别求逆；矩阵病了，先中心化、再 QR。带着这两句话，任何最小二乘问题都拆得开。

想读原书：附录 A.2，主体在九百二十七到九百二十九页——正规方程、乔列斯基、QR 一次讲全，病态处方在九百二十八到九百二十九页；全最小二乘从九百二十九页起，有余力再看。课后作业：把实验代码里的平移量从十万改成一百万，重跑一遍，看条件数和斜率偏差各自怎么变——双精度还撑得住吗？
