# E084 口播稿 · 三条加速路：金字塔、傅里叶、增量细化

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集有了平方差代价函数，但全搜索太慢。这一集讲三条加速路：图像金字塔、傅里叶与相位相关、增量细化。先粗后细，频域一次算完，最后用梯度抠小数。三条路可以单用，也可以串起来。目标都是让同样的对齐在可接受的时间里做到亚像素。四种名字听着多，其实都在回答同一个问题：怎么用更少的比较找到同一个位移。这一集把三条路的适用边界讲清楚，也会说明每条路什么时候会失灵。三条路各有代价，选之前先看运动范围、纹理和噪声。

书上第 562 页说，最简单的办法是全搜索，整数或亚像素步长都行；视频编码的块匹配常在正负十六像素里找。本集用二百五十六见方的图，正负二十四的全搜索要做两千四百零一次平方差；范围再大，成本按平方涨。全搜索的好处是保证找到范围内最优，坏处是只能用在范围小或图小的时候。图更大、搜索范围更宽，全搜索会迅速不可用。这是复杂度问题，不是实现问题。所以视频编码只在小范围做块匹配，再靠熵编码补。范围一小，全搜索就够用；范围一大，它的比较次数就压不住了。

书上第 562 页给出金字塔：先构造图像金字塔，在粗层用少量离散像素搜一个大致位置，再逐层细化。先看缩略图找大概，再放大找细节；粗层一个像素，对应原图好几个像素，所以同样的搜索范围在粗层便宜得多。关键是把粗层的结果传下去，别每层都从头全搜。金字塔的每一层都先做高斯平滑再降采样，避免混叠；否则粗层会出现假结构。层数越多，粗层越快，但丢结构风险也越大。粗层的作用是缩小候选范围，细层才在附近做精确比较。

书上第 562 页说，粗层估计用来初始化细层的小范围搜索；细层的位移要按尺度加倍。本集的三层金字塔只评估一百零八次，就找到和全搜索相同的整数位移；全搜索是两千四百零一次，差二十多倍。这就是金字塔的账：用粗层的少量错误风险，换细层的大量搜索。评估数只是比较次数，不含插值和内存；真实系统的差距还要看实现，但量级差是确定的。所以金字塔在实时防抖里很常见。评估数少了，整条链的耗时才会明显下降；这是金字塔最直接的收益。

书上第 562 页也提醒：金字塔不保证和全搜索结果一模一样，但通常几乎一样好，而且快得多。它省的是搜索，不是精度；如果粗层一开始就选错，细层只在错误附近微调，最后还是错。所以粗层搜索范围要覆盖真实运动，纹理也不能在粗层被完全抹平；这两条不满足，就该考虑傅里叶。粗层选错时，可以在粗层保留几个候选种子，再分别带到细层，这叫多种子策略。多种子能降低风险，但也会增加细层计算。多种子相当于在粗层多留几个候选，能覆盖更多可能，但每个候选都要付细层的成本。

看这张图：原图、二分之一、四分之一、八分之一，四层金字塔。层数越高，图越小、搜索越快，但细节也越少；八分之一层只剩大色块，适合定大位置，不适合抠细节。实际系统常用三到五层，按最大位移和纹理尺度选；层数太多，粗层已经没有可对齐的结构。到八分之一层，细纹理已经糊成块，这时再搜小位移，意义不大。选层数时，先问最大位移和最小纹理尺度。层数不是越多越好，粗层要还能看出可对齐的结构才算有效。

书上第 563 页说，平移信号的傅里叶变换幅度不变，相位线性变化。位移藏在相位里；不用把每个候选位移都试一遍，频域里一次乘法就能算完所有平移的相关。这就是傅里叶对齐的出发点：把搜索变成一次变换。幅度不变、相位线性，这两句话是傅里叶对齐的理论基础，剩下的都是实现细节。这也是频域方法对全局平移特别合适的原因。频域方法对加窗和边界很敏感，做之前先把图补边到两倍大小。补边的目的是让循环移位不把真实内容绕到另一边；边界处理不好，峰就会被污染。

书上第 564 页给出复杂度：FFT 处理 N×M 的图是 O(NM log NM)，而全搜索是 O(N²M²)；重叠范围大时，频域快很多。同一节也提醒，傅里叶相关默认循环移位，重叠很小，或者一张图是另一张的子图时，必须加窗。本集直接做，会在边界出现十字亮线；加 Hann 窗以后，峰值干净，位置也稳。加窗的代价是边缘信息被压低；窗口太大去不掉边界，太小又会丢有效像素，要折中。本集为了看清峰，先做均值去除再加窗。加窗会改变图像的统计，窗函数也要跟着进频域，不能只加在一幅图上。

书上第 565 页说，相位相关把每个频率的乘积除以幅度，做白化，再反变换；理想情况下输出一个尖峰，位置就是位移。本集加窗白化后，峰在横二十三、纵负十七，峰值零点五七零，和金字塔的整数解一致。尖峰越尖，位移越确定；峰变宽，说明信号在该方向缺约束。白化把每个频率的幅度都归一，等于让弱频段也说话；这也是它敏感、容易受噪声影响的原因。峰的位置是整数，亚像素还要靠后面的细化。峰值位置对噪声不算敏感，峰值高度会变，所以位置和置信度要分开看。

书上第 565 页也提醒：白化会把某些频段的噪声放大；如果两幅图都很模糊、纹理少、高频噪声多，相位相关可能反而更差。没有万能的加速方法；频谱干净、平移大，相位相关很好用；低纹理、强噪声，先滤波或者用金字塔更稳。选方法前先看数据，不要只看论文里的漂亮尖峰。如果必须用相位相关，可以先低通滤波，把高频噪声压掉，再做白化。低通滤波的截止频率要按纹理尺度选。先看数据的信噪比和纹理，再决定用哪种方法，比记排名更实用。

这张图把峰值邻域放大：中间亮点是真实的位移，周围是噪声旁瓣。本集峰值零点五七零，明显高于邻域；如果峰值只比旁边高一点，就该怀疑这组数据。相位相关不只看峰在哪，还要看峰有多突出；峰值和次峰的比，是最便宜的置信度。峰值突出程度可以用峰值除以邻域中位数，或者峰值减次峰；本集只展示原始峰。峰值低不等于一定错，也可能是图像本身重复。实际系统会把峰值图和阈值一起可视化，方便排查。把峰值图和阈值一起看，能很快发现重复纹理或者错误匹配。

书上第 566 页说，前面的方法最多到整像素；防抖和拼接要更高精度，常用泰勒展开做增量细化。在当前位移附近，把目标图按梯度线性化；残差约等于梯度乘修正量，解一个小方程就能得到零点几像素的修正。这一步不重新全搜，只在当前解附近迭代。泰勒展开只在小修正量下准；初值差得远，线性化就不成立，所以要先粗搜。增量细化不是独立方法，它总跟在某个粗解后面。初值越准，需要的迭代越少。线性化只在小范围内成立，初值偏差大时，解出来的修正方向就不可信。

书上第 567 页把线性化写成法方程 AΔu=b：A 是梯度外积的和，b 是负残差乘梯度。本集从金字塔的整数解出发，五步把位移误差从零点三一三像素压到零点一零三像素；每步只解一个二乘二方程。误差没有归零，是因为插值、噪声和线性化近似；实际系统会设阈值，够了就停。二乘二方程很快，但梯度要在正确位置采样；采样错了，解出的修正方向也会错。如果 A 接近奇异，说明这个方向没有梯度约束。条件数差的时候，同样一步会放大误差，迭代就会来回震荡。

这张图是细化误差随迭代下降：纵轴对数，五步从约三分之一像素降到约十分之一像素。前几步降得快，后面越来越慢；如果曲线不降反升，通常是梯度符号、插值或者初始位移错了。工程上不要盲目叠迭代；看误差曲线，设一个停止阈值，比固定步数可靠。误差曲线还能当调试工具：下降慢是条件数差，震荡是步长或符号问题，上升是初值或梯度错。本集五步就停，是为了展示曲线形状。停止阈值按需要的像素精度设，不必固定五步；五步只是本集的演示。

三条路怎么选：大位移、纹理足，用金字塔；全局平移、要一次算完，用相位相关；最后都用增量细化抠亚像素。本集只验证平移；参数运动、光流会把同样的粗搜、频域、细化路线扩展到更多参数。先看运动范围、纹理和噪声，再决定组合。组合顺序通常是金字塔先给整数解，增量细化再抠小数；相位相关可以替代金字塔给初值。真实系统还会加鲁棒损失和 RANSAC 兜底。如果运动模型选错，三条加速路都救不了精度。组合不是固定配方，先看数据再决定顺序，比套公式可靠。

这一集可以收成三件事：金字塔用粗层换搜索速度，相位相关用频域换一次算完，增量细化用梯度换亚像素。三者都有前提：金字塔怕粗层丢结构，相位相关怕低信噪比，增量细化怕初值太远。下一集讲参数运动，把平移推广到旋转、缩放、仿射这些情况。参数运动的雅可比会变成矩阵，但法方程的形状没变。先把这三条路走通，再进参数运动。下一集的雅可比是矩阵，法方程还是同样的形状，只是未知量变多。
