# E071 口播稿 · 局部特征的学习时代：从 BRIEF 到 SuperPoint

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

书上第 437 到 438 页说，Winder 与 Brown 的多阶段框架把 SIFT 和 GLOH 都收进来，还允许从数据里学参数，让新描述子超过手工调参的版本。书上第 438 页说，这就是描述子的转折点：参数不再全靠人定，而是从真实图像块里学。上一集片尾说下一集讲分割；转去分割之前，先把描述子最后一段补完，不然第 7 章的特征线是断的。这一集概括成三大步：先学参数，再压成比特，最后交给深度网络；展开就是后面的五级台阶。先学参数，是把人拍脑袋的决定换成数据里的统计；再压成比特，是让匹配变快；最后交给深度网络，是让特征自己从图里长出来。

书上第 438 页说，Hua、Brown 和 Winder 学的是低维投影，把高维描述子投到最有判别力的低维空间。Brown、Hua 和 Winder 再进一步，连池化区放在哪里也一起学。训练数据不是人工标注的小样本，而是互联网照片里用鲁棒运动恢复结构可靠匹配上的真实图像块。同期 Tola 等人的 DAISY 走另一条路，用稠密立体匹配的真值来优化参数。以前是人决定在哪求和、怎么降维，现在把这些决定交给数据。投影降维是为了让描述子更短、更有区分度；池化区决定局部信息怎么汇总。把这两件事一起学，等于把手工设计的格子交给数据调。

书上第 438 页说，图 7.18 画的是 SIFT、GLOH 等描述子的空间求和块，块的位置和权重可以从训练数据库里学。数据库里的图像块来自互联网照片，先用鲁棒运动恢复结构找出可靠匹配，再采样。左边是人设计的格子，右边是数据学出来的格子；格子没变，格子里怎么加权变了。这也提醒一句：训练数据偏了，学出来的描述子也会偏。鲁棒运动恢复结构的作用，是找出同一场景在不同照片里的可靠对应，这样采出来的块才干净。

书上第 438 页说，前面这些检测子追求的是跨所有物体类别的可重复性；也可以反过来，做类别专用或实例专用的检测子，专门最大化与其他类别的判别力。如果能确定图像里平面的朝向，还可以提取视角不变的图像块。通用检测子什么都能用，专用检测子只服务一类，但在自己那一类上更准。实例专用就是只认某一个具体物体；类别专用只认某一类物体，比如全部椅子。

书上第 438 页说，更近的一个趋势是二进制位串描述子，它能利用现代计算机架构里很快的 Hamming 距离运算。BRIEF 在关键点周围比较 128 对不同像素的亮度，把结果存成 128 位向量。128 位就是 16 个字节；比两个描述子像不像，不用算浮点距离，直接按位异或，再数 1 的个数。快，是二进制描述子最大的优点。位数固定，匹配时一次异或就能算完整串的差异，比浮点向量快很多。

书上第 438 页说，ORB 先给 FAST 检测子加上方向，再算带方向的 BRIEF 描述子。BRISK 给 FAST 加上尺度空间分析，再用径向对称的采样模式生成二进制描述子。书上第 439 页说，FREAK 用更像视网膜的 log-polar 采样模式，配上比特比较的级联，追求更快的速度。Mukherjee、Wu 和 Wang 的综述把这些经典检测子和描述子放在一起比较。三家的共同点是都在关键点周围挑像素对；差别在怎么挑、要不要先转方向、要不要跨尺度。ORB 先转方向，是为了旋转后仍能对齐；BRISK 和 FREAK 跨尺度，是为了远近变化时仍能匹配。

书上第 438 到 439 页说，图 7.19 把三种二进制采样摊开：BRIEF 是散落的像素对，BRISK 是同心圆上的径向采样，FREAK 是视网膜式的 log-polar 采样。图注还标了高斯模糊半径，采样前要先平滑，免得噪声把单像素比较带偏。二进制描述子把像不像压成一位一位的比较；采样模式设计得好，位与位之间才不容易重复，匹配才稳。同一位反复比较同一对像素，信息就浪费了；采样模式要尽量让每一位都有独立贡献。

书上第 439 页说，大概从 2015 年起，大多数新描述子都用深度学习来构造；Balntas 等人的综述和 Jin 等人的综述都这么总结。LIFT、TFeat、L2-Net、HardNet、Geodesc、LF-Net、SOSNet、Key.Net 这一批仍然以图像块为输入，和经典 SIFT 的做法很像。它们还是需要先有一个局部特征检测子定出图像块的中心，再按固定尺寸裁块送进网络。这一代是检测子加深度描述子，检测和描述还是分开的。块大小固定，网络输入尺寸就固定；检测子换了，描述子网络可以不动。

书上第 439 到 440 页说，另一类做法是 DELF、SuperPoint、D2-Net、ContextDesc、R2D2、ASLFeat、CAPS，它们直接把整张图作为描述子计算的输入。好处是感受野可以从数据里学，不用事先指定图像块多大。理论上这些卷积网络可以用上整张图的像素，不过实践中它们往往学出类似高斯的感受野。这一步把先检测再描述合成一个网络，特征点和描述子可以一起端到端训练。整图进网络，检测子不再是单独的模块；感受野多大，由网络自己学。

书上第 439 到 440 页说，把两代深度描述子并排看：patch-based 是检测子定中心、固定块大小、网络出描述子；full-image 是整图进网络、检测和描述一起学。书上第 440 页说，书里把前者形容成更像经典 SIFT 的路线，后者则不再需要指定图像块尺寸。前者工程上好替换，后者省掉了检测子这个超参数，但训练数据和算力通常更贵。前者适合在已有检测子的系统里替换描述子；后者要重训整条链路。

书上第 440 页说，HPatches 基准专门评图像块匹配；Balntas 等人的结果显示，HardNet 和 L2-Net 平均表现最好。另一篇论文说 CAPS 和 R2D2 最好，S2DNet 和 LISRD 也自称达到当时最好水平。WISW 基准的结论又不一样，它认为用新思路加强过的传统 SIFT 反而最好。同一件事，换数据集、换评价指标，冠军就换人；不要把某一篇的排行榜当成定论。榜单不同，是因为测试集、评价指标和训练数据都不一样。

书上第 440 页说，在 Jin、Mishkin 等人的宽基线图像匹配基准上，HardNet、Key.Net 和 D2-Net 名列前茅，D2-Net 找到的地标点最多。但结果很依赖任务，Difference of Gaussian 检测子仍然是最好的检测子。这些描述子跨昼夜大光照差异的表现，也有专门研究。这段的关键词是任务相关；没有一种描述子在所有场景通吃。宽基线指两幅图视角差很大；这种条件下，检测子和描述子都会受考验。

书上第 440 页说，宽基线匹配最新的趋势是干脆不要检测子，直接稠密提特征，再匹配并精化对应关系。这些更新的技术，Mishkin 在 2021 年做过评测。从先找点再描述，到整图提特征再匹配，检测子这一环被绕过去了；代价是计算量和匹配后的几何校验更重。稠密提特征，就是每个位置都算一个描述子，不再先挑关键点。

书上第 438 页说，二进制描述子的优势是利用 Hamming 距离，匹配可以按位算。书上第 439 页说，patch-based 深度描述子需要检测子定中心，还要固定图像块尺寸。书上第 440 页说，full-image 方法不需要指定图像块大小，感受野从数据里学。选型就看三件事：算力、精度、工程复杂度。二进制适合端上快速匹配；深度描述子适合难场景；没有检测子的路线适合追求极限精度、又愿意付算力代价的场合。工程复杂度包括训练成本、部署难度和调参工作量。

这一集是一条五级台阶。第一级，手工设计描述子；第二级，从数据里学参数和池化布局；第三级，把描述子压成二进制位串；第四级，用深度网络在图像块上学描述子；第五级，整图端到端，甚至不要检测子。每上一级，人做的决定少一点，数据做的决定多一点；但数据质量、算力成本和可解释性，也跟着变成新的问题。这五级对应的代表方法，在前面都出现过。

书上第 440 页说，书里最后把无检测子的稠密提取称为宽基线匹配的最新趋势，并说这些技术已经被 Mishkin 评测过。理论讲完，下一集上机：用 OpenCV 把检测、描述、匹配串成一条能跑的流水线，看看这些名字在代码里长什么样。下一集是实验课，OpenCV 特征全流程。下一集见。
