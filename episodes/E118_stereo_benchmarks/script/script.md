# E118 口播稿 · 习题课 + 榜单导读：Middlebury / KITTI 立体基准怎么看

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集先问一个不太舒服的问题：榜单第一名，一定比第二名好吗？不一定。同一个预测，换一个误差阈值、换一块评测区域、换一个训练与测试划分，名次就可能翻过来。这一集不教怎么刷榜，教怎么读榜。书上第 753 页说，Middlebury 立体与多视图基准是最早持续维护榜单的基准之一；KITTI 则覆盖立体、光流、场景流等多个任务。一份榜单至少要写清四件事：任务是什么、数据怎么分、指标怎么算、哪些像素不算分。榜单是一份带规则的测量报告，先看规则，再看名次。这一集先看五个代表基准，再看三个会让名次翻转的协议，最后把习题串起来。

看图。横轴是对数，从 Table 12.1 里挑五个代表，规模差三个数量级。原表共有 9 个基准，这一集只挑其中 5 个。书上第 754 页的 Table 12.1 给了这些数：Middlebury stereo 33 对高分辨率图像；KITTI 2015 200 对训练加 200 对测试；DTU 124 个玩具场景，每个 49 到 64 张图；ETH3D 13 个训练场景加 12 个测试场景；Freiburg Scene Flow 39000 对合成图像。这些数的单位并不一样：33 是图像对，400 是训练加测试的图像对总数，124 和 25 是场景数，39000 是合成图像对。所以读表时不能只看柱子长短，要先把单位和任务对齐。规模不是唯一标准，但它决定了能不能训练、能不能公平比较。一个 33 对的基准和一个 39000 对的合成基准，考的东西不一样。

书上第 754 页说，Middlebury stereo 有 33 对高分辨率立体图像。这里的 33 对指 33 组左右视图，每组包含左右两张图。这个数量听起来不多，但它的价值在高分辨率和长期稳定的评测协议。很多细节和小视差，只有在高分辨率上才看得出来。低分辨率图像里，相邻两个像素的视差差一点，重建出来的深度就会差很多；高分辨率能把这种差别保留下来。书上第 781 页说，Middlebury 提供高分辨率图像，但训练数据非常有限，所以深度学习方法在这个榜上仍然明显缺席。这个榜考的是另一件事：训练数据很少时，你的方法还能不能做对。高分辨率立体因此一直是一个独立赛道。

书上第 754 页说，KITTI 2015 有 200 对训练图像加 200 对测试图像，合起来 400 对。书上第 779 页说，KITTI 有专门的训练集，深度学习方法从 2016 年开始主导榜单。训练集给了同分布的例题；考得好，说明会做这类题，不等于会做没见过的题。书上第 781 页说，监督式深度学习方法在有专门训练集的榜单上很强，但跨域泛化仍然不好。看 KITTI 榜单，先问训练集有多大、测试集有没有被反复调参。训练集越大，越容易把榜单变成开卷考试。

把前两页放在一起看，就是一张对照表：Middlebury 训练数据少，深度网络缺席；KITTI 训练集大，深度网络霸榜。书上第 781 页把原因说得很直白：有专门训练集的榜单，监督学习能攻占；但换一个域，泛化就变差。所以“KITTI 第一”是一个有条件的结论：在 KITTI 的分布里、用 KITTI 的训练集、按 KITTI 的指标。换到室内、换到别的相机、换到雨天，颜色、纹理、光照和场景布局都变了，名次未必保留。读榜时先问：这个第一，条件是什么？条件不同，排名就不能直接横比。

看图。左边是两种误差分布，右边是同一对预测在 bad-1 和 bad-2 下的坏像素比例。A 的错误大多在 1.2 像素，bad-1 是 29.4%，bad-2 是 0.0%；B 只有 9.8% 的像素错到 5 像素，bad-1 是 9.8%，bad-2 也是 9.8%。bad-k 只数超过阈值的像素比例，不关心错多少。阈值定在 1 像素，B 赢；阈值定在 2 像素，A 赢。均方根误差更严，A 是 0.672，B 是 1.572，A 赢。所以“谁第一”要先问：榜单用的是哪个阈值、哪个指标。两个结论都不假，差别只在评测协议；A 和 B 没有绝对的好坏，只看哪个更适合你的误差容忍度。

均方根误差先把每个误差平方，再平均，再开方。A 是 0.672，B 是 1.572；A 更稳，因为它没有特别大的错。平方会把少数大误差放大：5 像素的错变成 25，1.2 像素的错只变成 1.44。所以均方根误差对离群值很敏感。如果你的应用最怕偶尔错得很离谱，就看均方根误差或最大误差；如果只关心多少像素超过阈值，就看 bad-1、bad-2。指标要和下游任务对齐。自动驾驶怕幽灵障碍，可能更怕大错；做特效怕边缘毛刺，可能更怕边界坏像素。先定任务能容忍多大的错，再选指标。

同一张 B 误差图，全图 bad-1 是 9.8%；去掉边界以后是 4.4%；去掉遮挡带以后是 6.3%。A 从 29.4% 降到 23.9% 和 21.6%。B 的大错集中在边界和遮挡，掩码一变，B 就从落后变成领先。边界像素容易出界，遮挡像素在一幅图里可见、另一幅图里被挡住，这两类位置本来就没有可靠真值。很多榜单会报去掉遮挡、去掉边界的分数，这样做的原因是这些区域的真值本来就不够可靠；但你必须知道它去掉了什么，否则两个分数没法比。比较两个分数之前，先问掩码是不是同一套。分母不同，冠军就可能不同。

稀疏预测 C 只在 30.0% 的像素上有有效值；在这 30.0% 里，bad-1 是 0.0%，看起来完美。但全图还有 70.0% 的像素没有预测。覆盖率就是有效像素占全图的比例，它决定了分母里有没有缺失像素。只报有效区的分数，等于只算做过的题；做了的全对，不等于整张卷子都会。看稀疏深度或稀疏真值的榜单，必须同时看覆盖率和有效区指标；分母里有没有缺失像素，会完全改变结论。覆盖率和有效区指标要成对出现，缺一个都不完整。

书上第 797 页说，在 closed-world 数据集上训练和测试，网络可能学到捷径，比如根据地面的位置猜深度，或者对不常见的物体不“弹出来”。closed-world 指的是训练和测试来自同一批场景、同一套采集条件。这就像考试题全从同一本习题册出，背答案也能高分。书上第 781 页说，跨域泛化仍然是开放问题。读榜时要问，训练集和测试集是不是同一个世界；如果是，第一名只证明它最会做这个世界的题。模型不一定故意作弊，是数据分布给了捷径。要判断真实场景能不能用，得另做跨域测试。

如果你要动手，书上第 801 到 803 页给了三个台阶。习题 12.4 是平面扫描：先把匹配代价卷起来，比较平方差、绝对差、census 等相似度。习题 12.5 是聚合与窗口：把代价在邻域里汇总，再做赢家通吃、左右一致性和亚像素。习题 12.6 是全局优化：动态规划、半全局匹配、图割、置信传播，最后在 Middlebury 上评测。不要一上来就做最难的；先把 12.4 的视差空间图做出来，再做 12.5 的窗口，最后才做 12.6 的全局。作业按这个顺序交，每一步都附一张评测表。评测表至少写清：数据划分、真值覆盖、指标阈值、掩码和是否跨域；每一步都要能复现。

看图。读榜五问，按顺序问。第一，数据集与划分：训练和测试是否真的分开？如果测试集被反复调参，第一名的含金量就会下降。第二，真值覆盖多少：稠密、稀疏还是带洞？分母里有没有缺失像素？第三，指标与阈值：bad-1、bad-2、均方根误差，哪一个？第四，遮挡与边界怎么算？换一套掩码，冠军可能就换人。第五，跨域还能用吗？同分布榜单的第一，不等于真实场景的第一。五问没有答完，名次不能直接横比。下一集把第 11、12 章串起来，看几何方法里谁承担了主要任务。把五问写成一张检查表，放在实验记录第一页。
