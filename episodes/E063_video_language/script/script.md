# E063 口播稿 · 视频理解与视觉语言：从动作识别到 CLIP

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集把每个像素都分好了。这一集把单张图连成时间轴，再让画面和语言接上。书上第 396 页说，对很多研究者，视频理解从检测和描述人的动作开始。动作是视频的基本原子单位，可以像积木一样串成更长的视频描述。同一页还给这一节排了两条线：先看动作识别和视频分类怎么从手工特征走到深度网络，再看视觉怎么和语言结合，做图像描述、视觉问答和文生图。上一集回答每个像素是什么，这一集回答这段时间发生了什么、能不能用一句短话说清楚，甚至反过来把一句提示画出来。两条线都围绕同一件事：让机器读懂时间里发生的变化。

书上第 397 页说，动作识别在 1990 年代就开始研究了。同期的相关题目还有人体运动跟踪，作者把它们合称人体运动分析。那一代技术用点和网格跟踪，也用时空签名来描述动作。进入 2000 年代，注意力转到时空特征：用小块光流识别体育动作，用时空特征检测器给电影里的动作分类，后来再接上图像上下文和跟踪轨迹。同一页还列了当年常用的数据集：KTH 人体运动、UCF 体育动作、Hollywood 人体动作、UCF-101 和 HMDB。这条路线是先手工设计什么样的变化像什么动作，再拿数据集比高低，是深度学习之前的路子。手工特征要人来决定看什么，换一个场景往往就要重新设计。

书上第 398 页的图 6.44 画了三条路线：双流架构、几种替代的视频处理架构，还有 SlowFast 的慢快双路。第 399 页说，除了把网络直接作用在视频像素上，比如用三维卷积，研究者还把光流当作额外输入，这就是双流架构：一路看静止画面，一路看运动。Carreira 和 Zisserman 后来把双流、三维卷积，以及两者的混合方案放在一起比较。一路认长什么样，一路认怎么动，两路合起来，才不容易把举起手看成放下手。光流记录每个像素往哪走，正好补上单帧看不到的运动。

还是第 399 页。最新的视频理解架构又回到直接在原始像素上做三维卷积。有的工作把三维卷积特征存进长时特征库，给动作识别更宽的时间上下文。Feichtenhofer 等人提出 SlowFast：慢路帧率低、时间分辨率低；快路帧率高、时间采样密，但通道更少。两路特征最后合起来。慢路像隔几秒看一眼，负责判断这是在干什么；快路像连拍，负责抓住手怎么挥、脚怎么迈。两条路分工，比一条路硬扛更省，也更准。慢路看得少但看得广，快路看得密但更轻，两者互补。

同一页，评估这些算法常用表 6.3 里的数据集。名单包括 Charades、YouTube8M、Kinetics、Something-something、AVA、EPIC-KITCHENS 和 AVA-Kinetics。书上第 400 页给了规模：Charades 九千八百段视频；YouTube8M 有四千八百个视觉实体、八百万段视频；Kinetics 七百个动作类、六十五万段视频；Something-something 一百七十四个动作、二十二万段视频；AVA 在四百三十段十五分钟视频里标了八十个动作；EPIC-KITCHENS 是一百小时第一视角视频。数据集从几十段运动视频涨到百万级网络视频，模型才见过足够多的动作变体。这些数据集覆盖体育、电影、日常动作和第一视角，规模一代比一代大。

书上第 399 页还说，和图像识别一样，视频理解也开始用自监督来训练。视频通常多模态：除了画面还有音轨，而音轨正好是免费的、不用人工标注的监督信号。推理时有声音，还能再提一点准确率。动作识别之外，还可以把整段视频分到海滩、烟花、下雪这类场景类别，这叫动态场景识别，用时空卷积网络来做。画面告诉你人在做什么，声音告诉你发生了什么；锅铲声、掌声、雨声，都是不用花钱的标签。自监督的意思是标签从数据本身来，不用人一条条标。

书上第 400 页说，很多计算机视觉研究的终极目标，不只是建三维模型或找相似图片，而是成为通用人工智能的一个组成部分。这要求视觉和语音、语言理解与合成、逻辑推理、常识与专业知识表示接起来。语音助手已经普及，下一步自然就是把视觉和自然语言处理融合。BabyTalk 是个早期例子：先检测物体、属性和位置关系，再推断一套彼此兼容的标签，最后生成图像描述。先认出有一只狗、在草地上、叼着球，再把这几块拼成一句人话，这就是从看见到说出。检测、推断、生成，三步各自都能单独检查。

书上第 402 页说，接下来几年，图像描述论文爆发式增长。很多系统把基于卷积网络的图像理解部件接上循环网络或长短期记忆网络来生成描述，这些部件主要是物体和人体动作检测器。系统还会配多示例学习、最大熵语言模型和视觉注意力。一个有点意外的早期结果是：找一组相似图片，把它们的描述拿来投票取共识，效果居然很好。最近几年，基于注意力的系统仍然是图像描述的核心。图 6.46 就把生成的每个词和图像区域对上了。不只说图里有狗，还要说清是哪只狗、在哪儿、在干什么；注意力就是让每个词都找到它对应的那块画面。投票的办法不训练复杂模型，却说明参考答案的多样性本身有用。

书上第 403 页说，图像分类只能从训练时的固定标签集里选一个。CLIP 换了个思路，用图像描述做零样本迁移，标签集可以随时换。给一张图和一组标签，CLIP 算的是这张图配上「一张某个标签的照片」这句话的概率，取最大的那个。它收集了四亿对图文，用对比学习判断图和句子配不配。更惊人的是，CLIP 没在这些基准上专门训练，零样本成绩却能超过各自微调过的 ResNet-50，换到分布漂移的版本也更稳，比如 ImageNet Sketch、ImageNetV2 和 ImageNet-R。它没有背类别表，学的是图和句子像不像。标签换成什么，提示句就跟着换，不需要重新训练分类头。

还是第 403 页。Goh 等人发现，CLIP 的内部单元对同一种概念的不同模态会有相似反应：蜘蛛侠的图片、单词蜘蛛、蜘蛛侠的简笔画，都能触发相近的单元。他们还找到一种对抗排版攻击：只要在真苹果上贴一张手写标签「iPod」，CLIP 往往就照着标签回答。图 6.47 画的就是这个现象：它不看场景里有什么，只看图上写了什么。这说明 CLIP 很会用文字线索，也提醒我们，它没有摸过苹果；一张便利贴，就能把它带偏。这说明它的判断很依赖画面里的文字，而不是物体的形状和材质。

书上第 403 到 404 页说，常用图文数据集有 Conceptual Captions、UIUC Pascal Sentence、SBU Captioned Photo、Flickr30k 和 COCO Captions。后两者还扩到每张图五十句描述。Visual Genome 更密：它用不同短语描述图像的不同子区域，也就是密集描述；图 6.48 画了它的区域、场景图和问答。YFCC100M 有大约一亿张 Flickr 图片，但只带标题、时间、描述、标签和可选位置这些原始元数据。书上第 405 页的表 6.4 给了规模：Flickr30k 三万图带框，COCO 一百五十万句、三十三万图，Conceptual Captions 三百三十万对；Visual Genome 十万八千图，VQA v2.0 二十六万五千图，VisDial 十二万图加对话。一句描述配整张图，还是一句描述只配一小块；后者更难，也更能教模型看清细节。密集描述把一张图拆成很多小区域，每块都有自己的短语。

书上第 405 到 406 页讲衡量句子相似度的指标。它们对图像描述和整个视觉-语言领域都很重要。常用五个：BLEU，双语评估替补；ROUGE，面向召回的要点评估；METEOR，带显式词序的翻译评估；CIDEr，基于共识的图像描述评估；SPICE，语义命题图像描述评估。BLEU 和 ROUGE 数的是词和片段的重合，METEOR 还看同义词和词序，CIDEr 拿多份参考答案投票，SPICE 则把句子拆成谁、做什么、在哪的语义命题再比。前面几个看字面像不像，SPICE 更看意思对不对。指标不同，侧重点也不同，报告结果时通常几个一起看。

书上第 406 页说，文生图是图像描述的反问题：给一句提示，生成一张图。图像维度太高，想让生成结果看着连贯，一直很难。早期用循环网络从零一笔一笔画，结果很糊；改用生成对抗网络后，图也只有六十四乘六十四。后来常见的做法是先画小图，再以这张小图和文本为条件生成高分辨率图。书上第 407 页说，DALL·E 用了两亿五千万对图文，效果很惊人。它由 VQ-VAE-2 和 Decoder Transformer 两部分组成，文本和图像都变成 token，最后生成五百一十二个候选，用 CLIP 重排。先学会一套图像单词，再让语言模型像写句子一样写图，最后请 CLIP 当评委，挑最像提示的那张。图像 token 排成网格，解码器再把它还原成像素。

还是第 407 页。DALL·E 还有个扩展：只保留一部分图像 token，让 Transformer 自回归猜剩下的，再解码补全；文本加半张图还能做图像到图像。第 407 到 408 页说，会描述不等于真理解。系统到底有没有看懂场景、能不能推理部件怎么配合，这就是视觉问答要回答的。VQA 数据集从 2015 年起带起一大片研究。描述是给图配一句说明，问答是指着图提问；后者不能靠背常见答案蒙混。补全任务和文生图共用同一套 token 表示。

书上第 408 页说，第二年 VQA v2.0 做了平衡的图像对：同一个问题，在两张图里答案不同，逼模型真看图像。后来又进一步降低先验假设和数据分布的影响，要求答案扎根在图像上。VCR 做视觉常识推理；GQA 有两千两百万个问题，建在 Visual Genome 的场景图上，专门考组合推理。这些数据集在表 6.4 里有汇总。问答不能靠背常见答案；数据集就专门设计成不看图答不对。平衡图像对让模型没法只靠问题本身猜答案。

还是第 408 页，讲 VQA 的方法。VQA 系统用各种注意力，把像素区域和语义概念关联起来。它不用循环网络或 Transformer 生成文本，而是先把问题解析成编码，再和图像嵌入融合，产生答案。图像特征可以来自粗网格，也可以用自底向上的物体检测器，配合自顶向下的注意力来加权。这几年在两者之间来回摆，最近两个表现最好的算法反而回到了更简单、更快的网格特征。多模态融合还有双线性池化、对齐、关系推理，以及神经模块网络、鲁棒 VQA、多模态预训练这些分支。模型要先读懂问题在问什么，再决定看图里的哪一块，不能把整张图平均一下就给答案。问题编码和图像嵌入必须在同一空间里才能融合。

书上第 409 页说，视觉对话比 VQA 更难：聊天机器人拿到一张图，要回答开放问题，还得接住前面聊过的内容；VisDial 是最早被广泛使用的数据集。视觉-语言预训练这几年也很猛，ViLBERT、Oscar 都是代表，CVPR 2020 的自监督视觉-语言教程里还有一整批系统。把这一集串起来：动作是视频的原子，双流、三维卷积、SlowFast 是读时间的三种办法；描述把画面翻成句子，CLIP 把分类翻成图文匹配，DALL·E 再把句子翻回画面；VQA 和对话要求机器不仅会说，还要会答。下一集是习题课：把识别这一章的重点题目挑出来，一道一道讲透。这两种任务都要求模型把图和对话历史一起理解。
