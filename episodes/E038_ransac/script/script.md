# E038 口播稿 · RANSAC：用投票找出可靠直线

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集结尾留了个问题：内点是谁、外点是谁，还都按残差大小猜。这一集介绍一个不靠猜的办法：RANSAC。书上第 510 页起，第 8 章专门讲鲁棒最小二乘和 RANSAC。RANSAC 的思路很直接：不先判断谁干净，而是反复抽一小撮点、拟合一条线，再让所有点投票。这一集三步走：先看旧办法在外点很多时卡在哪；再看投票怎么把好线挑出来；最后把胜出的内点名单交给最小二乘。

书上第 510 页说，旧路数是给残差换罚函数、按影响函数折权重，一轮轮迭代重加权，这就是上一集讲的 IRLS。书上第 511 页紧接着提醒：外点太多的时候，从一大把外点里起步的迭代，可能掉进错误的坑，回不到全局最优；更好的做法，常常是先找出一批跟主流运动合得来的内点，从这批内点开始。上一集解决的是怎么算，这一集解决的是从哪儿起步。起点站对了，上一集那套方法才有用。

书上第 511 页给了两个并列的办法：一个叫 RANSAC，随机抽样一致；一个叫最小中位数法。共同的第一步，是随机抽一小撮数据点，先算一个初始估计。书上第 512 页说，一轮里 k 个点全是内点的概率是 p 的 k 次方；样本点一多，要抽的轮数就涨得很快，所以能用最小的签，就用最小的签。这里 p 是一个点有效的概率，k 是一张签抽的点数。本集实验里，签就是两个点，因为平面上两点能定一条直线。小签有两个后果：一轮全中的机会大，但两点定线容易被噪声带歪，所以还得多抽几轮，用票数把好线挑出来。

书上第 511 页说，第二步，拿全部对应点来验这条初始线，残差落在门槛以内的记作内点；门槛多宽，依应用而定，图像里常见一到三个像素。第三步，把抽签重复 S 次，每一轮都数一遍内点，最后留内点最多的那一套。门槛就是允许的误差范围：残差小到门槛以内，才算自己人。抽两个点定线是抽签，数内点是计票，重复 S 次就是多投几轮；票数最多的模型胜出。

书上第 511 页说，数据点特别多、全算一遍太慢的话，还有两个加速变体：Preemptive RANSAC 先粗筛再细算，PROSAC 从最有把握的匹配先抽起。它们都是提速手段，正赛规则还是三步：抽签、计票、留内点最多的模型。具体细节本集不展开，知道什么时候用就行。

本集实验照上一集的配方，换个种子重新造数据：十六个内点，加一个外点，一共十七个点。抽签就从这个池子里抽，外点也坐在池子里。门槛定零点三，大约是两倍噪声。首轮抽签，两点都是内点，线也立住了，十六个内点里有十四个认它，首轮拿到十四票，不算差，也不是全中。外点在池子里，摸到它，线就可能偏。

抽两百轮，按票数排队：最高十五票，最低两票，中位数十三票。两百轮里有一百八十轮抽到干净签，但没有一轮拿到全部十七票，最好的签也差一个内点没进门槛。那二十轮摸到外点的签，票数全被压下去，最高只拿到五票。投票认的是票数，不是手气：外点混进签，线就歪，内点就不认它，票数自然上不去。外点不用被谁赶出去，它自己就落到低票区。

胜出线斜率零点五二九五，真线是零点五；十五个内点投了它，外点零票，外点到胜出线的残差是一点七七二九，远在门槛外，想投票也够不着。拿到十五票的签，两百轮里有五十七张，本实验取抽到的第一张。抽签、计票、留最多，三步走完，好线就出来了。这套流程没有一步是猜的：签是抽的，票是数的，胜者是比的。

胜出的模型怎么用？书上第 511 页说，要么把初始参数递给下一轮拟合，要么把整套内点名单递过去，交给下一轮数据拟合。本集走名单这一支：十五个内点集中起来，重解一遍最小二乘，斜率零点五三八四。说实话，单看这一份数据，两点胜出线碰巧比名单重解还贴真线一点；单次读数不比优劣。名单重解的价值，是用上十五个点的数据，而不只靠两个点。RANSAC 不负责终点，它负责挑人；终点还是最小二乘来算。这份名单十五人，比全部十六个内点少一个，下一幕把外点加压，看投票还认不认得自己人。

外点加压：在原来那个外点之外，再塞三个，一共四个，三个偏高、一个偏低，散在左中右。抽签池变成二十个点，外点占五分之一。普通最小二乘的斜率被拉到零点六四九六，明显跟着外点跑。RANSAC 照旧抽签投票：两百轮里八十三轮摸到外点，这一回胜出签拿到十六票，名单十六人，恰好是全部内点；四个外点零票。名单重解最小二乘，斜率零点五三零七，跟直接剔除外点解出来的那条分毫不差。名单凑齐是这一批签的手气，上一幕同一套机制只拿到十五人；四个外点零票，才是投票的本事。外点翻了两番，投票结果没有跟着偏。每个外点都想拉线，可票数不会说谎：混进签里的，票数把它压下去；想混进名单的，门槛把它挡在门外。

书上第 511 页还讲了并列的最小中位数法，LMS。它不数票数，看残差平方的中位数，谁的中位数小就留谁。本集在十七个点那一场，用同款两百轮也跑了一遍：LMS 选中线的斜率零点五四七六，同样贴着真线；RANSAC 的胜出线是零点五二九五。两种方法判据不同，这一轮选中的签也不同，读数入档，不分优劣。RANSAC 数票，LMS 比中位，目标都是把外点的影响压下去。

两条读数入档。第一，两场实验里混进外点的签，最高都只拿到五票；十七个点那一场，最好的签十五票，没有一轮全中，投票照样把好线挑了出来。第二，固定种子重放这场实验：数据和两场抽签逐位复现，每一条签、每一张票，一个都不走样。抽签交给运气，规则交给票数；结果能逐位复现，靠的是种子固定。同一份代码、同一个种子，重放出来分毫不差；种子一换，签就换，所以读数只认这一份。

两道作业。第一道，把门槛零点三换成零点一五和零点六，重跑投票，看胜出线和票数怎么变，想想门槛太窄、太宽各会出什么问题。第二道，把每签从两点改成三点，同样抽两百轮，数一数干净签的轮数，是变多还是变少。书上第 512 页说，样本点越多，要的轮数涨得越快。第二道就是在亲手数这个：干净签越难抽，要抽的轮数就越多，这笔账下一集算。第一道练手感：门槛宽一窄一，结果会差很多。

抽签、投票、交下一棒，RANSAC 的主流程就走完了。可门槛零点三是本集实验定的，抽两百轮也是本集实验定的。书上第 511 页起说，门槛依应用而定，图像里常见一到三个像素；书上还另列了一串变体；要重复多少轮才够有把握，书里有公式和对照表。下一集把门槛和轮数这两笔账算清楚，还会接上上一集用中位数定尺度的办法。下集见。
