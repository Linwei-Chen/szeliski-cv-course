# E129 口播稿 · 站在两幅图像之间：视图插值的原理

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集问一个最小的问题：手里只有左右两幅照片，加上它们的深度图，能不能算出中间那个没人拍过的视角？视图插值的做法很直接：先把每个像素按深度搬到新位置，也就是几何 warp，再把两幅搬过来的图像合并。它不靠生成模型，算的是几何关系加图像拼接。这一集只做两幅图之间的视角，先不碰任意视角。所有数字都来自一个可复现的二维合成实验：场景是 160×120，前景圆盘深度 1.0，背景深度 4.0。先把这条最小路径走通，再看真实图像还要补什么。两幅图加深度图，就能开工。

书上第 863 页说，视图插值用一对参考图和预计算好的深度图，做出无缝过渡。第 864 页接着说，两幅渲染图加上深度图，能生成虚拟相机在两者之间看到的中间视角。这里有三样东西：参考图给颜色，深度图给每个像素的距离，相机位姿告诉你从哪儿看。三样缺一不可。没有深度，只能做二维变形；没有位姿，不知道该往哪边挪。三样里深度图最难，它可能来自立体匹配、激光或传感器。深度图的误差会直接变成 warp 误差。所以拿到一对图，先看深度图靠不靠谱，再看位姿准不准。位姿从标定来，深度从匹配或传感器来，三者要对齐同一个坐标系。

书上第 864 页说，两幅源图要用参考相机和虚拟相机的位姿，加上各自的深度图，warp 到新视角。视差和深度成反比，近处的物体挪得多，远处的背景挪得少。我们的合成场景里，前景圆盘视差 20 像素，背景只有 5 像素。前向 warp 的公式很小：x 撇等于 x 加上，虚拟相机位置减源相机位置，乘 K 再除以深度 Z。K 是焦距和基线合起来的常数。视差单位是像素，深度单位是场景单位。每个源像素带着颜色和深度搬到目标位置，搬完会出现重叠和空洞，后面的 z-buffer 和补洞就是处理这两件事。K 和 Z 都是场景单位，换算好才不会把视差错算。

书上第 864 页提醒，前向 warp 时多个像素可能落到同一个目标像素上。可以用 z-buffer 记深度，只留最近的那个；也可以从后往前画，让近处最后覆盖。两种写法结果一样。没有深度竞争会怎样？后画的背景会把先画的前景盖掉。我们的无 z-buffer 版本，前景保留只剩 0.381，红色圆盘被背景吃掉了大半。z-buffer 不是可选项，它决定谁挡住谁。只要做几何 warp，就得回答这个问题。先画远，再画近，或者每像素留最近深度，都能让近处物体赢。深度图有噪声时，z-buffer 也会把边缘画错。这一步只比深度，不比颜色。

看图。左边是左参考，中间是插值中点，右边是右参考，三张图用同一尺度。中点不是把左右简单平均，而是每个像素按深度搬到中点，再合并。圆盘在中点回到画面中央，背景纹理也跟着视差对齐。z-buffer 版本 PSNR 34.52 分贝，前景保留 1.000。两幅图都覆盖的地方，按 0.5 和 0.5 混合；只有一幅覆盖的地方，直接用那一幅。缩略图里中间那张很像原图，它其实是两幅图加深度图算出来的。注意中点的背景也不是简单平均，混合只发生在两幅都覆盖的区域。所以中间视角不是原图，也不是左右平均图。

书上第 865 页说，一幅图有洞，就用另一幅图补；两幅都有值，就按虚拟相机到两个源相机的相对距离混合。基线越宽，前景和背景错开越多，单幅图露出的洞越大。我们的单图空洞从 225 涨到 1082 像素。两幅图的洞通常在相反方向：左图前景右移，露出左边；右图前景左移，露出右边。所以两幅图能互相补洞。补出来的区域是另一幅图的信息，不是新的观测。基线越宽，补洞区越大，伪影风险越高。补得再顺，也不等于真实观测。洞的大小直接反映遮挡露出的面积。

看图。横轴是参考相机基线，纵轴是单幅图的空洞像素数。0.25 时是 225，0.5 时 485，0.75 时 743，1.0 时 1082，单调上升。右边两张掩码更直观：窄基线的洞是一条细月牙，宽基线的洞变成大月牙，位置都在前景边缘。掩码里白色是洞。拍立体视频时，基线不是越大越好。太宽，中间视角的洞补不过来，伪影也更明显。基线选择在拍摄和标定阶段就要定下来，后期再改代价很大。基线越宽，视差越大，露出的前景边缘越多。

书上第 865 页还说，两幅图曝光差太大，补洞区和混合区会出现不同曝光，产生细微伪影。我们把左图亮度乘 1.12，PSNR 从 34.52 掉到 27.25，掉了 7.27 分贝，接缝肉眼可见。几何对齐只是第一步，颜色一致是第二步。真实图像还要做曝光和白平衡校正。曝光差不是几何错误，但它会让补洞区和原图区颜色不一致。曝光校得不好，接缝会比洞更显眼。做立体拍摄时，两台相机的曝光、白平衡、增益最好先对齐，再谈几何。颜色不齐，几何再准，画面也会显得假。

看图。有 z-buffer、无 z-buffer、目标视图，三张并排。无 z-buffer 的前景保留只有 0.381，PSNR 26.01，背景把圆盘切成两块。z-buffer 用深度决定谁覆盖谁，前景保留 1.000。这是几何正确性，不是画质微调。如果谁在前谁在后都搞错，后面再好的补洞和混合也救不回来。无 z-buffer 的圆盘被切成两半，原因是背景后画，遮挡顺序错了。深度图有噪声时，z-buffer 也会把边缘画错，所以深度质量仍然关键。遮挡顺序错了，后面每一步都白做。

书上第 865 页说，刚性场景的锯齿可以用两遍前向-后向算法改善；非刚性场景可以用 view morphing。真实图像的坑更多：曝光不一致、裂缝、遮挡边界、非刚性形变。我们的合成场景只覆盖了前两个。所以先分清场景是刚性还是非刚性，再决定用几何 warp、view morphing，还是直接上多视角重建。裂缝来自前向 warp 的采样间隙。两遍前向-后向先正向再反向检查，能减少锯齿和裂缝。非刚性场景不能直接套刚性 warp，需要先处理形变。先判断场景，再选方法，能少走弯路。

书上第 865 页说，视角相关纹理贴图不给每幅图单独配深度，它建一个 3D 模型，按虚拟相机位置选不同源图。第 866 页说，按虚拟视角和源视角的夹角倒数加权，几何可以很粗，混合不同视角仍能产生细节感。我们的例子里，源视角是 −40°、0°、35°，虚拟视角 10°，归一化权重是 0.132、0.610、0.258，最近的 0° 权重最高。夹角越小，源视角越接近虚拟视角，权重越大。权重归一化保证混合后亮度不漂。几何粗一点没关系，视角纹理能把细节补回来。视角越近，贡献越大，这是加权的基本直觉。

这一集收成三件事。视图插值等于深度图 warp 加 morphing。z-buffer 决定遮挡，补洞和混合决定洞和接缝。基线越宽洞越大，曝光差会留接缝。下一集讲光场，把两幅图之间的插值，扩展成四维光场的连续视角。先把两幅图之间走通，再谈任意视角。记住三个词：warp、z-buffer、blend。做实验时先检查深度图，再检查位姿，最后看遮挡和曝光，顺序别乱。这三样东西，就是这一集的主线。
