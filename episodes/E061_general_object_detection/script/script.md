# E061 口播稿 · 通用对象检测：R-CNN 家族、YOLO 与 DETR

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集讲行人检测。这一集把镜头拉远，看通用对象检测。它不只找脸或人，而是找任意类别的物体。书上第 379 页说，人脸和行人检测最早被大量研究，但计算机视觉一直想解决通用的检测与标注问题，不只是整图分类。同一页说，PASCAL VOC 挑战赛有二十类，同时设分类和检测两个赛道。同一张图，分类只要说出有什么，检测还要把每个目标框出来、标上类别。分类回答图里有什么，检测还要回答在哪、有多大。检测的输出是每个目标的框和类别。

书上第 379 页列了 VOC 检测赛道的早期赢家。Chum 和 Zisserman 2007 年的特征检测器加空间金字塔匹配 SVM。Felzenszwalb、McAllester 和 Ramanan 2008 年的星形拓扑可变形部件模型。Lampert、Blaschko 和 Hofmann 2008 年的滑窗 SVM。同一页说，2012 年前两名，一个是滑窗空间金字塔匹配 SVM，一个是牛津大学重实现的可变形部件模型。这个时候还是手工特征加分类器，大家比的是特征怎么设计、分类器怎么调，深度网络还没上场。这些方法都靠人工设计的特征，再交给分类器判断。

书上第 379 页说，ILSVRC 2010 把数据从 VOC 2010 的两万张扩到一百四十万张，类别从二十类扩到一千类。它也有检测任务，但图像范围更宽，更难更杂。同一页说，COCO 每张图的物体更多，还带像素级分割，所以能同时研究语义分割和实例分割，检测和分割从此共用一套数据。表 6.2 列了一批用来训练和测试通用检测器的数据集。数据规模一下大了很多，类别也多了很多，检测器才有足够的东西可学。

要评价检测器，先得量框准不准。书上第 380 页说，主任务是给所有目标套上准确的框，再把类别标对。量每个框的准确度，常用交并比 IoU，也叫 Jaccard 指数或 Jaccard 相似系数。IoU 就是预测框和真值框的交集面积，除以并集面积。同一页图 6.26a 画了这个示意。两个框重合得越多，IoU 越接近一。完全不沾边就是零。框太大或太小，都会把分数拉低。IoU 只看两个框的重合程度，不看类别。

书上第 380 页说，检测器先提出一批可能的长方形区域，再给每个区域分类，打一个置信度。这些区域还要过一道非极大值抑制，也就是 NMS。NMS 按置信度从高到低贪心，把和强检测重叠太多的弱检测删掉。这一步不能省。同一个目标附近往往冒出十几个框，都留着，评估时会把一个目标算成好多次。NMS 让一个目标只留一个最自信的框，把附近的重复框压掉。

书上第 381 页说，评估时把所有检测按置信度从高到低排，逐个判成真阳性或假阳性。类别对、IoU 也够高，就是真阳性。类别错，或者这个真值已经被更自信的框匹配过，就是假阳性。每降一次置信度阈值，就能算一组查准率和查全率。查准率是真阳性除以真阳性加假阳性。查全率是真阳性除以 P，P 是测试图里标注的真值目标总数。阈值放松，报得更多，查全率上去，查准率下来。阈值收紧就反过来。这两个指标天生互相拉扯。查准率看报出来的框里有多少是对的。

书上第 381 页说，把每个阈值下的查准率、查全率画成一条曲线，曲线下的面积叫平均精度 AP。每个类别各算一个 AP，再平均，就是平均精度均值 mAP。同一页图 6.27a 是一条示例曲线。VOC 以前只用一个 IoU 阈值 0.5 算 mAP。COCO 在一组阈值 0.50 到 0.95 上平均，要求更严。同一页还提到基于概率的 PDQ 和更平滑的 Smooth-AP。脚注说，F 分数是查准率和查全率的调和平均。AP 把不同阈值下的表现收成一个数。AP 高，意思是又准又全，既不乱报，也不漏报。

书上第 382 页说，最早的神经网络检测器之一 R-CNN，先用 selective search 抽大约两千个区域提议。每个区域缩放到 224 见方，送进 AlexNet 或 VGG，最后用 SVM 分类。同一页图 6.28a 画了这个流程。它像先把图上所有像物体的碎片剪下来，再一张张送进照相馆辨认。区域提议先给出可能的位置，网络只负责判断。准是准，但两千个区域要各跑一遍网络，慢得让人着急。

书上第 382 页说，Fast R-CNN 把卷积网络和区域提取的顺序对调，并用全连接层替掉 SVM。同一个头既算类别，又精修框。这样卷积只算一遍，训练和测试都快得多，精度也明显更好。图 6.28b 是它的结构。同一页说，它成了共享骨干加两个头、两个损失的典型，不过这两个说法要到 Mask R-CNN 那篇论文才正式提出。书上第 380 页还说，图 6.29 的 COCO 检测 AP 逐年提升，和深度网络架构的进步强相关。共享卷积让所有区域共用同一份特征图。一份特征大家用，不用为每个区域重新算一遍，这就是它快的根本原因。

书上第 382 页说，Faster R-CNN 用卷积区域提议网络 RPN 替掉较慢的 selective search，推理快很多。书上第 383 页说，RPN 在每处粗位置上提出一批形状大小不同的锚框，覆盖不同物体。每个提议再交给 Fast R-CNN 的头分类精修，最后用 NMS 排序合并。同一页图 6.30b 是它用的单分辨率特征图。RPN 和分类头一起训练，提议也越来越准。找候选这件事也交给网络自己学了，不用先慢慢找候选。

书上第 383 页说，R-CNN 三兄弟都在单一分辨率的卷积特征图上算。要更好的尺度不变性，最好在图像金字塔每层都算特征，但太贵。同一页说，直接用网络内部的各层也不行，因为层的语义抽象程度不同。高层懂语义、分辨率低；低层分辨率高、语义浅。最好的办法是特征金字塔网络 FPN。它用自顶向下的连接，把高层的语义灌回高分辨率层。图 6.30d 画了结构。FPN 输出的每一层都可以接检测头。这让检测器明显更强，也没那么怕物体大小变化。

书上第 383 页说，DETR 把 NMS 和锚框生成都去掉了。它用 ResNet 骨干接 Transformer 编解码器，直接输出固定数量的一批框，其中一些可以是无物体。书上第 383 到 384 页说，真值框也用无物体补齐到同样数量。训练时用二部匹配，把每个预测框一对一配到真值框，选总代价最低的配法。总损失就是配对框之间的损失和。书上第 384 页说，作者说它在 COCO 上能和当时最好的检测器竞争。一对一配对避免了重复框，所以可以不用 NMS。像安排座位，每个预测只能坐一个真值，不能抢。配好之后才算账。

书上第 384 页说，另一条路是单阶段网络。一个网络直接在多个位置输出检测，不再分提议和分类两个网络。代表是 SSD 和 YOLO 家族。YOLO 的意思就是你只看一次。两阶段像先挑候选人再逐个面试，稳但慢。单阶段像一眼扫过去，就把人和位置都报出来，快，但更容易漏小目标。

书上第 384 页说，RetinaNet 也是单阶段，建在特征金字塔上。它用焦点损失，把已经分对的简单样本权重压低，让训练盯住难样本，免得大量简单负样本淹没训练。书上第 385 页说，YOLO 家族最新是 YOLOv4，速度超过 EfficientDet 等快检测器，图 6.31b 有对照。论文把流程拆成几段，其中 neck 做 FPN 那样的自顶向下特征增强，还把各种技巧分成训练用的免费礼包和检测时几乎不加成本的特殊礼包。两类礼包都不改网络结构，只调训练和推理细节。焦点损失就是别在已经会的题上反复刷，多做错题。

书上第 385 页说，多数框检测器还在 COCO 上评测，但 Open Images、LVIS 这些新数据集也用起来了。相关研讨会还设实例分割、全景分割、关键点估计、密集姿态估计的挑战。同一页说，开源框架有 TensorFlow Object Detection API 和 PyTorch 的 Detectron2。书上第 386 页还给出一张表 6.2，把分类、检测、定位常用的图像库列成一张总表。数据集和工具箱都齐了，想自己练一个检测器，门槛比十年前低得多。

把这一集串起来。先立度量：IoU 量框，NMS 去重，AP 量整体。再看两阶段 R-CNN 三代怎么把速度和精度一步步做上去，FPN 补多尺度，DETR 用 Transformer 一对一。最后是单阶段 YOLO 一线，用速度换市场。没有哪一种检测器全面赢。要稳选两阶段，要快选单阶段，要端到端简洁看 DETR。书上第 385 页还提醒，实例分割、全景分割、关键点估计、密集姿态估计，都是本章后面要讲的话题。下一集讲语义分割，不只框出物体，还要给每个像素贴上类别。
