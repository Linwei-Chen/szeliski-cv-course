# E096 口播稿 · 去噪进化史：高斯、BM3D 与神经网络的接力

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集讲去噪。书上第 644 页说，去噪是图像处理和计算机视觉的经典问题，四十多年里出现了几百种算法，最近的主流都基于深度神经网络。去噪不是把图磨平。磨得越狠越干净，也越像塑料。我们要看的是，谁能在降噪和保边之间取得平衡。去噪没有唯一答案，只有在一个假设下最优。假设不同，算子的选择也不同。图像处理里，去噪往往是很前面的一步。它和去模糊、超分经常一起出现，工程上很少单独存在。

书上第 644 页说，最新的真实去噪基准是 NTIRE 2020 和 SIDD。它的无噪声真值，是把 150 张含噪图平均得到的，比人工加噪更接近真实传感器噪声。合成噪声好做实验，但真实噪声有信号相关、去马赛克、压缩这些因素。只在高斯噪声上刷分，换到手机照片常常翻车。所以看论文，先看它用什么噪声模型。SIDD 用 150 张平均做真值，也说明真实噪声很难有一张绝对干净的参考。同一台相机，不同设置下噪声也不一样。真实噪声还随 ISO 和温度变化，固定一个 σ 不够。

书上第 644 页列了去噪的经典谱系：全变分 TV、高斯尺度混合、Field of Experts、非局部均值 NLM、BM3D、稀疏字典 K-SVD，后面还有 EPLL、MLP、WNNM、收缩场、TNRD、跨通道噪声模型。这条线的主线是先验越来越强。TV 保边但会 staircase，NLM 保纹理但慢，BM3D 强但参数多。BM3D 之后还有 BM3D-Net 等学习式变体。看图。这里把同一张含噪图交给五种方法。含噪原图是 20.4 dB；高斯滤波 23.1，中值 23.6，双边 23.0，NLM 23.6。高斯最平滑，边缘也一起糊。中值更擅长去椒盐。双边和 NLM 会保住更多边缘和纹理。它们都在用图像自身的结构对抗噪声。先验越强，能用的结构假设也越多。这张图只做二维演示，参数也没有针对每张图单独调优。换一套参数，排名可能会变。

书上第 645 页说，DnCNN 现在被当作深度去噪的基线，还有 learning to see in the dark 这类低光去噪工作。DnCNN 学的是噪声残差，不是整张干净图。网络只看含噪图，输出噪声，再把它减掉。这比直接回归干净图更容易训练。学习式方法的优势是端到端，代价是要数据、要算力，训练分布之外还容易失效。训练数据可以用干净图加合成噪声，也可以用真实配对。数据决定模型能学到什么。DnCNN 之后还有 FFDNet、CBDNet，思路都是先估噪声再去噪。

还是第 645 页。书上说，今天的传感器大多数时候已经比较干净，只有在低光下要拉高 ISO，读出噪声和光子噪声才会和信号相比。噪声不是均匀的。亮处信噪比高，暗处信噪比低，所以去噪强度也应该随亮度变。噪声估计可以用小块方差、主成分或者深度学习。把暗部和亮部一视同仁，是最常见的错误。低光下光子噪声服从泊松分布，读出噪声近似高斯。两者混在一起，暗部噪声就不再是常数。先估噪声水平，再决定磨多狠。

书上第 645 页说，低光下更好的办法是低 ISO 快速连拍，再把多帧合成一张去噪图。HDR+ 把这套做法推广到低光摄影。Night Sight 还会对齐、合并运动区域，并用运动测光决定帧数和曝光时间。连拍降噪靠的是多帧平均，噪声按根号帧数下降。但前提是对齐。手抖、行人、风吹，都会让平均变成重影。对齐误差超过半个像素，平均就会糊。连拍帧数不是越多越好，运动、存储、功耗都有限制。运动测光就是在算拍几张最划算。所以手机夜景的第一难题，常常是对齐和运动分割，不是去噪本身。

书上第 645 页说，去模糊和超分密切相关，最大的区别是模糊核通常更大、而且是未知的，下采样因子 D 等于 1。超分是补采样，去模糊是反卷积。一个把缺失的像素补出来，一个把已经混在一起的光拆开。模糊核估错，反卷积会把图变成振铃和鬼影，而不是变清晰。反卷积是病态问题。核的频域零点会让噪声爆炸，所以必须加正则或者先验。核可以是运动模糊、离焦模糊，也可以两者叠加。核估计准了，反卷积才有意义。所以去模糊的第一步，往往是核估计，不是反卷积。

书上第 645 页说，去模糊可以利用多种信息。可以把清晰但含噪的图，和模糊但干净的图结合起来；也可以拍很多短曝光；还可以用编码光圈，同时估深度和减模糊。核心思路是用另一种退化换信息。短曝光少模糊但多噪声，长曝光少噪声但多模糊。把两者的优点拼起来，比单张硬解更稳。清晰含噪和模糊干净，是两种退化的互补。编码光圈把模糊核做成可识别的图案，这样单张图也能估核，代价是进光量和后期处理。多源信息的共同点，是不指望单张图解决全部问题。短曝光堆叠也能同时做 HDR。

书上第 645 页说，有 IMU 时，可以用它帮助确定模糊核；双像素传感器也能辅助失焦图像的去模糊。手机里的 IMU 记录三轴运动，能告诉你相机怎么抖，比从图里盲猜核可靠得多。双像素本来用于对焦，左右视图的微小视差也能提供深度或模糊线索。IMU 的角速度和加速度要和时间戳对齐，否则核会估偏。时间戳对不齐，角速度和加速度就挂不到正确的画面上。IMU 只能测相机运动，拍运动物体还要靠图像。这也是手机计算摄影的工程难点。

书上第 646 页说，过去十年出现了大量学习式去模糊算法。也有工作故意把纹理重新加回去，让结果更符合图像统计，这就是现在常说的感知损失。感知损失不追求像素最接近，而追求看起来像真图。所以它可能更讨喜，也可能编出原图没有的纹理。做取证或者医学影像时，这种好看反而是风险。感知损失常用 VGG 特征，不是像素差。学习式去模糊常用对抗损失或感知损失，视觉更锐，PSNR 可能反而低。评价指标要和任务匹配。

看图。合成高斯噪声下，含噪 20.4 dB；高斯滤波 23.1，中值 23.6，双边 23.0，NLM 23.6。椒盐噪声下，高斯 22.4，中值 26.8。边缘相关，高斯 0.591，双边 0.647，NLM 0.678。这些数字说明，没有万能的去噪器。高斯噪声下，中值和 NLM 略好；椒盐噪声下，中值明显赢。边缘相关高，不代表视觉一定好，还要看振铃和纹理。注意这些参数是同一套设置，实验只做同条件比较。PSNR 对模糊和振铃不敏感，SSIM 和视觉检查要一起看。这里的双边和 NLM 参数没有逐图调优，换参数排名会变。

看图。八帧平均把噪声降了 63.7%，PSNR 到 29.4 dB；不消除位移直接平均，掉到 20.6 dB。运动模糊是 19.0 dB，Wiener 用正确核是 21.6，错误核只有 12.9。去模糊还把噪声放大了 2.69 倍。连拍的关键是对齐，去模糊的关键是核。两者都是模型对了才有用。Wiener 错误核的 12.9 dB 不是算法坏了，是模型错了。这正好说明核估计有多重要。63.7% 接近理论值 1 减 1 除以根号 8，也就是 64.6%。这个数在平坦区测，全图含纹理时降幅会小一些。

工程上怎么选？先判断噪声类型。椒盐噪声先用中值；高斯噪声可以选双边、NLM 或 BM3D；低光连拍先对齐再平均。能连拍就优先连拍，噪声按根号帧数下降；只能单帧时，再选保边去噪或者学习式。去模糊先估核，核不可信就别硬解。感知损失可以好看，但不能当证据。先做基线，再上学习式，失败时更容易定位。如果噪声类型判断错了，后面调参也救不回来。PSNR 只是门槛，放大看边缘、振铃和重影，才知道能不能交付。

这一集收成三件事。去噪是在降噪和保边之间取舍；连拍靠对齐和平均，单帧靠先验或学习；去模糊靠核，核错会反噬。下一集换到户外，讲去雾。去雾和去噪不同，雾是大气散射造成的对比度下降，有物理模型：无雾的图像，至少有一个颜色通道很暗，这就是暗通道先验。下一集我们把雾拆开看。下一集见。
