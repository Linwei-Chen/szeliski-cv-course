# E006 口播稿 · 贝叶斯思维：先验、似然、后验与 MAP

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

数学工具箱第六站，贝叶斯思维。上一集说：似然，是观测投给 x 的票。可票也有不够用的时候：一台传感器，孤证不立；一图去噪，每个像素只有一次观测——光靠似然，寸步难行。这一集，给估计再加一张牌：先验。花十来分钟，讲清先验、后验与 MAP，以及连接它们的钥匙——贝叶斯法则。

原书 944 页式 B.14：没有 x 的先验模型时，L 等于 p(y｜x)，也等于 p(x｜y)。讲者拆解：没有先验，就是先验处处相同——似然、联合、后验只差常数倍，峰在同一处，选似然最大＝选密度最高。何时是好主意？原书：若数据把候选值紧紧聚在一个值周围——如 p(x｜y) 是单峰高斯——MLE 就是最优：无偏，方差最小。脚注再补：高斯–马尔可夫定理——线性模型、噪声零均值不相关、不必是高斯——最小二乘就是最优线性无偏估计 BLUE。

第一，多峰：能量有几个谷底时，原书提醒可能得推迟决策——比如跟踪中目标的位置，等更多测量；CONDENSATION 就是粒子滤波与 MCMC 的一员。第二，目标未必是峰：式 B.15 改为最小化期望损失：损失函数对后验取平均。原书例是机器人避墙：两侧代价不必对称。损失取冲激，原书说回到 MLE——讲者注：严格说是零一损失，给后验的峰：无先验即 MLE，有先验即 MAP。取平方距离，得后验均值——原书叫 MSE，即期望值估计。

把主线的数学补完。测量是线性时，式 B.16：预测就是矩阵乘状态；能量变成二次型，式 B.17。谷底有闭式解，式 B.18——一组信息加权的平均；还附赠式 B.19：后验协方差也是闭式——不确定性白送。H 等于 I 时，退化成上一集的信息加权平均。测量非线性呢？迭代解非线性最小二乘，A.3 节；CRLB 下界把矩阵换成雅可比即可。

现在请出主角：先验。动机来自一个天花板。原书 948 页 B.4 开篇：最大似然常能给出好解，但有时与测量一致的可能解范围太大，大到没有用处。拿图像去噪说事：若只用带噪版本逐像素估计，根本无法前进——能产生每个带噪测量的取值太多了。脚注 4 直译：事实上，最大似然估计就是噪声图像本身。出路？靠图像的典型性质——比如它们倾向于分段平滑。

先验到底是什么？原书：图像倾向分段平滑的性质，可以编码进先验分布 p(x)——它衡量一张图是自然图像的可能性。构建或估计先验分布的统计模型，叫生成模型——从 p(x) 采样，看生成的东西像不像自然图像。先验也不止图像：物体大致尺寸、镜头焦距、某物体出现的概率——全是先验，都能让估计更可靠。讲者补个直觉：噪声是孤立跳动，分段平滑先验不信孤立跳动——它把相邻像素往一起拉。MRF 编码（B.29）留到 4.3 节。

钥匙登场：贝叶斯法则，式 B.26。后验 p(x｜y) 等于似然乘先验，除以 p(y)——p(y) 是归一化常数，让后验积分为一。取负对数得式 B.27：负后验对数似然，等于负对数似然，加负对数先验，再加 log p(y)。做能量最小化时 log p(y) 是常数，通常丢掉。但有一种情况可以保留：先验自带未知参数——讲者称超参数——想定它们，可以保留 log p(y)：用奥卡姆剃刀最大化观测似然，或用模型选择挑自由参数个数。

最小化负后验对数似然，解叫最大后验，MAP。原书写成能量，式 B.28：E 等于数据能量加先验能量。数据能量衡量在状态 x 下观测到 y 的负对数似然；先验能量的角色，对应正则化里的平滑能量——讲者解读：可以把正则项看成一个先验。原书还泼了盆冷水：MAP 未必总是可取——它选的是后验分布的峰，而不是均方误差这类更稳定的统计量；选哪种统计量，回 B.2 的损失函数去想。

本集实验的数学，一眼看穿。高斯似然乘高斯先验，后验还是高斯——共轭。诀窍：把先验当成一台虚拟传感器。先验中心 x0、宽度 σ0，等价于在能量里加一项：x 减 x0，用先验精度 C0 加权。于是 MAP 就是式 B.20 的推广：信息加权平均多拉一票——x0 以权重 C0 入伙；后验精度，等于各测量精度之和再加 C0。σ0 越小，C0 越大，这票越重。这是讲者推导的标准结果——标量情形——原书 B.4 只给框架。

看实验。真值还是 3.0，读数还是上一集那对：A 读 2.20，标准差 1；B 读负 2.30，标准差 4。现在加一张牌：先验中心 3.5，σ0 等于 2。左图三条曲线：数据能量，似然的碗；先验能量，中心 3.5 的浅碗；总能量，相加。谷底从 MLE 的 1.93 被拉到 MAP 的 2.23——先验轻轻推了一把，朝 3.5 的方向挪了 0.30。

先验的强弱是旋钮。右图扫描 σ0：无穷大，等于没有先验，回到 1.93，正是 MLE；4.0，拉到 2.02；2.0，本集基准，2.23；1.0，2.69；0.5，3.17——注意，已越过真值 3.0，正被拽向先验中心 3.5。先验越强，谷底越靠先验，后验越窄：标准差从 0.97 压到 0.44——但更自信，不等于更准确。解析对不对？把未归一化的后验在网格上积分：均值 2.23、标准差 0.87，与解析公式一致。先验不是魔法，是一张有分量的票。

上一集埋的雷排掉一半：测量混着离群值怎么办？答案在 B.3 稳健统计。直觉一句话：给大残差减刑——换长尾噪声模型，如 Laplacian，惩罚随残差增长变慢，这就是 M 估计量，式 B.21。实操两步：IRLS 迭代降权，式 B.23 到 B.24；尺度用 MAD 估，式 B.25。开局用 RANSAC：先随机抽小子集找内点。细节留到 8.1.4 节与后面的应用集。

收个尾。贝叶斯思维一句话：数据投似然票，先验投常识票，MAP 是两叠票相加后最高的那座峰。暗线也收拢：负对数似然是能量，先验也是能量——能量相加，正是正则化的结构。

想读原书：附录 B 后半，第 943 到 949 页——式 B.14 到 B.19 的 MLE 与线性最小二乘、B.3 稳健统计、B.4 先验与贝叶斯的式 B.26 到 B.28；B.5 随机场与 B.6 不确定性，留到 4.3 节与应用集回收。课后作业：把先验中心 x0 从 3.5 改成 0——一个错误的先验——再把 σ0 从 4.0 调到 0.5，看 MAP 被越拉越偏。强先验能救你，也能坑你。下一集：卷积——上一集两枚骰子之和的伏笔，马上兑现。
