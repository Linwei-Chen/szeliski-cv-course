# E048 口播稿 · 架构演进史：AlexNet、VGG、GoogLeNet、ResNet 的接力

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集留了个悬念：卷积网络的错误率，怎么从四分之一掉到百分之三点几？这一集兑现。书上 5.4.3 节讲网络架构，是一部十年接力史。第一棒 AlexNet 点火，第二棒误差再降三成，第三棒追求效率，第四棒把网络做到一百五十二层。我把它叫接力赛：每代架构解决的，正是上一代暴露的痛点，精度、深度、效率、部署，一棒接一棒。接力跑完，书上 5.4.4 节讲工程生态：去哪下现成模型，怎么用在自己的任务上。这就是本集全部内容。

这一集的标题叫架构演进史。卷积网络不是 2012 年才发明的。书上第 299 页说，现代卷积网络上世纪九十年代末就已开发部署，但直到克里热夫斯基、苏茨克维和辛顿 2012 年的突破性论文，才开始在自然图像分类上超越传统方法。赢了多少？错误率从百分之二十五点八，掉到百分之十六点四。这套系统叫 SuperVision，后来大家更熟悉它的另一个名字：AlexNet。书上第 300 页说，他们还用了 dropout、小幅平移和颜色扰动做数据增广、动量法，以及权重衰减。这四件技巧今天仍是家常便饭，2012 年点火的不只是架构，还有这套组合拳。架构和训练方法一起进步，才有了那次突破。

AlexNet 之后，接力棒一年一传。书上第 300 页说，2013 年的获胜者蔡勒和弗格斯把 AlexNet 加宽，卷积部分通道更多，错误率又降了约百分之三十。2014 年夺冠的是牛津 VGG 团队的西莫尼扬和齐瑟曼。他们发现了一个朴素的道理：用小卷积核反复堆叠。三乘三卷积加激活，再来一次三乘三加激活，中间穿插二乘二最大池化，通道每过一级翻一倍，最后接几层全连接。这样堆出十六到十九层的网络，错误率又降了百分之四十。两层三乘三代替一层五乘五，参数量还省两成八，这是实验档里实算过的账。小核堆得深，非线性也更多，这是 VGG 的出发点。

屏幕上的接力图，把这五年串成一条线。AlexNet 八层，误差从百分之二十五点八降到十六点四；蔡勒和弗格斯再降约三成；VGG 十六到十九层，再降四成；后面是 GoogLeNet 的效率路线和 ResNet 的一百五十二层。书上第 300 页紧接着提醒：如图 5.44 所示，性能大幅提升，代价是计算量也大幅增加。VGG 赢了比赛，也把模型越做越大。这句话把接力棒交给追求效率的人：下一棒，要在同样的精度下把计算量压下来。

书上第 300 页说，2015 年的 GoogLeNet 走另一条路：效率。它开场就用一串带步长和常规卷积、再加池化的主干网，把图像分辨率从二百二十四乘二百二十四快速压到二十八乘二十八。开场就把图压小，算力从这里开始省。然后，网络的基本积木换成 Inception 模块。每个模块是一个小型分支网络：同一路输入并排走几条不同的卷积路线，最后把各路特征拼接起来。像会诊一样，同一个病人，几位医生从不同角度各看一遍，结论合在一起。

书上第 300 页说，Inception 模块最重要的特点，是在做更大的三乘三和五乘五卷积之前，先用一乘一的瓶颈卷积把通道数压下来，省下大量计算。一乘一卷积像一个阀门：先把通道拧小四分之三，再做贵的卷积。实验档实算过：同样输入输出，直接三乘三要三万六千多个参数，套上瓶颈只要四千三百多个，压到大约八倍半分之一。这种先投影再卷积的思路，佩罗纳 1995 年就提过近似版本。书上第 301 页说，GoogLeNet 还把结尾的全连接层删掉，改成全局平均池化，再接一层线性层进 softmax。按七乘七乘五百一十二的特征图算，全连接要两千五百万参数，全局平均池化加线性层只要五十一万，差四十九倍。性能与 VGG 相当，计算量和体积却低了一个量级。通道压小以后，后面的卷积核不用改，乘加次数却少了一大截。

接力赛第四棒，解决深度的烦恼。书上第 302 页说，第二年，残差网络问世，这是何恺明团队的工作，让能成功训练的层数大幅扩展。核心创新叫跳跃连接，最早叫捷径连接：让信息和梯度绕过一组卷积层直接流通。看屏幕上的图：主线是正常的卷积路，红色弧线就是跳跃连接，输入抄近道，直接加到卷积结果末尾。为什么叫残差？网络要学的从完整变换变成了差值，卷积只学该补什么，补的差值加回原输入。近道一通，梯度回传更顺，深层网络才训得动。层数越深，这个近道越重要。没有它，梯度一层层往回传，走到浅层就衰减得差不多了。

残差块还有个变体叫瓶颈块。先一乘一压通道，再三乘三卷积，最后一乘一升回去，和 GoogLeNet 的瓶颈同款。何恺明团队还把 ReLU 挪到相加之前，深层网络能表达恒等映射，还是零成本。把残差块配上步长卷积和通道翻倍，就得到十八、三十四、五十、一百零一、一百五十二层的一系列网络。层数可以继续往上堆，训练误差不再随深度变差。书上第 303 页说，2015 年，ResNet 不只拿下 ILSVRC 分类、检测、定位三项第一，还在 COCO 数据集上拿下检测和分割两项第一。此后变体层出不穷：ResNeXt 用分组卷积，DenseNet 在不相邻的块间也连跳跃线，SENet 给每层加全局上下文。三种变体各解决一个问题：分组、跨层连接、通道注意力。从十八层到一百五十二层，都是同一套积木搭出来的。

第五棒不在赛场，在手机上。书上第 303 页说，网络越做越大时，一股反向潮流出现了：造更小更省的网络，给移动和嵌入式设备用。移动端的约束很硬：功耗、发热、内存都有限。所以轻量化不是可选项，是能不能跑起来的问题。最早的代表作之一是 MobileNets：用深度可分离卷积，它是分组卷积的特例，分组数等于通道数；再配宽度和分辨率两个可调倍率，精度、体积、速度之间可以滑动调节。后继的 MobileNetV2 加了倒残差结构，捷径连接改接在瓶颈层之间。ShuffleNet 在分组卷积之间加洗牌，让不同组的通道互通。ShuffleNet V2 又加通道拆分算子，直接按端到端实测速度调网络。这些省下来的计算、参数和内存，都是手机上真实的续航。

接力跑完，换站。书上 5.4.4 节讲模型动物园。书上第 304 页说，想亲手玩这些架构，最好的办法是从模型动物园下载预训练模型，比如 TorchVision 库。翻开 models 文件夹，AlexNet、VGG、GoogLeNet、Inception、ResNet、DenseNet、MobileNet、ShuffleNet 都有现成实现，还有做分类、检测、分割的其它模型。更新的模型看 PyTorch Image Models 库；其它语言也有类似合集，比如移动端 TensorFlow 的模型库。动物园里每个模型都带着训练好的权重，下载就能推理。这对没有大算力的团队特别重要，省掉几周的训练时间。模型动物园这个名字，是 Caffe 框架的主开发谢尔哈默起的，当年拿它当招牌，后来成了整个领域的行话。

书上第 304 页说，更常用的做法是至少做一下微调：用更贴近应用特征的数据，而不是动物园模型的公开基准数据，继续训练。记住一对行话：主干和头。网络末尾几层叫头，层图堆叠时它在最顶上，其余叫主干。书上特意说，这对术语是 Mask-RCNN 论文带火的。换头怎么换？新数据少，接个线性模型；数据多，接一整段网络。头的选择看数据量：数据越少，头越简单，越不容易过拟合。微调主干也行，但学习率得调小，不然预训练的好处就被冲掉了。书上第 305 页说，这种一处预训练、搬到另一处用的套路叫迁移学习，5.4.7 节讲自监督时还会细看。也有论文叫树干和树枝，偶尔还有脖子，说的都是同一件事。

回到评估曲线。书上第 305 页说，模型大小通常用参数量来量，也就是权重加偏置的个数；计算负载常用每次前向推断的浮点运算次数来量。坎齐亚尼等人 2017 年的评估，把尺子铺到 2012 到 2017 年的 ImageNet 顶级网络上，包括 Inception-v3 和 Inception-v4。模型又大又费算力，就有人动起省的脑筋：低精度定点算术、权重压缩。同页说，XNOR-Net 这篇论文研究用二值权重，连线只有开和关，外加可选的二值激活；论文对早年的二值网络和其它压缩技术还有不错的综述。参数量小不代表算得快，还要看每层乘加的次数。反过来，计算量小也可能权重很大，部署时同样占内存。

书上第 305 页说，网络设计还有个更新的潮流：神经架构搜索，简称 NAS，让算法去尝试不同的网络拓扑和参数组合。书上第 306 页说，这比早期反复试错的人工设计，省下了研究者的时间。这份名单还在快速变长：FBNet、RandomNets、EfficientNet、RegNet、FBNetV2、EfficientNetV2；甚至还能做无监督的架构搜索。把最新网络画到一张图上对比，结论很直观：比起前面那些老网络，新一代用少十倍甚至更多的参数，达到更高精度。从 AlexNet 到 EfficientNet，同一任务参数省一个数量级。NAS 把设计网络变成搜索问题：定好搜索空间和评价指标，让算法自己找。代价是搜索本身也要算力，所以常用代理任务先筛。

最后一站，工具箱。书上第 306 页说，过去十年出现了大量深度学习软件框架，维基百科词条就列了二十多个，约一半还在活跃开发。Caffe 是最早用于计算机视觉的框架之一，如今基本被 PyTorch 和 TensorFlow 取代。教材方面：格拉斯纳的入门书用 Keras；《动手学深度学习》用 MXNet，最近也补了 PyTorch 和 TensorFlow 版；斯坦福 CS231n 和约翰逊的讲义各有一讲框架基础。书上第 307 页说，还常配可视化工具，比如 TensorBoard 和 Visdom；更高一层的封装也有了，比如 Classy Vision，几乎不用写代码就能训练或微调分类器。卡帕西还写了篇训练网络的实用指南，帮你避开常见的坑。框架换得快，但数据、模型和训练流程的思路是通用的。

接力跑完，收一收。从 AlexNet 的点火，到 ResNet 的一百五十二层，再逛完模型动物园和工具箱。留两道作业。第一道口算：两层三乘三卷积代替一层五乘五卷积，输入输出通道数不变，参数量省百分之几？答案在实验档里，这里不说。第二道思考题：两层三乘三和一层五乘五，参数量之外还有什么区别？提示：想想激活函数出现了几次。下一集换个视角，原书 5.4.5 节讲可视化权重与激活：网络内部到底学到了什么，每层看到的图长什么样。前面埋的反卷积网络探针，也在那里兑现。下集见。
