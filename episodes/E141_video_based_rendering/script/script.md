# E141 口播稿 · 视频纹理与静态图动画：重排、分层与补洞

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这是正课第一百三十三集，补第 14 章视频渲染的开头。前面有一集讲视频漫游，另一集讲自由视点视频；这一集讲两件更基础的事：已有视频怎样重排成新视频，单张静态图怎样分层动起来。书上第 887 页说，视频渲染和视频动画，是把拍到的视频重新生成新序列。一条线是视频纹理，另一条线是静态图动画。核心都是从素材里找可复用的片段，不是凭空生成。视频纹理面向一段循环素材，静态图动画面向一张照片，两者都在重新安排像素的时间顺序。好处是省成本、保留真实光影，难处是接完还要像一段连续拍摄。

书上第 888 页说，Video Rewrite 把原视频帧重排，去匹配新说出的句子，比如电影配音。做法是先做语音识别，从源视频和新音频里提取音素；音素三个一组，叫三音素，因为人说话有协同发音。然后到源素材里找匹配的三音素，把嘴部图像剪下来、贴到目标视频里，还要做头部运动的几何变换。分析阶段跟踪嘴唇、下巴和头；合成阶段用形变把相邻嘴形融合。三音素比单音素多了前后文，拼出来的嘴形不会一个音一个样。音素是三音素的基本单位，协同发音让相邻音互相影响，所以要看三个一组，而不是孤立的一个音。头部一动，嘴部位置就变，几何变换不能省。

书上第 888 页说，更进一步的 face transfer，用一段新的源视频，而不只是音频，去驱动以前拍好的视频；重渲染说话人头时，连视觉语音、表情、头姿都带上。书上第 889 页说，视频动画也能用于全身运动，比如匹配两段视频的光流场，用一段驱动另一段；也可以把表面纹理展开成稳定图像，再贴回原视频。从换嘴型走到换整张脸、换全身，关键都是找到源和目标之间的对应。光流场描述每个像素往哪走，两段视频对上了，动作就能从源视频搬到目标视频。对应找得准，换脸才不飘；对应一错，表情和头姿就会打架。

书上第 889 页说，视频纹理把一段短视频重新排帧，保持视觉连续，变成可以一直播的动画。最简单的做法是比外观，用 L2 距离找相似帧，然后跳过去。同一页提醒，如果两帧运动不同，会出现很明显的伪影，视频会卡住；比如钟摆，外观一样但方向相反，跳过去就会突然倒着摆。直接算光流也不稳，无纹理区尤其不可靠，而且视觉和运动的权重也不好定。外观距离只看像素值，运动方向要看帧与帧之间的变化；两帧长得一样，不代表接得上。视频纹理不是把整段循环播放，而是把看起来接得上的片段接起来；难点是接的时候运动也要接得上。

看图。图 1 用 100 帧、160×120 的合成往返小球。第 99 帧在 x 等于 62，只比外观时，最近邻是第 21 帧：两帧像素完全相同，MSE 是 0.0000，但方向从向左变成向右。加上光流方向后，最近邻变成第 95 帧：方向仍是向左，外观 MSE 是 0.002884；总代价从 1.20 降到 0.79。这就是本集实验的出发点：把外观项和运动项分开，单独看方向错时会付出多大代价。外观项负责像不像，运动项负责往哪走；两个都要，缺一个就会跳错。

书上第 889 页说，与其只比单帧，可以匹配相邻帧的三元组或更大邻域，就像 Video Rewrite 匹配三音素；把所有帧的相似度堆成 n×n 矩阵，再用 FIR 滤波强调匹配得好的子序列。书上第 891 页说，匹配结果可以写成跳转表，也就是任意两帧之间的转移概率；这些概率可以看成一个隐马尔可夫模型，HMM。本集实验为了把方向单独拎出来，用光流方向项代替三元组；真实系统还要 FIR 和图割。相似度矩阵管像不像，FIR 管连续几帧都像不像，跳转表管下一步往哪跳。FIR 滤波可以理解成在时间上做加权平均，让连续几帧都匹配的片段得到更高的分数。三层合起来，才像一段会自己走下去的视频。

看图。图 2 还是第 99 帧。只比外观跳到第 21 帧，位置一样、方向相反；加运动项跳到第 95 帧，方向对，但位置从 x 等于 62 到 x 等于 70，外观 MSE 是 0.002884。直接把这两帧硬切，最大相邻帧 MSE 是 0.002884；做 cross-dissolve，L 等于 2 降到 0.000320，L 等于 4 降到 0.000115，L 等于 8 降到 0.0000356，L 等于 16 降到 0.00000998，降了 99.65%。方向对了，位置差还在；混合不是修方向，而是把位置差摊到几帧里。混合只在位置差较小的相邻帧之间有效；位置差太大时，还是要先找更接近的候选帧。方向错了，再多混合也只是把倒放变模糊。

书上第 891 页说，找不到完全匹配时，可以用形变，也就是扭曲加混合；运动够混乱，比如篝火、瀑布，简单的扩展交叉溶解就够；更好的过渡可以在时空体上做 3D 图割。多个物体独立运动时，要先把视频分成独立运动区域，再分别动画；慢速摇摄可以拼全景视频纹理；把鱼缸里的鱼抽成视频精灵，可以沿指定路径动，路径方向要和原运动方向匹配。同一页还提到 Vid2Player 和 mocap soup；动态纹理则把视频当成三维时空体。分层和区域分割都是为了减少互相干扰；每个区域单独处理，接缝才有机会藏好。从整帧重排，走到按区域、按精灵、按时空体处理，接缝会少一些。

看图。图 3 是 240×160 的合成静态图，分成背景、云、树、船四层。船层有软 alpha；软 alpha 合成 MSE 是 0.000000，硬边 mask 的 MSE 是 0.001491，PSNR 28.27 dB；软边像素有 1344 个。船向右移 22 像素后，原位置露出 1619 个背景像素；留黑洞 MSE 是 0.540623，修补后降到 0.034745，降了 93.6%。软边的像素同时含有前景和背景，硬边只取其中一边；所以软边合成更接近真实拍摄。软 alpha 过渡自然，硬边会有锯齿；补洞补得够好，移动后的背景才不抢眼。

书上第 892 页说，静态图动画的第一步是分层，把图分成若干层，每层用同一种运动纹理；每层要有颜色图、matte 和合成顺序。层移动会露出被遮住的背景，所以要用增强修补把洞填上；修补不用完美，因为只有洞边界附近的像素容易露出来。运动类型有树摇、水波、云移、船晃和静止；所有效果可以挂到全局参数，比如虚拟风的速度和方向。前向映射会有洞和走样，所以实际用逆向映射。合成顺序决定谁遮住谁，顺序错了，前面的层会被后面的层盖住，所以它也是参数。分层、抠图、补洞、指定运动、合成，五步做完，图才会动得自然。

这一集的实验是合成数据，不是真实视频；视频纹理只演示一个剪辑点，不做完整 loop 优化、3D 图割、多区域分割；运动项用光流方向，不是原论文的三元组加 FIR；静态图的 alpha 是已知图形羽化，不是 Bayesian matting 估计；补洞用 Telea 示意，不是 Criminisi 原算法。书上第 893 页说，更近的工作用深度网络，从静态照片猜一个运动场，把图像编码成多尺度深度特征，双向推进，再解码成循环流体视频。深度方法并没有推翻这些步骤，它只是用网络学出运动场和分层，对应和补洞仍然要处理。传统方法靠找片段、拼片段，深度方法靠学运动、生成帧；两条路都在解决连续性问题。

这一集把视频重排、视频纹理、静态图动画走完了。视频纹理的关键是外观加运动：只比外观会跳错方向，方向对了还要用混合藏位置差；静态图动画的关键是分层加 matte 加补洞，再给每层指定运动。一边是旧视频重新剪，一边是旧照片分层动；共同点是把已有素材拆开、再按新脚本装回去。找一段 5 秒的循环视频，先只比外观做跳转，观察有没有方向翻转；再加运动项，比较跳转前后的连续感。下一集讲 environment mattes 和暗角、PSF；再下一集讲三焦张量和完整自标定。找素材时先看跳转是否接得上，再看混合能不能把差值压下去。作业不要求做出完整系统，只要求你能说出哪一步在比外观、哪一步在比运动、哪一步在补背景。
