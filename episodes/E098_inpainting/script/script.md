# E098 口播稿 · 消失的它：图像修补 inpainting

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这是正课第九十集，讲图像修补。书上第 665 页说，把照片里被移除的物体或者缺陷留下的洞补上，叫 inpainting，是纹理合成最常见的应用之一。修补要做的是让补出来的区域在结构、纹理、颜色上都像原来就在那里。洞小可以靠邻域，洞大就必须借图像别处的纹理。修补是有条件地编造，不是恢复唯一真值。洞的位置、大小和背景纹理决定用什么方法。先判断这个洞是小瑕疵，还是大物体留下的。背景纹理越强，越不能只靠平滑。

看图。图 1 是合成纹理图上的修补结果：真值、带洞输入、扩散 26.8 dB、示例块 19.9 dB。扩散把周围颜色平均进洞，补出来的是一块平滑的补丁。示例块从已知区搬小块纹理，能保留真实的纹理统计。两张图各有胜负：PSNR 高的那张看起来更平滑，纹理更像的那张 PSNR 反而低。本集实验就是把这两种方法放在同一张图上比较。看放大图，比只看分数更可靠。

书上第 666 页说，修补可以用来去掉照片里不想要的人，修老照片和电影的划痕，或者去掉吊威亚的钢丝。Bertalmio 等人沿等照度线方向传播像素值，并穿插各向异性扩散。等照度线就是亮度相同的线。沿着它传，边缘不会被抹断。扩散适合小洞和平滑区域，能把颜色和渐变接上。等照度线是边缘的切线，所以对细长划痕特别有效。Bertalmio 还会交替扩散，防止方向失控。Telea 用水平集里的快速行进法，做得更快。洞落在草地、砖墙、头发上，就会明显糊。

书上第 666 页说，Bertalmio 等人后来在修补区域加合成纹理。示例块方法也可以从外向内填，叫 onion-peel 顺序。这种顺序可能传不好强方向结构。从外向内，一圈一圈往里面补；遇到长边缘、栏杆、屋檐，方向会被一圈圈的顺序带歪。置信度更新让后面的块越来越自信，但不代表结构对。示例块从已知区搬块，能保留真实纹理统计。onion-peel 适合纹理均匀的大洞，不适合结构洞。如果洞跨过长边缘，一圈圈的顺序会把方向接错。

书上第 666 页说，Criminisi 等人用示例块纹理合成，合成顺序由区域边界上的梯度强度决定。先补结构最强的地方，再补纹理。每补一块，置信度往下传。优先级等于置信度乘数据项，数据项看等照度线撞到边界有多强。数据项大，说明结构强；置信度大，说明周围已知像素多。两者相乘再排序。顺序错了，纹理会把结构切断。优先级也可以由用户笔触指定，Sun 等人的交互线就是干这个。优先级高的块先补，补完再更新掩码和置信度。

书上第 666 页说，如果有一个大图像库，有时可以直接复制一整块区域来填洞。Hays 和 Efros 用图像上下文和边界兼容性选源图，再用图割和泊松融合拼进去。这相当于从图库里找一张相似的照片，抠一块贴过来。难点是找到语义和光照都匹配的块，不然接缝会露馅。图割负责接缝，泊松负责颜色和梯度融合。源图库越大，越可能找到语义匹配的块。没有大图库时，只能在当前图里找源块。源图库越大，越可能语义匹配，但版权和隐私是另一回事。

书上第 667 页说，最新的修补技术都用深度神经网络。架构上有 partial convolution、边缘结构传播、多分辨率注意力或者残差、迭代置信度反馈。网络学的是洞周围该长什么样这个先验。它能编出纹理，也可能编错。partial conv 只对已知像素做卷积，避免把洞里的零当成真实颜色。掩码随层传播，越深越知道哪里缺。学习式修补的评测要看感知质量，不能只看 PSNR。partial conv 不是万能，掩码边界仍可能出伪影。学习式方法需要训练数据，换到没见过的场景可能失效。

本集实验在合成纹理图上挖掉一块已知真值的洞，再比较填补结果。常数填充 21.58 dB，扩散 26.83 dB，示例块 19.86 dB。洞内纹理能量，真值 0.0734，扩散 0.0000，示例块 0.0605。边缘相关，扩散 0.823，示例块 0.720。这组数字里，PSNR 和边缘相关偏爱扩散，纹理能量偏爱示例块。PSNR 对平滑但没有纹理的结果很宽容，所以不能只看一个数。报告修补结果时，要同时给 PSNR、纹理指标和放大图。纹理能量只是统计量，方向对不对还要看结构。

本集实验还比较了洞的大小和 patch 大小。小洞 28.01 dB，大洞 16.19 dB。patch 等于 11 时是 25.6 dB，与 patch 等于 7 差 5.77 dB。洞越大，可借的上下文越少，越容易编错。patch 越大，单块纹理更完整，但更容易把不该带的结构搬进来。参数没有通吃，得看洞的形状和纹理尺度。细长洞比方形洞更难借到完整纹理。patch 太小会重复，太大会搬错结构。洞越大，PSNR 下降不是线性，是断崖。这些读数都来自合成纹理图，不是真实照片。

这一集实现了一个简化的 Criminisi 优先级，结果在本实验里没有赢过简单的 onion-peel。这不代表论文方法错，而是说明优先级、数据项和搜索空间的实现细节非常关键。真实系统里，结构传播、置信度更新、源块搜索要一起调。只抄一个公式，常常补出锯齿。本实验场景纹理比较均匀，结构也简单，onion-peel 已经表现很好。这不说明 Criminisi 本身弱，只说明实验边界有限。这个负结果保留下来，避免误导。真实实现还有源块搜索加速和置信度归一化。

小洞和平滑背景，先用扩散或者快速行进，快且稳。有纹理或者大洞，用示例块或学习式。修补前先决定结构优先还是纹理优先。长边缘、栏杆、屋檐必须先补结构。输出前放大看接缝、重复纹理和方向断裂，PSNR 只是参考。洞跨过人物或文字时，优先保护语义结构，必要时手工画引导线。学习式适合有训练数据的场景，取证和医学要谨慎。修补前先备份原图，修完对比放大，避免越修越假。没有训练数据时，传统方法更可控。

这一集讲完了。修补是用邻域或者别处的纹理填洞。扩散保平滑，示例块保纹理，填充顺序决定结构。PSNR 不等于看起来真。选方法之前先看洞的大小和背景纹理。下一集把这一章的应用串起来，讲手机夜景模式的十八道工序，把 HDR、超分、去噪、去雾、修补串成一条管线。应用集见。下一集见。这一集的重点是方法边界，不是调参。
