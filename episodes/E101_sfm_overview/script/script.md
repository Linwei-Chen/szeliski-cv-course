# E101 口播稿 · 从一堆照片到一座三维城市：SFM 问题总览

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集进第 11 章，从运动恢复结构，SFM。书上第 684 页说，从图像重建三维模型，是计算机视觉从诞生起就有的核心题目。三维建模在虚拟旅游、自动驾驶、增强现实里都非常有用。前面十集，我们大多在让一张图更好看、更准确；这一章反过来，从多张图里把相机在哪、场景长什么样一起算出来。SFM 的输入是一堆照片和它们之间的对应点，输出是相机位姿加稀疏三维点云。它是一连串几何估计，不是一次就能完成的操作。

书上第 684 页说，这一章用图像之间的对应点，构建场景的稀疏三维模型，并把相机重新定位到模型里。整条 SFM 管线可以压成六步：输入照片、特征匹配、双视图几何、三角化与位姿、束调整、稀疏点云。每一步都可能失败。匹配错，几何就错；基线太小，三角化不稳；位姿初值差，束调整会掉进局部极小。所以管线不是单向流水线，后面发现重投影误差大，要回到前面重修。后面每一集，都会拆开其中一段。

书上第 684 页把本章分成五段。11.1 标定相机内参，11.2 从 3D-2D 对应估计位姿并三角化，11.3 双视图 SFM 和对极几何，11.4 多帧 SFM 与束调整，11.5 实时 SLAM。这门课的主线是 11.2 到 11.5，后面的分集按这四节展开。11.1 的内参、消失点、单视图度量，只在总览里定位，不单独展开。这是课程边界，不是它不重要。同一页也说，本章跳过了三焦张量和完整自标定等更丰富的材料，只讲大规模图像重建里最有用的基础。

书上第 684 页说，这一章用图像之间的对应点构建稀疏三维模型。SFM 的第一口粮不是像素，是同一个三维点在两张图里分别落在哪。这叫对应点，也叫特征匹配。前面第 7 章讲检测与描述，第 9 章讲运动估计，都是在为这里准备。好的匹配要满足三件事：描述子像、几何一致、跨多张图能串成 track。只靠描述子，会有重复纹理误匹配；只用几何，又需要初始位姿。工程上通常先粗匹配，再用 RANSAC 和双视图几何剔除外点，最后把多张图的匹配串成轨迹。匹配质量决定 SFM 的上限。

两张图之间有一条硬约束，叫对极几何。同一个三维点，在左图的位置确定后，它在右图只能落在一条直线上，这条线叫对极线。为什么？左相机看到的那条视线，在右相机里就是一个平面，平面和右图像的交线就是极线。两相机光心之间的连线叫基线。基线越大，同一点的视差越大，深度越稳；基线太小，视线几乎平行，深度就病态。书上第 684 页把双视图 SFM 放在 11.3，下一集会专门讲对极约束、本质矩阵和基础矩阵。这一集先建立直觉：SFM 的深度，是从两个不同位置看同一件事的视差里挤出来的。

书上第 684 页说，11.2 先从 3D 到 2D 的对应估计相机外参位姿，再把一组 2D 对应三角化成三维点。位姿就是相机在世界里的位置和朝向。已知三维点和它们在图像里的像素，求相机位姿，叫 PnP。反过来，已知两个相机位姿和一对像素，求三维点，叫三角化。位姿和三角化是一对搭档：位姿准，三角化才准；三角化出的点又会反过来约束位姿。重投影误差，就是把三维点投回图像，和实际像素差多少。SFM 后面所有的优化，几乎都在压这个误差。下一集会把这套位姿与三角化算一遍。

两张图只能给你一个相对位姿和一组三维点。要建一座城市，需要很多张图。多帧 SFM 的核心是 track：同一个三维点在不同图像里的像素串成一条链。所有相机位姿和所有三维点一起估计，才不会被单对图的噪声带偏。书上第 684 页说，11.4.1 用因子分解，在正交投影近似下同时估计结构和运动；更通用的是 11.4.2 的束调整。因子分解像把一个大矩阵拆成相机矩阵乘三维点矩阵，数学漂亮，但正交投影只是近似。真实透视相机还是得靠束调整。多帧的好处是冗余：一个点被很多帧看到，错一个匹配不至于毁掉全局。

束调整，英文 bundle adjustment，就是把所有相机参数和所有三维点放上谈判桌，一起最小化重投影误差。为什么叫束？每台相机的中心发出一束光线，穿过图像上的点，打到三维结构上。调整这些光束，让它们和观测最吻合。目标函数不神秘：每个观测像素和预测像素的差，平方求和。未知量是每台相机的内外参和每个三维点。未知量巨大，但每个观测只涉及一台相机和一个点，所以雅可比矩阵非常稀疏。书上第 684 页把束调整列为 11.4.2 的核心。下一集会讲它怎么解，稀疏性怎么利用。束调整是 SFM 的精度上限所在。

真实的增量式 SFM，是一张张往上加。先选两张基线合适、匹配多的图做初始化，三角化第一批三维点。再一张张加新图，用 PnP 估计新相机位姿，三角化新点，跑一次局部束调整，最后做全局束调整。COLMAP 的心脏就是这套循环。增量式最怕两件事：初始化选错，后面全歪；漂移累积，转到一圈回来接不上。所以工程上要选好初始对，做几何验证，控制每步的外点，还要有回环或全局优化兜底。书上第 684 页说，本章聚焦大规模图像重建的基础。后面会把这条增量流水线拆开，也会用 COLMAP 真跑一遍。

增量式一张张加图，精度好但慢。全局 SFM 先把所有相机的旋转估出来，再统一估位置和结构，适合几万张互联网照片。书上第 684 页提到大规模图像重建，11.4.6 讲互联网照片重建，11.4.7 讲全局 SFM。全局方法的关键，是把相对旋转变成全局一致的旋转，再解位置。难点是噪声、外点、断开的子图。分布式方法则把大图切成小块，各自重建，再对齐合并。两条路的共同目标都是：别让误差随图像数量越滚越大。后面会讲万张乱序照片怎么建模。

书上第 684 页说，11.5 讲实时的同时定位与建图，SLAM，它在移动过程中重建三维世界模型。SFM 可以离线慢慢算，SLAM 必须在线、实时，还要知道自己在哪里。典型 SLAM 分三层：前端跟踪相机，后端优化位姿和地图，回环检测把走过的路认出来，消掉累积漂移。视觉 SLAM 还会遇到纯旋转、快速运动、纹理缺失、动态物体。后面会讲 SLAM 的基本问题，再拆 ORB-SLAM 的三层结构。这一集先记住：SLAM 是 SFM 的实时版，但约束更强，容错更低。

我们用 200 个合成三维点、两个相机做三角化。近处平均视差 0.411，远处 0.134，深度越远，视差越小。基线 0.5 时，中位相对误差 0.0163；基线 2.0 时，降到 0.0046。把像素噪声从 0.002 加到 0.01，误差从 0.0046 涨到 0.0429。基线为零时，视差为零，深度没有定义。这组数把 SFM 的命门说清楚了：深度不是从单张图里看出来的，是从视差里算出来的。基线小、噪声大、匹配差，深度就会烂。所以工程上要选基线合适的图像对，要做亚像素匹配，要剔除外点。不是所有照片都适合做 SFM。

SFM 的失败模式很有规律。第一，视差太小：纯旋转、远距离、基线不足，深度病态。第二，匹配错：重复纹理、反光、动态物体，几何全歪。第三，退化运动：所有相机共线或共面，解不唯一。第四，漂移：增量式越走越偏，回环接不上。第五，尺度：单目 SFM 只能恢复到相似变换，绝对尺度得靠外部信息。工程上要监控重投影误差、track 长度、三角化角度、内点率。发现异常先回退，不要硬优化。书上第 684 页也说明，本章跳过三焦张量等更复杂的工具。遇到退化场景，基础工具不够，就要用额外约束。SFM 是一套带诊断的几何工程。

收束成三句话。SFM 从对应点同时估相机位姿和三维结构。深度靠视差，视差靠基线，三角化靠几何。束调整把所有参数一起优化，精度高，但怕错匹配和退化。下一集正式进双视图几何：对极约束、本质矩阵、基础矩阵。这一集是地图，下一集开始拆第一块内容。先把同一点在两张图里只能落在一条极线上的关系想明白，后面的八点法、位姿恢复、三角化才有根。下一集见。
