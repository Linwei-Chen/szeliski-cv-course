# E000 口播稿 · 人人都能学懂的计算机视觉（先导片）

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

一百三十六集，二十五个小时的成片，只为一个目标——把这本一千多页的《计算机视觉》巨著，掰开揉碎，讲给高中数学以上的每一个人听。不是科普，是力求把每一章的核心都讲透。

欢迎来到《计算机视觉通识》，我是你未来几个月的学习搭子。这一集是先导片，三分钟讲清楚：这门课讲什么、怎么讲、你能得到什么。

我们用的教材，是 Richard Szeliski 写的《Computer Vision: Algorithms and Applications》第二版，施普林格 2022 年出版，全书一千两百多页。作者先后在 DEC 剑桥研究院、微软研究院和 Facebook 主持计算机视觉研究，这本书也被全世界许多大学的视觉课程采用。

手机夜景模式把暗部擦亮、人脸识别一秒解锁、全景照片自动拼成——这些你每天都在用的功能，背后的核心原理大多能在这本书里找到对应的章节，比如夜景对应计算摄影，全景对应图像拼接。

课程里每个知识点都走三步：先用生活里的类比建立直觉，让你先「看见」它；再把公式一条条摆上桌面，不跳步、不糊弄；最后动手跑一遍真实代码，眼见为实。

数学底子薄也别慌。开课前八集是「数学工具箱」，向量、矩阵、梯度、概率、贝叶斯，要用什么补什么，随用随补，跟原书的附录 A、附录 B 正好对上。正课哪里卡住了，随时回工具箱回炉。

全书十四章，外加三个附录：从「图像怎么形成」出发，途经图像处理、深度学习与识别、特征与拼接、三维重建，一路走到基于图像的渲染。这张地图不是我们拍的脑袋，它来自作者自己给全书写的一张十三周课程表，我们把它展开成了一百三十六集。

每一集你都会拿到五样东西：可翻页的动画幻灯片、带书页出处的逐字口播稿、高清视频、能直接跑通的示例代码，还有课后习题的参考解答——原书没有公开的答案，我们一道一道写。我们自制的课件、代码和讲稿全部 GitHub 开源，免费、可纠错、持续更新。

你不需要科班出身：有高中数学底子，加上愿意敲点 Python，再配上随用随补的数学工具箱，就能跟上主线。我们对每一集的验收标准是：看完之后，你能把刚学的内容，讲明白给另一个人听。

开胃菜已经备好：数学工具箱第一集，和正课第一集「计算机视觉到底是什么、它为什么这么难」，都在资料包里。这两个问题想清楚了，后面的路会顺很多。
