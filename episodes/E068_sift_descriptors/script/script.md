# E068 口播稿 · SIFT Ⅱ：128 维描述子的构造、归一化与匹配

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

检测到关键点以后，下一步是匹配：判断不同图像里哪些特征来自同一个位置。书上第 434 页说，有些情形局部运动主要是平移，比如视频序列，或者已经校正过的立体像对。这时可以直接比较小块里的像素，用平方差之和，或者归一化互相关。检测负责找到点，描述子负责说出它长什么样。说不清楚，匹配就只能靠猜。描述子就是把这小块窗口压成一串能比较的数。这一步做不好，后面的匹配再精细也没用。

但大多数情况下，特征的局部外观会随方向和尺度改变，有时还会发生仿射形变。书上第 434 页说，通常更可取的做法，是先估计局部尺度、方向或者仿射坐标架，再用它重采样图块，然后才形成描述子。先把图块摆正、缩放好，再描述，比直接拿原始像素硬比要稳。这一步做得好，后面的距离比较才有意义，也决定描述子能不能跨视角对上。估计出来的坐标架，决定图块按什么角度和尺度展开。展开得准，后面比较的才是同一块表面。

即使补偿了这些变化，图像块的外观通常仍会逐图变化。书上第 434 页把问题说成两件事：让描述子对这些变化更不变，同时保留不同图块之间的可区分性。太不变，大家都长得一样；太敏感，同一个点又对不上。Mikolajczyk 与 Schmid 综述并实验比较了一批视角不变的局部描述子。好的描述子要认得出同一个人，也要分得开不同的人。这两个要求互相拉扯，设计描述子时要在中间取一个位置。偏向哪一边，都会损失另一边的性能。

书上第 435 页用图 7.15 说明多尺度定向图块：确定了局部尺度和方向以后，用八乘八的采样，采偏置和增益归一化后的强度值。采样间距是相对检测尺度的五个像素。这种低频采样让特征对兴趣点的定位误差更稳。这是最朴素的思路：先摆正，再粗粗采六十四个数。它适合图像拼接这类透视缩短不严重的任务。网格越粗，采到的数越少，细节也跟着变粗。优点是对小误差不敏感，缺点是分辨能力有限。

对透视缩短不严重的任务，比如图像拼接，简单的归一化强度图块表现不错，也容易实现。书上第 435 页说，为了补偿检测器在位置、方向、尺度上的小误差，多尺度定向图块用五个像素的间距采样，并取更粗的金字塔层来避免混叠。为了补偿线性的曝光变化，也就是偏置和增益，图块强度被重新缩放，使均值为零、方差为一。减均值、除标准差，就把整体变亮变暗、对比度变大变小先抹平。它只处理线性曝光变化，复杂的光度变化还要靠后面的归一化。这里默认曝光变化是线性的，非线性的变化不在这一步处理。所以后面的归一化还要再补一层保护。

SIFT 由 Lowe 提出。书上第 435 页说，做法是在关键点周围十六乘十六的窗口里，逐像素计算梯度。计算时使用关键点被检测到的那一层高斯金字塔。梯度幅值会被高斯衰减函数压低，越靠外权重越小，因为外围梯度更容易受小的配准误差影响。先只看每个像素的梯度朝哪、有多强，这是 SIFT 的原材料。窗口取多大、用哪一层，都是为了让描述子看到同一块物理表面。窗口越大，看到的上下文越多，混进其它结构的机会也越大。取多大，要和检测尺度配合。

每个四乘四的象限里，会形成一个梯度方向直方图，按高斯权重把梯度值加到八个方向桶之一。书上第 435 页说，为了减小位置和主方向估计误差的影响，原来的二百五十六个加权梯度幅值，会被软分配到相邻的二乘二乘二个直方图桶里。书上第 436 页说，这种分配用的是三线性插值。一票不投给一个桶，而按距离分给周围八个桶，轻微错位不会让描述子跳变。软分配的权重按距离算，离桶中心越近，分到的越多。这样直方图在相邻桶之间是连续的。

书上第 436 页的图 7.16 是 SIFT 的示意：左图算梯度方向和幅值，并用高斯衰减加权；右图在每个子区域里统计加权方向直方图，用三线性插值分配。图上画的是八乘八的图块和二乘二的描述子阵列，但 Lowe 的实际实现用十六乘十六的图块，和四乘四组八桶直方图。四乘四个格子，每格八个方向，正好一百二十八个数。示意图画小一点是为了看清结构，实际实现要密得多。示意图和实际实现不同，读数时要以实现参数为准。否则会把数出来的维数算错。

四乘四组八桶直方图，给出一百二十八个非负值，这是 SIFT 描述子向量的原始版本。书上第 436 页说，为了减小对比度或增益的影响，一百二十八维向量被归一化到单位长度；加性的变化已经被梯度消掉了。为了进一步抵抗其它光度变化，数值被截断到零点二，然后再次归一化到单位长度。先单位化，再截掉特别大的分量，再单位化一次。三步一起用，既压对比度，又防止少数大梯度独霸。零点二不是数学上唯一的选择，工程实现里也有别的截断值。归一化之后，向量只保留方向的相对分布，整体亮度不再影响距离。截断再压掉少数特别大的分量。

主成分分析版的 SIFT 由 Ke 与 Sukthankar 提出，是更简单的描述子算法，思路受 SIFT 启发。书上第 436 页说，它在三十九乘三十九的图块上计算水平和垂直方向的梯度导数，得到三千零四十二维向量。然后用主成分分析，把三千零四十二维降到三十六维。先老实算一大串，再用主成分挑出最有信息的那几个方向，换来更小的存储和更快的匹配。维度降下来，匹配更快，但也会丢掉一些细节，这是它的代价。维度越低，存储和距离计算越省，细节保留也越少。选多少维，要看任务能接受多大的损失。

SIFT 的另一个流行变体是 SURF，它用盒式滤波来近似 SIFT 里的导数和积分。RootSIFT 则观察到，只要把 SIFT 描述子按 L1 范数重新归一化，再对每个分量开平方，就能显著提升可区分性。书上第 436 页讲的就是这两个变体。SURF 换更快的算子，RootSIFT 几乎不改结构，只在归一化上做文章，代价很小。SURF 走速度路线，RootSIFT 走归一化路线。两者的改动都不大，原有的匹配流程可以继续用。想提速就看 SURF，想提升可区分性就看 RootSIFT。

GLOH 是 Mikolajczyk 与 Schmid 提出的 SIFT 变体。书上第 437 页说，它用对数极坐标分箱，替代 Lowe 用的四个象限。空间箱分布在半径零到六、六到十一、十一到十五的范围。除中心区域外有八个角向箱，总共十七个空间箱。GLOH 用十六个方向箱，而不是 SIFT 的八个；二百七十二维直方图再用主成分分析投影到一百二十八维。把方格换成同心圆加扇区，远处格子更大，统计更符合透视下的分布。半径按对数增长，近处格子细，远处格子粗。这样远处的大格子不会比近处的小格子还密。

书上第 437 页的图 7.17 说明 GLOH 用对数极坐标箱来计算方向直方图。每箱用十六个梯度方向，图上只画八个，是为了不显得拥挤。在 Mikolajczyk 与 Schmid 的评测里，GLOH 总体性能最好，比 SIFT 略胜一点。GLOH 更强但更复杂，SIFT 紧随其后，工程上常常还是选 SIFT。评测只是当年数据集上的结论，换任务换数据，排名可能变。所以论文里的排名，要结合自己的数据重新验证。评测用的是当年的数据和评价指标，换了条件，结论未必成立。工程选型还要自己复测。

可操控滤波器是高斯导数滤波器的组合，能快速计算任意方向上的奇对称和偶对称边缘、角点特征。书上第 437 页说，因为它们使用相当宽的高斯，对定位误差和方向误差也不太敏感。与其为每个方向单独算一遍，不如先算好几个基，再按方向调配出来。这和第 3 章的可操控滤波是同一套思想，只是用到了描述子上。基的个数固定，方向可以连续变化，所以算起来省。方向越多，组合的系数也越多。

在 Mikolajczyk 与 Schmid 比较的局部描述子里，GLOH 表现最好，SIFT 紧随其后。书上第 437 页说，他们也给出了书中没有展开的许多其它描述子的结果。没有一种描述子全面碾压；维数、归一化、不变性和速度，要按任务取舍。所以选描述子，先问任务最怕什么，再看哪个指标最要紧。选型先看数据，再看实现代价。能不能接受误差，比排名第几更实际。

这一节从为什么原始图块不够，讲到多尺度定向图块、SIFT、主成分版、SURF、RootSIFT、GLOH 和可操控滤波器。书上第 436 页说，SIFT 的核心是十六乘十六窗口、四乘四组八桶直方图、一百二十八维，以及单位化、零点二截断、再归一化。现在每个关键点都有了一串数，下一步就是拿这串数去匹配。下一集讲最朴素的阈值匹配，再讲更稳的比率测试、互检和几何校验。匹配这一半接着描述子那一半，后面几集都围绕它展开。先把这串数的构造记牢。
