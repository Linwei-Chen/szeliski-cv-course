# E127 口播稿 · 重建怎么算好坏：指标、基准与数据集

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集先问三个问题：数据从哪来，训练和测试怎么分，结果怎么报统计量。同一套算法，换一个数据集，换一种划分，冠军就可能换人。所以基准不只是排行榜，它是实验设计。上一集讲尺子，这一集讲拿尺子量谁、量几次、怎么报数。同一个模型，在室内数据上第一，换到室外可能就掉队。排行榜只告诉你谁在这张卷子上分高，不告诉你为什么。先把这三个问题问清，再看谁第一。数据集、协议、统计，这三件事缺一不可。

书上第 954 页说，可靠算法要在有挑战、有代表性的数据集上测；有真值或者别人的结果时，测试还能更定量。数据集不是一堆照片。它至少包含场景、标注、真值和划分四件事。同一批图，按场景分和按图片随机分，结论可能完全不同。比如测试图来自训练时见过的同一间屋子，模型只要记住屋子的纹理，就能拿高分。选数据集先问它代表什么，再问它怎么分。不然你测到的只是记忆，不是泛化。真值也可能有错，划分也可能不独立，这两件事都要单独检查。

书上第 954 页说，很多数据集自带 benchmark，能查到最新结果和代码。书里点名了 Middlebury、PASCAL、ImageNet、KITTI、Sintel、COCO。基准等于数据加协议加榜单。协议不只是数据集名字，还包括训练和测试怎么分、用什么指标、什么分辨率、结果怎么聚合。同一个数据集，换个划分、换个指标、换个分辨率，数字就不能直接比。先看协议，再看名次。协议不同的第一名，含金量不一样。协议里最容易被忽略的是聚合方式：先算每场景再平均，还是把所有像素混在一起。

书上第 960 页说，NYU3D 和 ScanNet 是早期室内三维数据集；新算法常用 3D Scenes、ICL-NUIM、ShapeNet、Tanks and Temples 的组合。书上第 958 页说，双目和多视图立体里，ETH3D 与 Tanks and Temples 有榜单，DTU 多是论文自报。室内、物体、场景、多视图，任务不同，数据集也不同。数据集带着采集方式和场景分布。换一批场景，就等于换了一道考题。别把室内结论直接搬到室外。同一个场景，换传感器、换光照，分布也不一样。

看图。同一批合成场景，随机划分的测试准确率是 1.000，按场景留出只有 0.500，差了 0.500。随机划分会把同一场景的纹理泄漏进测试集，分数虚高。按场景留出，才是看模型能不能迁移到新场景。这就像考试前把答案发给了同班同学。随机划分里，测试图和训练图来自同一间屋子，模型记住屋子就够了。按场景留出，测试场景真的没见过，成绩才可信。随机划分的高分，很多时候只是同一场景的复制。

书上第 954 页说，有真值或者别人的结果时，测试更定量。真值至少有四种来路：激光扫描、合成渲染、多视图重建、人工标注。每种都带着自己的误差和偏差。激光会有遮挡和孔洞，合成图往往太干净，多视图重建会继承匹配误差，人工标注受标注规范影响。所以真值不是天上掉下来的标准答案。先问真值怎么来、误差多大，再谈模型差几个点。真值误差要和模型误差分开报。真值错了，排行榜再漂亮也没用。

看图。方法 A 的平均分是 0.715，高于 B 的 0.700。可 B 的中位数和最差都是 0.700，A 只有 0.550。八个场景里，B 赢了五个。平均值会被三次大胜拉高，却掩盖五次失败。产品更怕最差场景，所以中位数、最差和置信区间都要报。一个班平均分高，不代表没有不及格的学生。A 的三次大胜把平均分抬到 B 之上，可它的五次失败才是用户实际会遇到的场景。平均值是摘要，不是全部。置信区间还提醒我们，这点差距可能只是噪声。

书上第 952 页说，高斯线性情形，协方差可以直接由噪声加权 Hessian 的逆算出；大问题可以只报方差或者单参数协方差。同一页还说，非线性或鲁棒问题，可以用局部 Hessian 给 Cramér–Rao 下界。Hessian 描述能量碗的弯曲程度，碗越陡，估计越稳。参数估计不是只给一个数，还要给一个范围。范围越宽，结论越虚。所以只报均值不够，要报不确定度。协方差矩阵太大时，至少要把关键参数的方差报出来。这也是摄影测量一直坚持的精度申报。

看图。五五配比时，B 是 0.775，A 是 0.750，B 赢。室内占到七成时，A 是 0.825，B 是 0.762，A 赢。翻转点在 57.1% 室内。同一对方法，测试集配比一变，冠军就换。所以读榜先问测试集代表谁，别把某个配比的第一名当成普遍真理。这不是模型变了，是考卷变了。数据配比就是考卷的组成。榜单往往不写测试集配比，这个信息得自己查。室内多考几道，A 就占便宜；室外多考几道，B 就翻上来。

读一张基准表，先问五个问题：任务是什么，训练和测试怎么划分，指标朝哪个方向，结果怎么聚合，代码和配置能不能复现。五个问题问完，再看排名。任务不同、划分不同、聚合不同，数字就不能放在一张桌上比。聚合尤其容易藏事。平均值、中位数、最差场景，可能讲出三个故事。复现还要看随机种子、超参数和预处理。代码和配置拿不到，这个第一名只能当传闻。先看考卷，再看分数；考卷不一样，分数没有可比性。

书上第 960 页说，很多算法在同一个数据集上训练和测试，换到别的数据集就掉；域适应可以缓解这个问题。常见的坑有五个：同场景泄漏、榜单过拟合、论文自报、硬件不同、只报平均。看榜要看跨数据集、看最差场景、看能不能复现。三样都过，再信这个第一名。不然第一名可能只是这张榜的熟人，换一张榜就现原形。硬件不同，速度和显存也不能直接横比。论文自报也要分清是引用原表，还是自己复跑。

这一集收成三件事。数据集要看代表性和真值；基准要看协议和划分；统计要报均值、中位数、最差和不确定度。下一集动手做一个迷你 NeRF 实验，把数据、训练和评测串起来，看看一个场景从照片到新视角，最少需要哪些环节。基准是实验设计，不是排名。先问怎么量，再问谁赢。数据集、协议、统计，三件事缺一不可。下一集我们把这三件事落到一个具体场景上。下一集见。
