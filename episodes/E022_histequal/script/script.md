# E022_histequal 口播稿 · 直方图均衡与 CLAHE：灰扑扑照片的救星

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集结尾留了个承诺：书上第 115 页的下一节讲直方图均衡，让直方图帮你自动定映射。这一集就来兑现。增益、偏置、伽马都要人来调，书上第 116 页给出一个热门的自动方案：从图像自己身上算出映射。

本集分三步。先讲全局直方图均衡，一条映射曲线管全图；再看它的两个毛病，发灰和噪声放大；最后升级到局部版本 AHE 和 CLAHE，把图切块各调各的。全程配数值实验，每个公式都实际算过。范围是书上第 115 到 119 页。

问题从哪来？书上第 115 页问：亮度、增益这些控制能让图像好看，可怎么自动定出最好的值？书上摆了两条路，从第 115 页到第 116 页：把最暗和最亮的像素拉到纯黑、纯白；或者把平均值推向中间灰，再把范围铺满可显示区间。这是书上给的两条启发式。

要检验这些直觉，先得看清图像的明暗分布。书上第 116 页说，把每个颜色通道和亮度值的直方图画出来，从分布里算最小值、最大值、平均强度。直方图就是每个灰度级上的像素计数，八位图要备一张 256 格的累积表。

书上第 116 页举了一个典型情况：图里暗值和亮值都过剩，中间灰度段却大片无人。书里接着问：能不能同时提亮一部分暗值、压暗一部分亮值，还把可用动态范围占满？你能想出这样的映射吗？答案在下一页。

书上第 116 到 117 页给出热门答案：直方图均衡。找一条强度映射 f(I)，让均衡后的直方图变平。变平的意思是每个灰度级上的像素数一样多。找法借了概率里的技巧：想从概率密度里采样，先算累积分布函数；把直方图逐级累加，就得到这条曲线。

书上第 117 页打了个比方，这个比方是书里的：把直方图想成一次考试后全班的分数分布。怎么把某个分数换成它的百分位？考到 75% 百分位的学生，成绩好过四分之三的同学。答案是把分布积分起来，得到累积分布。

式三点九：c(I) 等于第 0 级到第 I 级的直方图累加，再除以 N；也可以写成递推，本级累计等于上一级累计，加本级人数除以总像素。N 是像素数，也是比方里的全班人数。八位图时，I 和 c 都按 0 到 255 标度。查出百分位，就定下这个像素该变成的值。

把 c 当映射用，f(I)=c(I)，这就是全均衡。书上第 117 页说，均衡后的直方图确实平了。数值实验里，均匀输入下，被占用的灰度级计数只取 8 或 16 两档，这是查表取整留下的台阶，整体接近平坦。

但书上马上补了一句：图像也平了。这里的平是缺对比度、看着发灰的平，书上的用词是 flat、muddy looking。从映射曲线上看，扎堆的暗部被陡坡摊开，亮部也摊开，原本分得开的明暗两端都被拉向中间。

第二个代价：书上第 117 页提醒，直方图均衡这类增亮操作，会把暗区里的噪声放大，变得更显眼。数值实验里，给暗区加标准差 3 的噪声，过全均衡后输出差升到约 6.24，取 α=0.5 则约 4.60。在这个实验的分布下，暗区斜率 2.397 大于亮区 1.740，噪声跟着放大。

怎么补救？书上第 117 页说，只部分补偿直方图的不均，映射写成 f(I)=αc(I)+(1−α)I，也就是累积分布和恒等变换的线性混合。代入端点看：α 等于 0 就是原图，等于 1 就是全均衡，中间可以连续调。

效果方面，书上第 117 页说，部分均衡后的图像保住更多原始灰度分布，明暗更讨喜。数值实验里，α 取 0.5，输出逐点落在原图与全均衡之间，噪声放大也更轻。这个 αc+(1−α)I 和上一集的线性混合是同一种形式，只是换了用途。

有的图一条曲线不够。书上第 117 页说，对有些图，在不同区域用不同的均衡可能更好，书里举了一幅亮度范围特别宽的图。与其算一条曲线，不如把图切成 M 乘 M 的块，每块各做各的直方图均衡。

切了就出事。书上第 117 页说，块状均衡的结果出现大量块效应，也就是块边界上的亮度跳变。另一种办法是滑动窗口：每个像素都重算一遍以它为中心的 M 乘 M 直方图。效果好了，但很慢。朴素实现每像素 M 平方次运算，光栅扫描只更新进出块的像素，可以降到 M 次。

书上第 117 到 118 页给了更聪明的路：还是先算非重叠块各自的均衡函数，但在块与块之间对这些函数做平滑插值。每个像素的映射由邻近几块共同决定，边界上无缝过渡。这样既免了块效应，又不用逐像素重算直方图。这套技术就是 AHE 和 CLAHE。

正式命名：书上第 118 页，这套块间平滑插值叫自适应直方图均衡 AHE；它的限制对比度版本，也就是限制增益版本，叫 CLAHE，出自 Pizer 等人 1987 年的工作。名字里的 CL 就是对比度限制。书上脚注说，CLAHE 已经进了 OpenCV。

插值怎么做？书上第 118 页说，对块内位置为 s、t 的像素，四张查找表 f00 到 f11 按式三点一零混合。权重是 (1−s)(1−t)、s(1−t)、(1−s)t、st，四项加起来等于 1。四个角上还原各自的函数，权重随像素在块内的位置连续变化。

这张示意图里，图按虚线切成四块，蓝圆点是块中心的查找表，橙方块是角点变体的查找表位置，黑星是待处理的像素。像素离哪几张表近，就按远近比例混用哪几张。对照书上图三点九的两种布局，怎么实现得又快又省，下一页讲。

实现诀窍一：提速。书上第 118 页明说，逐个输出像素混四张查找表太慢，可以先让像素分别过四个相邻的查找表，再把四个结果混合。线性混合下，这两种做法逐点相等，数值实验也验证了。

诀窍二：换个布局。书上第 118 页的变体把查找表放在每个 M 乘 M 块的角点，对应图三点九的第二种布局。累积直方图时，每个像素的计数也按双线性权重拆给四个相邻顶点。一张表拿到的是一份，不再是非零即整票。

书上给这个计数分配起了名：式三点一一，软直方图。每个像素不再硬投一票给一个格子，而是按权重拆成几份，分给四个相邻查找表。书上说这招在别处也用：构建 SIFT 特征描述子和词汇树。这些在后面的课程会讲到。

收个小节。书上第 119 页三点一点五：点算子最广泛的应用之一，是照片的对比度与色调调整，让照片更好看，或者更好读。打开任何修图工具，调对比度、亮度、颜色，背后很多就是上一集和本集前半讲的点算子。

书上第 119 页点名三题：三点一、三点六、三点七，让你动手实现，后两题的题干在第 181 页。三点六做照片特效：对比度、solarization，书上括注是量化。三点七完整做一遍直方图均衡。选做小问有：把 5% 的像素压到纯黑纯白；限制映射增益。

本集小结。直方图均衡用累积分布函数自动定映射，就是考试百分位那一套。全均衡会发灰、放大暗区噪声，部分均衡用 α 混合来折中。切块的 AHE 加上对比度限制就是 CLAHE，块间双线性插值靠式三点一零，软直方图的技巧也用于构建 SIFT 描述子和词汇树。
