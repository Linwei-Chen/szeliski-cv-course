# E120 口播稿 · 从点云到表面：隐函数、泊松重建与 Marching Cubes

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集从一张已经配准好的点云出发，问一个问题：怎么把它变成表面。常见有三种存法。显式网格存三角面，点云存采样点，隐式场给每个位置存一个内外值。这三种表示对应三种不同的工程取舍。三维重建的终点，通常是一张能渲染、能测量、能进仿真器的表面，所以表示的选择会决定后面能做什么。这一集是第 13 章的第一集，后面两集讲融合和配准。网格适合直接渲染，点云适合直接采集，隐式场适合做查询和改拓扑。

看图。左图是三角网格，中图是表面采样点，右图是隐式场的切片。书上第 825 页说，显式表面包括三角网格、样条和细分曲面。书上第 826 页说，除了显式表示，还要看点表示和体表示。网格最像成品，点云最像原料，隐式场更像一个函数。成品好渲染，原料好采集，函数好改拓扑。左图每个三角面有顶点和连接关系。中图只有点，没有面。右图每个格点存一个数，红线是数值等于零的位置。三种图都是同一个球，方便只看数据结构的差别，不被形状干扰。看这三张图，先只看数据结构，不用管球是怎么来的。

书上第 827 页说，参数化和非参数化表面模型都假设拓扑已知而且固定。要更灵活，可以把表面表示成有向点集，或者用三维隐式函数。网格的顶点和面一旦定死，想让它长出新洞、合并两块、裂成两半，就得重新网格化。隐式场不用，因为表面只是零等值面，拓扑可以自己变。比如扫描一个人，手臂从贴腿到抬起，拓扑没变，但变形很大。如果两个物体粘在一起，拓扑就变了，网格要重新连。网格的优点是渲染成熟、文件格式多。缺点是拓扑固定，难处理大变形。所以选网格还是隐式场，先看任务需不需要改拓扑。

书上第 829 页说，点云转表面的一条路，是先把点云变成隐式符号距离或者内外函数。每个有向点给一个法向，点附近的正负号由法向决定。离表面越远，数值越大。点云本身没有里面，是法向把里面和外面分开。法向错了，隐式场就会漏气。符号距离的绝对值是到最近表面的距离，符号表示内外。如果只保留正负号，就得到 0/1 占据函数。点云转隐式时，法向估计是第一步。法向不准，符号距离在表面附近就会抖。符号距离和占据函数只差一个符号，用途不一样。

书上第 831 页说，隐式面用指示函数 F(x,y,z) 表示内外。F 小于 0 在里面，F 大于 0 在外面。表面就是 F 等于 0 的那层壳。找到这层壳，就找到了表面。一旦有了 F，查询任意点的内外、求梯度、提等值面，都是同一套数组操作。F 的梯度指向外法向。把梯度单位化，就得到法向场，这也是 Poisson 重建的输入。隐式场可以存在规则网格上，也可以存在八叉树上。远离表面的地方用大格子，能省内存。规则网格查起来简单，八叉树省内存，两者可以配合。

看图。左边是隐式场的二维切片，红线是零等值线。右边是三维网格的三角面数随分辨率变化。书上第 831 页说，在规则网格上存距离函数，查值快，也容易用 Marching Cubes 提等值面。Marching Cubes 逐个格子看八个角的正负，按查表把交点连成三角面。二维切片看四个角、连成线，三维看八个角、连成面。它的查表有 256 种角点正负组合，按对称性归并成 15 种基本情形。二维切片就是 marching squares。MC 的输出是顶点和三角面，可以直接进渲染器。但它不去噪，噪声会直接变成毛刺。每个格子只和相邻格子共享边界面，拼起来是连续的。

三档分辨率的结果是这样。N 等于 48 时，14492 个三角面，半径误差 0.000107。N 等于 64 时，25964 个面，误差 0.000060。N 等于 96 时，59036 个面，误差 0.000027。体积误差只有负 0.038%。等值面加 0.1，半径外移到 1.1000。分辨率越高，面越多，误差越小。但面数涨得比精度快，工程上要选合适档位。面数大约按 N 的平方涨，半径误差大约按格子边长线性降。所以要让误差减半，N 要加倍，面数约翻四倍。从 48 到 96，误差实际降到约四分之一，比线性预期还好，面数涨到约四倍。如果只做可视化，N 等于 48 就够。如果要量体积，N 等于 96 更稳。这就是工程取舍。

看图。左边是真值场，中间是带噪场，右边是 Poisson 恢复场。书上第 831 页说，Poisson 重建用的是一张平滑的 0/1 内外函数。在已知表面点附近，把梯度设成沿有向法向，其他位置设成 0，再用 B 样条八叉树表示。二维切片里，Poisson 恢复半径误差 0.000884，带噪场是 0.037731。Poisson 不是直接拟合点，它把法向当梯度，积分出一张更平滑的内外函数。方程左边是拉普拉斯，右边是法向场的散度。解完这张场，再提零等值面，就得到平滑表面。同样的两个数，带噪场是恢复场的四十多倍。Poisson 的优点是全局平滑，小噪声会被压下去。缺点是尖锐边会被抹圆，除非加约束。二维切片和三维重建解的是同一个方程，只是维度不同。

实验里把边界全设成零，零等值线变成 0 条。把一半法向翻转，零等值线也变成 0 条。Poisson 方程并不能自动纠错。边界条件和法向朝向错了，积分出来的场就没有正确的零等值面。法向必须一致朝外，边界必须给可信值。这两件事比解方程本身更容易出错。真实系统还要先做法向一致化、边界补洞、离群点剔除。这些预处理不做，解方程只会把错误抹匀。两个失败对照说明，输入比求解器更关键。所以实际流程是：估法向、统一定向、补边界、解方程、提等值面，一步都不能省。

书上第 832 页说，深度网络已经开始用于体表示的构造和建模。书上第 833 页说，NeRF 把像素射线方向也作为输入，输出连续的透明度和辐射值。神经隐式场把查表换成问网络，但问的还是同一个问题：这个点的内外和颜色是什么。NeRF 是第 13 章末尾的延伸，不是这一集的正文。这一集只把隐式场和 Marching Cubes 讲透，神经场留给后面的课。DeepSDF 学符号距离，Occupancy Networks 学 0/1 占据，NeRF 学透明度和颜色。它们都把几何换成网络查询。神经隐式可以用单图或稀疏视角补全，但训练、泛化和实时性是另一门课，这一集不跑网络。原书在第 832 到 833 页只给了一段概述，没有展开训练细节，这一集也停在概念层。

要渲染和碰撞检测，网格最直接。要采集和编辑，点云最灵活。要改拓扑、去噪、做融合，隐式和体表示更顺手。没有一种表示能通吃。工程上经常是点云进来，隐式场中间处理，最后提成网格交付。三条路线可以接在一条流程里，各自负责一段。选表示还要看内存、渲染速度、可编辑性和后续融合。没有绝对最优，只有和任务匹配。深度图进来，TSDF 是最自然的体表示。扫描点云进来，Poisson 更常见。网格负责最后交付。选网格看渲染和碰撞，选点云看采集和编辑，选隐式看拓扑变化和去噪。三条路线可以串起来。

这一集的主线是：点云先变成隐式场，再由 Marching Cubes 提成网格。Poisson 给了另一条路，从法向积分出内外函数。下一集讲深度图融合与 TSDF，看 KinectFusion 怎么把一帧帧深度图叠成一个体。再下一集讲 ICP，把多视角点云先配准。配准和融合不进这一集，这一集只负责从点到面。记住三件事：点是原料，隐式场是中间表示，网格是交付物。融合和配准都是为这三件事服务。第 13 章的主线是采集、配准、融合、表面，这一集完成最后一步的第一半。先把从点到面走通，后面再处理多帧融合和多视角配准。
