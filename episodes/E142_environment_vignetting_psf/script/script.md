# E142 口播稿 · 环境蒙版、暗角与 PSF：透明、变暗与变糊

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集补两个容易被跳过的物理层。一个是环境蒙版，讲透明或反光物体怎样把背景折射进自己的像素。另一个是相机的暗角和 PSF，讲镜头怎样把画面边角压暗、把边缘糊开。书上第 883 页说，环境蒙版不是简单抠图，它建模每个像素怎样折射或反射环境光。书上第 615 页说，广角或大光圈镜头会让画面角落变暗，这叫暗角。书上第 616 页说，成像系统的空间响应函数就是卷积核，也就是 PSF。一个在物体侧，一个在相机侧，两边都在问同一个问题：这个像素的颜色到底从哪来。普通抠图只管把人贴到新背景上，环境蒙版还要管玻璃杯后面的背景被弯成什么样。暗角和 PSF 是相机自己给每个像素加的衰减和模糊。一个改变亮度，一个改变清晰度，都可以用少数几个参数描述。两个主题都在追问像素颜色的来源。

书上第 883 页说，把透明物体放到新背景前，不能只抠颜色，要建模每个像素从环境哪个方向取光。这个四维映射把像素坐标映到方向，整体是六维表示。Zongker 等人把它叫 environment matte，因为它把 object matting 从剪贴推广到连折射、反射一起搬走。普通抠图只带走颜色和透明度，环境蒙版还带走这个像素后面藏着哪一块背景。它多出来的是一张取色表。每个像素都记着去环境的哪个方向取光、取多少。普通 matte 只有 alpha 和 F 两个量，环境蒙版多出方向和强度，所以能表现玻璃后面的背景被放大、翻转或扭曲。environment 指的就是这块外部背景。

书上第 884 页说，普通合成是 C 等于 alpha 乘 F 加 1 减 alpha 乘 B。环境蒙版再加一个间接项 I，等于 R 乘 A 区域上 B 的积分。更复杂的版本用多个有向高斯叠加，每个高斯有中心、宽度和方向。alpha 管盖住多少，F 管物体自身颜色，R 和 A 管背景从哪里来、来多少。可以把它想成给每个像素配一张小表，告诉它去背景的哪个位置取色。alpha 是门开多大，F 是门后物体的颜色，R 和 A 是背景从哪扇窗进来。有向高斯比矩形支持区更灵活，因为它还能描述光从哪个方向来。

书上第 885 页说，把物体放在显示器前，换不同图案。纯色背景估 alpha 和 F，横竖条纹估支持区，四个方向的高斯条纹估多个高斯响应。采完以后换一张新背景，就能把物体放进去。同一页还提醒，多背景方法不能处理动态场景，比如水倒进杯子。这时用单张渐变背景估一个二维位移。环境蒙版是拍一套图案、解一组参数、换背景重渲染。图案越多、方向越全，解出来的取色表越细，但采集也越慢。纯色背景那一步其实是在解一个逐像素的线性方程组，三个颜色就够把 alpha 和 F 分开。

看图一。实验用 160×160 的合成折射物体，放在 4 个方向、3 个相位的条纹前。纯色背景估出 alpha，误差 1.79e−17。每个像素在正负 14 像素里搜位移，平均误差 1.901 像素。折射权重平均误差 0.0291。换到新背景，环境蒙版重渲染 PSNR 是 57.52 分贝，不做折射的朴素抠图只有 38.29 分贝，差 19.23 分贝。多出来的这层背景从哪来，就是环境蒙版的价值。朴素抠图只把物体贴上去，玻璃后面的背景不会跟着弯。

书上第 885 页说，环境蒙版原理上是六维表示。如果要覆盖所有视点，需要 8D 映射。用 4D BRDF 可以降回 6D，但会丢掉多重折射。再加时间、再加波长，维度还会涨。每多一个自由度，采集和存储都更贵，所以实际系统只参数化十几个数，不存完整函数。实际系统只保留少量参数，抓住主要效果。本集 lab 每像素只用一个位移加一个折射权重，是环境蒙版的极简版，不是完整的多高斯模型。真实玻璃可能一个像素有多条折射路径，单一移不够。这也是后面的章节要用多个有向高斯叠加的原因。

书上第 615 页说，广角、大光圈镜头容易让角落变暗，这叫暗角。暗角分自然、光学、机械三类。最准的标定是积分球或均匀白墙，也可以拼全景，把每张图的中心当作真实辐射。只有单图时，可以找径向缓慢变化，或者看径向梯度的不对称。同一页还提醒，不建模暗角，梯度域融合也拼不出好看的全景。暗角是一个只跟半径有关的乘法衰减，先估出来，再逐像素除回去。它和内容无关，所以白墙能当体检表。自然暗角来自光路几何，光学暗角来自光圈遮挡，机械暗角来自遮光罩或镜筒。三类叠在一起，最后看到的还是一条径向曲线。

看图二。实验用 200×280 的合成图，角落亮度只有中心的 0.450。用均匀白墙按半径分箱，拟合 1 减 a r 平方减 b r 四次方。径向 profile 的 RMSE 是 0.00035。校正后 PSNR 从 18.34 分贝升到 69.73 分贝，提升 51.39 分贝，角落亮度回到接近中心。暗角像给照片加了一个圆形渐暗滤镜。知道滤镜长什么样，就能反向除回去。但如果角落已经压到接近 0，除回去只会把噪声放大。所以拍摄时别让边角欠曝太多。这也是 HDR 拍摄要改快门、不轻易改光圈的原因之一。

书上第 616 页说，空间响应函数是成像系统最后要标定的特性，它把光学模糊卷积进图像。这个卷积核就是 PSF。它受镜头模糊、径向畸变、抗混叠滤波、像素形状影响。标定时用长直线或条，最好用略倾斜的边。边可以估到亚像素，所以 PSF 也能到亚像素。斜边法先得到一维 LSF，再转成 MTF。但计算摄影更愿意直接估完整的二维 PSF。书上第 618 页说，把观测写成 B 等于 D 乘 I 卷积 K，解一个大型线性最小二乘，就得到 K。核估得准，后面的去模糊才有依据。斜边法只要一条边，但要求边足够长、足够直，方向也要覆盖水平、垂直和对角。如果只有一条水平边，就只能恢复水平方向的投影，恢复不了完整二维核。这也是计算摄影更愿意直接估二维核的原因。

看图三。实验用 96×96 的斜边靶标，真 PSF 是 7×7 的各向异性高斯。用最小二乘估出的核和真核相关 0.966，核 MSE 是 0.000132，核和归一化到 1。模糊把边缘梯度从 0.343 压到 0.232。用估出的核做 Richardson–Lucy 去卷积，梯度回到 0.514。去卷积不保证 PSNR 提升，它只是把边缘变陡，振铃也会被放大。PSF 估得准，去模糊才有依据。核错了，去卷积只会放大振铃。所以先看核的相关性和形状，再看去模糊图好不好看。

这一集的三个实验都是合成的。环境蒙版每像素只有一个位移和一个折射权重，不是多高斯混合，也没有做真实显示器采集。暗角用均匀白墙，不是单图盲估。PSF 用已知斜边靶标，不是无靶标盲估。去卷积用 Richardson–Lucy，不是教材里的全部去模糊方法。还要更正一个课程清单的笔误。按教材目录，暗角是第 10 章的 10.1.3 节，PSF 是 10.1.4 节，不是 10.1.2 节。这三个量都是先标定、再补偿的乘性或卷积模型。合成数据只能证明管线通，不证明真实相机也这么干净。真实相机还有噪声、滚动快门、色差、非均匀照明，任何一个都会让标定变难。真实项目里还要拍多张、换曝光、做平均，才能把噪声和标定误差分开。所以真实流程要先线性化、去噪、配准，再谈估参数。这些差异不会因为换一种算法就消失。

这一集把环境蒙版、暗角、PSF 三条线走完了。环境蒙版回答透明物体的像素从背景哪里取色，暗角回答角落为什么变暗，PSF 回答边缘为什么变糊。一个是物体的折射，一个是镜头的衰减，一个是镜头的模糊。三件事都可以先测量，再反着补回去。顺序上先修暗角和 PSF，再修物体，最后谈环境蒙版的合成，画面会干净很多。这三件事的共同思路，是把相机和物体的物理效应显式写出来，而不是靠后期调色硬压。先物理、后审美，画面才稳。留一个练习：拍一张均匀白墙估暗角，再拍一张斜边靶标估 PSF。把估出的暗角和 PSF 用在同一张照片上，看边角和边缘各改善多少。记录校正前后的角落亮度和边缘梯度，别只看肉眼。下一集讲三焦张量和完整自标定，把多视图几何的高级部分收尾。
