# E107 口播稿 · 全局 SFM：先对齐旋转，再一次性解相机

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集讲全局 SFM。上一集的增量式是一台相机一台相机地加，精度好，但越到后面越慢，因为每加一批，就要解一个越来越大的优化问题。书上第 728 页说，另一条路是等特征对应都建立好之后，把所有结构和运动的未知量放在一个全局步骤里一起解。这样做的误差不按拍摄顺序累积，适合上万张、顺序打乱的照片集；代价是前期匹配和相对旋转要算全，内存也大。它先把相机之间的相对关系算全，再一次性对齐，不追求边建边看。它和增量式解决的是同一个问题，只是求解顺序不同。

书上第 729 页把流程说得很清楚：先用两两欧氏重建起步，得到相对旋转和相对平移方向；再做全局一致的朝向估计，也就是旋转平均；最后把局部平移旋转到全局坐标系，缩放之后定出相机位置。实际管线可以记成四步：两两重建、旋转平均、中心求解，最后可选一次全局 BA 精化。两两重建只要求两张图之间有足够匹配，不要求全局尺度。旋转平均负责朝向，中心求解负责位置。顺序不能反。先转，后平移；旋转错了，中心怎么解都歪。

书上第 729 页说，两两相对旋转估出来以后，用旋转平均求每台相机的全局朝向。每台相机有很多条来自邻居的姿态候选，加权求和之后做 SVD，投影回最近的旋转，这是内层平均。鲁棒平均再按残差降权，外迭代几轮。候选越多，平均通常越稳，但错的候选也会一起进来。难点是外点：一条错的相对旋转就能把平均拉偏。工程上给残差大的边降权；也可以用灭点、重力方向或者 IMU 提供绝对朝向，消掉旋转漂移。还有一点，旋转矩阵不是向量，不能直接做算术平均。

书上第 730 页给出中心关系：c_j 减 c_i 等于 s_ij 乘 t_ij。t_ij 是经过全局旋转的单位平移方向，s_ij 是这条边的尺度。也可以写成 t_ij 叉乘 c_j 减 c_i 等于零，只解相机位置。每条边只告诉我们往哪个方向走，不告诉我们走多远，所以尺度 s_ij 也是未知量。把所有边堆成一个线性最小二乘，固定一台相机消掉平移规范，再固定一条边的尺度消掉尺度规范，就能解。这套方程是线性的，可以一次求解；难的是变量多，还要选好规范。实验里把第一条边的尺度设成真值，只为了和真值同尺度比较；真实系统里这个尺度未知，结果只能定到相似变换。书上第 729 页说，机器人社区把这一步叫位姿图优化；方程是线性的，但尺度变量多，稀疏求解很关键。

书上第 730 页提醒两件事。第一，这些方程最小化的是代数对齐，不会正确加权不同基线的重建。第二，共线相机更麻烦：所有相机在一条直线上时，可以沿着这条线滑动，仍然满足方向约束。原因是每条边只约束方向；共线时方向几乎一样，尺度又能自由调，位置就滑动了。诊断要看线性系统的条件数，看相机中心是不是近似一条线，看边尺度是不是互相矛盾。近似共线也会让条件数变坏。数学上这是秩亏：沿线的绝对位置不可观测，条件数变大只是数值表现。工程上用共享相机的相对尺度、广角、多方向基线来打破退化。这些诊断都不需要真值，只用方程和边图就能做。

全局 SFM 适合并行和分布式。图像对匹配可以按图像分块；旋转平均可以按图分区，先解局部再合并；中心求解是稀疏线性系统，可以分块解，也可以迭代解。大规模系统通常把任务拆到多台机器，最后只交换相机姿态和边。书上第 730 页列了两个带全局技术的开源管线：Theia 和 OpenMVG。分块也有代价：边界会产生不一致，合并时要再做一次全局对齐；边太多，通信和存储会成为瓶颈。分块边界最好有重叠，合并后至少再做一次全局对齐，让结果回到整体一致。好处是内存和计算可以摊到多台机器上。

先看合成实验。12 台相机、30 条边，其中 2 条是外点；相对旋转噪声 0.5 度。普通旋转平均的中位误差 13.93 度，最大 24.46 度。换成鲁棒平均，中位降到 0.84 度，最大 1.39 度。普通平均把每条边都当真，两条错边就能把全局朝向拉偏十几度；鲁棒平均按残差降权，错边的话语权越来越小。中位误差看整体，最大误差看最坏的那台相机。鲁棒平均也有边界：初始化太差、外点太多，迭代会掉进局部极小。这个实验只说明在这组合成数据上鲁棒权重有效，不代表所有真实数据都这样。

再看中心求解。圆环相机上，中位误差 0.162，最大 0.238；换成共线相机，中位误差涨到 2.61，最大 5.61，条件数从 114 涨到 615。两组用同一条边图、0.5 度方向噪声；第一条边尺度固定为真值，只为了同尺度比较。圆环有不同方向的基线，方向约束互相咬住；共线时边几乎平行，位置可以滑动，条件数变大，误差放大。条件数大，说明方向约束对位置的控制很弱。两组实验的区别只在相机中心怎么摆。全局 SFM 的精度不只取决于算法，还取决于相机的几何配置。

全局 SFM 的失败边界可以列成几条。相对旋转外点多，旋转平均被拉偏；边图不连通，有相机孤岛；共线或近似共线，中心滑动；基线差异大，代数解没有加权；尺度约束不足，整体缩放飘；纯旋转，平移方向没有信息。落地前做几项检查：边图连通而且有冗余，旋转残差分布正常，中心条件数可控，共线比例不高，最好和增量式或者已知 GPS 对照。全局式快，误差不按顺序累积，但对相对旋转的质量非常敏感；增量式慢，会漂，局部更稳。边图有孤岛，先补匹配，或者分连通分量重建，再合并结果。选型看数据规模和几何质量。

把这一集收成三件事。全局 SFM 先用两两重建和旋转平均定全局朝向，再解相机中心和边尺度，最后做全局 BA。旋转平均要鲁棒，中心求解要固定规范、警惕共线。它适合大规模乱序照片，但依赖高质量的相对旋转和连通的边图。下一集讲 SLAM：机器人一边走一边定位，一边建图。和 SFM 的区别是在线、有先后、要闭环；这一集是离线把照片摆好，SLAM 还要处理时间顺序和回环检测，随时修正走过的路。地图会随时间增长，还要判断旧地图是否仍然一致。下一集见。
