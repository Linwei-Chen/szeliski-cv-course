# E023_linfilter 口播稿 · 线性滤波与卷积：均值、锐化与找边

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集讲直方图均衡，那是逐像素改自己的值。这一集换一种做法，看邻居再定。书上第 119 页开篇就拿局部自适应直方图均衡当例子，说它是一个邻域算子：用一片邻域的像素值，共同决定一个输出。邻域算子可以做柔化模糊、锐化细节、强化边缘，也能去除噪声。

这一集走三段。先讲卷积机制，包括相关、卷积和冲激响应。再看边界，六种补全模式和归一化补零。最后过常用核，从均值到锐化。范围是书上第 119 到 127 页。夹在中间的可分离滤波小节，留到下集细讲。

最常用的一类邻域算子是线性滤波。输出像素的值，等于小邻域内像素值的加权和，书上写作式 3.12。权重表叫核，也叫掩模，里面的系数叫滤波系数。这个加权求和运算记作 f 圈乘 h，名字叫相关。相关把核直接滑过图像，不翻转。

书上第 120 页图 3.10 给了一个手算算例。八乘八的图，配一个九宫格核，周围权重 0.1，中心 0.2。核每停一处，九个像素加权求和，得到一个输出，最后输出六乘六。浅蓝格子是源邻域，浅绿格子是当前输出位置。

接着看卷积。式 3.13 是相关的紧凑记法。式 3.14 把输入的偏移符号反过来，式 3.15 把这个运算叫卷积，记作 f 星 h。两者的差别是卷积先把核旋转 180 度。核对称时，相关和卷积结果一样；核不对称时，差别马上出现。

为什么卷积要翻转？书上第 120 页说，全黑图上只亮一个点的冲激信号，卷积之后，核原样放回来，所以核又叫冲激响应。换成相关，放回来的是镜像。书上的括号请读者自己验证，我们真做了：非对称核下，卷积与相关的输出最大差 0.1200，正好等于核与镜像的最大差。

书上第 121 页图 3.11 排了八宫格：原图、模糊、锐化、保边平滑、二值化、膨胀、距离变换、连通域。模糊和锐化是线性滤波的样本。保边平滑和后四格属于非线性。书上预告第 3.3 节会讲形态学滤波和距离变换。

线性滤波有两条基本性质。叠加原理是式 3.16：先相加再滤波，等于分别滤波再相加。平移不变是式 3.17：信号平移，输出跟着平移。书上用 behaves the same everywhere 来说这件事，意思是算子处处行为相同。实验里叠加最大差 2.22e-16，平移最大差 0.00e+00。

有时核会随位置变化，式 3.18 是移变版本。书上举的例子是随景深变化的散焦模糊。多数时候核固定，卷积可以写成矩阵乘法：图像拉直成向量，g 等于 H 乘 f，式 3.19，H 是稀疏矩阵。实验里 8×10 的 H，每行恰好三个非零元，Hf 与直接卷积最大差 0.00e+00。

核滑到图像边缘会伸出图外。书上第 123 页提醒，图 3.10 的相关输出比原图小一圈，这就是边界效应。脚注 6 还提到，早期卷积网络 LeNet 反而采用了这种缩一圈的结构。

补救办法是补全。书上第 123 到 124 页列了六种：补零、补常数、复制边缘、环形绕回、镜像翻转、外插延伸。图形学文献把这类机制叫 wrapping mode 或 texture addressing mode。六种模式的公式，书上留作习题 3.9，我们的实验已经全部实现。

补完之后再模糊，书上第 124 页有四条结论。补零把边缘拉暗，复制把边界值向内传播，镜像保住边缘附近的颜色，外插让边界像素保持不动。实测都对得上。均匀图上补零后边缘环 61.11，镜像和复制保持 100。亮框图上补零 90.0，镜像 135.6，复制 160.0。外插的角点保持差 5.55e-17。

还有归一化补零。给图像配一层透明度，补零后连 alpha 一起模糊，再逐像素除以 alpha。等权方块核下，这等于只对图内像素取平均。亮框图角点得到 160.0，边中得到 140.0。暗角消失，书上的评语是效果可以相当好。

下面看常用核。最简单的滤波是滑动平均，也叫方块核：K 乘 K 窗口取平均。书上说，这等价于用全一核卷积再缩放。图 3.14a 的五乘五方块核，每个系数就是二十五分之一。

核很大时可以提速。沿扫描线滑窗，维护一个运行和，每步加最新像素、减最旧像素。书上说这跟求和面积表是一家人，稍后细讲。实验对账：K 等于 15 时，直接法每像素 225 次乘加，滑窗每趟只要 2 次加减。两种算法最大差 1.11e-16；二维两趟最大差 2.78e-16。

要更平滑，可以换帐篷核。它是分段线性的三角帽，学名 Bartlett 滤波。三乘三版本叫双线性核，由两个小三角帽相乘铺成，图 3.14b。实验核过账：外积合成与标准双线性核逐位相同；帐篷卷帐篷，得到 [1,4,6,4,1] 除以 16，书上叫它「高斯」核，图 3.14c。

这个带引号的「高斯」是三次曲线凑出的近似，拉普拉斯金字塔拿它打底。近似高斯也可以用方块核反复卷积得到。真要旋转对称，得用仔细采样的高斯，习题 3.11。它们都是低通核：放行低频，衰减高频。频率响应到第 3.4 节用傅里叶再算。

平滑核还能反着用，拿来锐化，学名叫非锐化掩模。书上第 126 页说，模糊削弱的是高频；把原图减模糊图的差补回去，图像就变锐。式 3.22 写成 gsharp 等于 f 加 γ 倍的原图减模糊图。第七集预习过这个式子，这一集落定页码。

书上第 126 页讲了段暗房往事。数字摄影之前，这是标准锐化手法：把底片失焦翻印出一张模糊的正片负片，两张叠在一起印相。书上说这对应式 3.23：g 等于 f 乘以 1 减 γ 倍模糊图。负片叠印就是透射率相乘。书上收尾说，这不再是线性滤波，但依然好用。

实验把两种锐化都算了。线性版叠加最大差 4.44e-16；γ 从 0 到 1，边缘强度从 1.1360 升到 1.9768，提升 1.74 倍，强度按 Sobel 梯度平均幅值算。暗房版违反叠加，违反量 0.7569。本集 γ 取 1 时，暗房版输出最小 0.0001，线性版最小 −0.6012。

线性滤波还是边缘检测的前处理。图 3.14d 的 Sobel 算子，书上拆成竖直方向的帐篷核，乘水平方向的中心差分。中心差分这个名字，来自导数正好落在像素中心。书上说它有效强调竖直边。实测用书上核系数、不归一化：竖直边响应 4.00，水平边 0.00。

图 3.14e 是简单的角点核，找横竖二阶差分同时出现的位置。二阶差分说的是斜率的变化。实测角点响应 1.00，轴对齐直边 0.00，对角边反而 3.00。书上提醒它对对角边也响应，和实验一致。更好的角点检测器，书上指向第 7.1 节。

收一下。相关不翻转，卷积先翻转，冲激信号一验就知道。六种补全：补零变暗、复制内传、镜像保色、外插定住。方块核可以滑窗提速，帐篷卷帐篷得到近似高斯。锐化有两条路，线性补高频，暗房乘透射率。Sobel 找边，角点核初瞥。全部落在书上第 119 到 127 页。

第七集留过一条线索：卷积是加权平均的数学化。前面几集讲信息加权，这一集讲空间加权，形式都是加权和。邻域权重怎么设计，决定了图像里什么被保留、什么被抹平。
