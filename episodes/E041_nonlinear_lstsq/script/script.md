# E041 口播稿 · 非线性最小二乘：泰勒展开 + LM 算法手推骨架

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集给答案配了误差棒，用协方差说明结果有多确定。那一集的整套计算，前提是线性最小二乘，正规方程一次解完。这一集把这条迭代路线走一遍。书上第 945 页说，测量变成非线性的时候，整个方程组只能用非线性最小二乘，迭代着解，原书把细节指向附录 A.3。这一集就拆这句话：非线性卡在哪，迭代具体怎么走。书上第 930 页说，很多视觉问题，比如运动恢复结构，最小二乘里的函数对未知参数不是线性的，这叫非线性最小二乘，也叫非线性回归。常见的解法是围着当前估计，用导数也就是雅可比重新线性化，算出一个增量。所以非线性问题没有一次解完的办法，只能估一步、修正一步，反复迭代到收敛。

书上第 930 页给出两个式子。A.45 是能量：每个测量算出来的值，减去实际测到的值，平方，再对所有测量加起来。A.46 对增量做一阶泰勒展开：在当前参数附近，把非线性函数当成线性的，函数的增量近似等于雅可比乘参数增量。代进能量，就得到近似能量：雅可比乘增量，减去残差向量，平方，再求和。A.45 就是线性最小二乘能量的非线性版本。对增量展开这一步，是后面所有推导的起点。好比站在山坡的某一点，只看脚下很小的一块，把弯坡当成直坡；直坡怎么往下走，线性最小二乘已经会了。

书上第 931 页说，在这组近似出来的方程里，雅可比和残差扮演的角色，跟正规方程里的测量行和测量值一样。换成直白的话：雅可比接测量行的班，残差接测量值的班，正规方程的壳子没变，左边矩阵、右边向量，解一个增量。变的只有一件事：线性问题方程拼一次就结束；非线性每走一步，都要站在新参数上重新算雅可比、重新算残差、重新拼方程、重新解增量。这就是迭代重线性化的意思。书上同一页提醒，这个近似只在局部极小附近、或者增量很小的时候成立。

近似只在局部成立，所以参数直接加上增量，不一定让平方和残差下降。书上第 931 页说，有时候按公式走一大步，能量反而升高。切平面说往这边走会更好，真实地形是弯的，走过去可能更糟。实验里会看到，一步跨出去，能量涨了十一个数量级。那怎么办？原书给了两条路。第一条，步子迈小一点，别一次走完。第二条，给方程加阻尼，让步子自己变小。两条补救都写在原书同一页，先看第一条。

书上第 931 页讲第一条补救：步子迈小。参数更新写成当前参数加上一个系数乘增量，系数在零和一之间。定这个系数的简单做法，是从一开始试，然后一次一次减半，这叫一种简单形式的线搜索。不行就减半，再不行再减半，直到能量真的下降。优点是简单；缺点是费，地形越坏，要减的次数越多，每试一次都要重新算能量。原书紧接着给了第二条路：阻尼。

书上第 931 页说，另一条保证下坡的办法，是给近似海塞加一个对角阻尼项。近似海塞就是雅可比的转置乘雅可比，对所有测量求和。加了阻尼以后，要求解的方程变成：近似海塞，加上阻尼系数乘近似海塞的对角线，解出的增量，等于雅可比的转置乘残差再求和。这套做法叫阻尼高斯-牛顿法。在线性情形里，近似海塞就是测量矩阵转置乘测量矩阵。阻尼项加在矩阵对角线上，阻尼越大，解出来的步子越小。阻尼系数是零，就回到原来的高斯-牛顿；系数拉大，步子更谨慎，泰勒近似反而更准。

书上第 931 页讲阻尼系数怎么调。判据看下降：如果残差平方的下降没有预期那么快，就把阻尼系数调大；如果预期的下降拿到了，就调小。这里说的预期，是泰勒近似 A.46 事先算出来的数。一阶泰勒近似加自适应阻尼，这套组合通常叫列文伯格-马夸特算法。原书括注引了一九四四年和一九六三年两篇文献，还说它是更一般的信任域方法的一个例子。信任域方法的意思是，每一步只在泰勒近似可信的小范围里找解，阻尼系数控制每一步敢走多大。今天工程里解非线性最小二乘，它常常是默认的第一选择。

下面动手验证。两个实验场。第一个是前几集那条直线，十六个真内点，老配方。这次把直线换一种写法：不用斜率，改用倾角，斜率等于倾角的正切，模型对倾角就不再线性。要注意，这是同一个拟合问题换写法，答案不该变，线性最小二乘一次解出的解就是标准答案。第二个实验场是圆拟合：十二个点落在一段圆弧上，残差是每个点到圆心的距离减半径。这个模型对圆心非线性，半径那一项是线性的，而且远起点加很强的非线性，正好用来验证原书那两句警告。先看这张等高线图：横轴倾角，纵轴截距，颜色越亮能量越低；黑虚线是高斯-牛顿轨迹，红实线是列文伯格-马夸特轨迹。两条轨迹分别由这两种方法生成，星星是线性最小二乘的解。直线的失灵和会师，都在这两条轨迹上。

先看失灵，两个形态。形态一，从远处起点看直线问题。泰勒近似把弯坡全当成直坡，预测走完这一步，能量直接落到谷底，只剩零点三左右。结构上的原因是：直线问题换成倾角写法后，雅可比的两列，一列正比于横坐标，一列是常数，张成的方向和斜率截距写法一样，所以预测永远一步落到线性最小二乘的能量。真实走完这一步，能量从六百九十四降到五十八点五，降了一大截，但跟预测的零点三比，剩余能量被低估了一百九十多倍。形态二，圆拟合从远处起点跑高斯-牛顿。前三步能量确实在降，但参数已经被甩到几十万的量级，圆被拉成近乎直线；第四步，高斯-牛顿的预测仍然说会下降，真实结果能量爆涨了十一个数量级。原书的警告，在实验里就是这样出现的。高斯-牛顿也没有停：三十轮里十二次能量上升，三十轮跑完，还停在一个完全不对的地方。

就在爆涨那一步的位置上，两条补救同台比较。图里红线是实测能量，蓝虚线是泰勒预测，灰点线是当前能量；预测一路说降，实测步步暴涨。第一条，步长减半：从全步开始试，一次一次减半，减了十八次，系数缩到百万分之几，才找到第一个下降步。这个位置上，高斯-牛顿解出的全步长度有六十四万；减了十八次，实际走下来只有二点四。能救，但每试一次都要重新算能量，试错成本很高。第二条，阻尼：同一个位置，往近似海塞的对角线上加一点阻尼，解出的增量长度只有零点七，一步就稳稳下降。两条路都要重新计算能量或增量。减半是事后补救，走错了往回缩；阻尼是事前稳健，不让自己迈出不可信的大步。这也是工程里偏爱阻尼的一个原因。

正式跑列文伯格-马夸特。圆拟合从温和的远起点出发，十五轮收敛，圆心几乎回到原点，半径几乎回到二，能量贴住真参数处的参照线。阻尼系数的轨迹值得看：前三轮连续被拒绝，能量不降，阻尼系数一轮轮放大；第四轮走通了，但下降没达到预期，阻尼系数又放大一档；之后下降都达到预期，它才一步步收紧。下降不及预期就放大，达到预期就收紧，自适应就是这两个方向的循环。不过要说清楚：起点再远一点，列文伯格-马夸特也会掉进另一个谷里，起点依然要紧。再看直线：三个不同离谱程度的起点，列文伯格-马夸特全部收敛，把倾角换算回斜率，和线性最小二乘一次解出的斜率、截距一致，相对误差不到一万亿分之一。同一个问题，换一种写法答案不变；从正课的最小二乘到附录的非线性版本，这条线闭合了。

书上第 931 页结尾指了两条路。起点离二次收敛区太远的时候，在泰勒展开里补上二阶项的牛顿型方法，可能收敛更快；内存紧张的时候，只需要梯度的拟牛顿方法，比如 B-F-G-S，也派得上用场。这些属于数值优化教科书的范畴，本集只指路，不展开。两道作业。第一道，拿一个你自己的非线性模型，比如指数衰减，亲手算一遍雅可比，写出高斯-牛顿的增量公式，再跑一遍列文伯格-马夸特，把每一步的预测下降和真实下降记成表，看近似在哪里失效。第二道，把直线实验的起点挪得更远，分别跑高斯-牛顿和列文伯格-马夸特，数一数各自几轮收敛、前几轮阻尼系数怎么变，和圆拟合那条轨迹比一比。作业不要求写代码，手算也可以。
