# E014 口播稿 · 二维变换的族谱：欧氏、相似、仿射、射影一家亲（正课·06·第2章图像形成）

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集结尾我们说，词汇表备齐了，该让对象动起来了。这一集就讲怎么动：二维变换的族谱——平移、刚体、相似、仿射、射影，一家五口，各守各的规矩。

本集路线四段：先把五级变换一个个过，矩阵长什么样、有几个自由度、保住什么性质；再看那页著名的族谱表和背后的嵌套群结构；然后回答一个隐藏问题——点会变，线跟着怎么变；最后三个附加变换加一遍数值实验。

这顿主菜其实预告过两次。齐次坐标那集，我们把表 2.1 当全景图看过一眼：自由度 2、3、4、6、8，数目越大，保的性质越少——当时说主菜在 E014 上桌，今天正式开饭。

第二次预告是上一集片尾。范围就是 §2.1.1，原书第 40 到 43 页；三维那套族谱（表 2.2），讲者安排在下集 E015 开场再过——讲者按：相机的摆放本身就是一次三维刚体变换，放一起讲更顺。先说清本集主菜：不是背五种矩阵，是看清一条规则——矩阵越自由，保住的几何性质越少。

第一级，平移。写起来最简单：x′ = x + t，往右挪 tₓ、往下挪 t_y，两个数，两个自由度。

写进矩阵世界有两种衣裳。紧凑版是 2×3：左边并一个单位阵、右边接上 t；正式版补一行 0 0 1，凑成 3×3 全秩矩阵。讲者按：代价是多存三个数，好处是变换可以连乘、可以求逆，一连串动作缩成一个矩阵。原书特意提醒：公式里等式两侧都出现增广向量时，都能换成完整齐次向量。

第二级，转起来：旋转加平移，学名 2D 刚体运动，也叫 2D 欧氏变换——因为欧氏距离在它手里不变。旋转矩阵 R 由角度 θ 生成，满足两个硬约束：R 乘 R 的转置等于单位阵，行列式等于一。角度一个数，平移两个数，一共三个自由度，保住的是长度。

两个小注脚。机器人教程里这套东西叫 SE(2)，2D 旋转叫 SO(2)——special 指「无反射」，行列式等于一，这是原书脚注 1 给的说明。另一个是讲者补的图像坐标彩蛋：图像 y 轴朝下，正角度在屏幕上看起来是顺时针——齐次坐标那集的作业验证过这一点，这集的作业会接着用。

第三级，相似变换：在刚体上面再发一个缩放因子 s。x′ = sRx + t。它还有个更紧凑的马甲：二乘二那块是 a −b、b a，只是不再要求 a 平方加 b 平方等于一——因为缩放混进来了。四个自由度，保的是线与线的夹角。讲者按：直观说，形状放大缩小不变形。

第四级，仿射：矩阵块干脆不设限制，任意 2×3，六个数全放开，六个自由度。平行线在仿射下仍是平行线，直线也还保着；相对相似，仿射放弃了角度——长度则早在相似那级就放开了。

第五级，射影变换，直接在齐次坐标上操作：x̃′ = H̃x̃，H̃ 是任意 3×3 矩阵。注意 H̃ 也是齐次的——整体乘个倍数算同一个变换，所以九个数只值八个自由度。

落到普通坐标要过一道除法：x′ 的分子是 h₀₀x 加 h₀₁y 加 h₀₂，分母是 h₂₀x 加 h₂₁y 加 h₂₂。讲者按：分母里含着 x 和 y，这就是「透视」二字的来历。它保住的是直线：直线变换后仍是直线。别称有两个：透视变换，和后面会反复出现的名字——单应 homography。

原书把五级画在一张图里：同一个方格，一级级变过去。讲者照着示意重绘了这张图，还把每级的自由度标了出来——平移只是挪窝；刚体多了转角；相似再大一号；仿射开始歪；射影连平行都保不住——讲者按：近大远小，就是拍照的感觉。

把五级排成正式的族谱，就是表 2.1。一行一变换：平移两个自由度，保定向——朝向，即线段方向不变；刚体三个，保长度；相似四个，保角度；仿射六个，保平行；射影八个，只保直线。注意读法，表注原话：每一行也保住下面各行的性质——所以平移保得最多：定向、长度、角度、平行、直线全在；射影只保直线一条。原书说，最容易的理解方式：把它们当成同一批可能受限的 3×3 矩阵。讲者按：一级比一级少几个限制，就是这张表从上往下读的样子。

表 2.1 的表注藏着关键读法：每一行也保住下面各行的性质——原书举的例子是相似变换：不只保角度，也保平行和直线。反过来读，从下往上就是约束逐步收紧。另外二乘三矩阵补一行 0 0 1 就成 3×3；想更深究层级本身，原书指向 Hartley 与 Zisserman 的书。

为什么叫「族谱」而不只是「排行榜」？因为它们构成嵌套的群：同族变换复合起来还是同族——相似乘相似还是相似；逆变换也还在本族里——平移的逆是负平移，相似的逆是倒过来转再除以 s，射影的逆还是个 3×3。封闭加可逆，原书点名的这两条都齐了。

每个简单群都是下一级的子群。这套结构后文有刚需：§3.6 把这些变换施加到图像上（图像变形）时，靠的就是复合与逆都在族内。深究的李群、李代数，原书指向三篇机器人教程。讲者按：对现在的我们，记住 SO(2)、SE(2) 两个名字就够。

有个自然的问题：点会动，线呢？直线方程是 l̃·x̃ 等于零，把 x̃′ = H̃x̃ 代进去整理，就得到线的变换公式：l̃′ = H̃ 的转置逆乘 l̃。讲者按：点正着走，线反着走，乘回原点恰好抵消。

讲者按：这里又是点线对偶——上一集点线共用「内积为零」，这一集点线各用一套矩阵，H̃ 与 H̃ 转置逆互为镜像，结构上还是同一条对偶。符号与运算的细节，原书推荐 Jim Blinn 的书，第九、第十两章专门讲。

族谱之外，原书补了三个常用附加变换。第一个，拉扁压扁：x 方向一个缩放、y 方向一个缩放，各配各的平移——改长宽比专用。它是仿射的一种受限形式。

但原书立刻补了一句：遗憾的是它不能干净地嵌进表 2.1 的群链。讲者按：这话要读准——它本身是仿射的一个子群，只是不在平移、刚体、相似这条主链上；「不嵌套」说的是不落在这条链，不是说不属于任何群。

第二个附加变换，平面流：八个参数，x′ 和 y′ 各是五项的二次多项式——常数、两个一次、两个二次。它什么时候出现？一块平面发生微小的三维运动——所以它可以看成完整单应的小运动近似。

它最大的卖点：对运动参数 aₖ 是线性的——而这些参数恰恰常是待估量。讲者按：估计问题里线性意味着能直接最小二乘，这是把非线性近似换成线性化最实际的动机。

第三个，双线性插值：也是八个参数，x′ 和 y′ 各四项，x′、y′ 各带一个 xy 交叉项，系数各自独立。用途：方形四个角点动了，中间的形变由它插出来——其实任意四个不共线点的运动都能插。

代价：对参数线性，但一般不保直线——只有平行于方形两轴的线例外。原书说它常很有用，比如稀疏网格的样条插值，在 9.2.2 节会用到。讲者按：这三个附加变换的共同点是「先好用，再论出身」——族谱管不到的地方，工程照样开工。

讲者实验：把族谱算一遍。十八项数值断言，对表 2.1 的「保住什么」那一列逐级验证——每级的主性质都有断言，另加结构、群与计数检验：平移保定向（朝向，线段方向不变）和边长、R 正交、刚体保长度、相似保角度、仿射保平行和直线、射影保直线；说不保的，就造反例：非均匀缩放改角度、射影把平行边掰得不平行。再加上群闭合、逆在同族、co-vector 恒等式，和自由度计数对照。

讲者设计的另一项是同步检查：代码输出的重绘五联图，逐文件 md5 比对、同步进幻灯片目录。

实跑结果：十八加一，十九项全过。几个反例值得看一眼：对角阵 2、1 把 45 度角压成 26.6 度——仿射保平行不保角度；射影变换把两条原本平行的边掰到方向不平行——直线还在，平行没了。讲者归纳：每一级自己的那条性质，都有对应的数值断言钉住。

讲者归纳，一句话带走：二维变换是一套受限的 3×3 矩阵——每往下一级，就少承诺一样几何性质：定向、长度、角度、平行，逐级让渡；直线是底线，连射影都保住。

讲者按，再给一个记忆锚：8 = 9 − 1。3×3 矩阵九个数，整体乘个倍数不算数，所以射影是八个自由度。表上「保住什么」那列从下往上读，就是约束逐步收紧——族谱的每一级，都是上一级加上一道新的限制。

讲者归纳，盘点一张词汇表：单应、自由度、嵌套群、SO(2) 与 SE(2)、余向量，一共五个词。这五个词下集还会再用——原书说，三维那套变换族谱跟二维非常相似（原书第 43 页）。讲者按：到时主要是数字变大。

课后两条。读原书：§2.1.1，原书第 40 到 43 页，对照 Figure 2.4 和 Table 2.1。作业接齐次坐标那集的尾巴：把那个负三十度旋转接上平移和缩放，验证合成矩阵仍是 a −b、b a 的相似形式；再随手取直线上三点，用叉积验证射影变换保直线。
