# E062 口播稿 · 语义分割：FCN、U-Net 与分割任务全景

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集把物体框出来，这一集再进一步，给每个像素贴标签。书上第 387 页把这类问题拆成四种：语义分割，逐像素分到类别；实例分割，把每个物体单独描出来；全景分割，物体和背景一起标；密集姿态，把人体像素对应到身体部位。同一页说，这是通用物体识别和场景理解里更有挑战的版本，识别和精确边界要同时做。分类说图里有什么，检测说在哪，分割说每个像素属于谁。四种任务共用一张像素网格，区别在标签怎么组织。

书上第 387 页说，基本做法是给图上每个像素标一个类别。四类任务都建立在这层像素标注上。老办法常用能量最小化或贝叶斯推断，也就是条件随机场。TextonBoost 用一元势，按颜色分布、位置先验和纹理布局分类器打分；位置先验是前景更可能在中间、天空偏高、道路偏低。再加成对势，看相邻像素的颜色梯度。每个像素先各自表态，再让邻居互相商量，边界就顺了。只看单个像素容易把边界切碎，邻居一商量，整片区域就连起来。条件随机场就是在这种像素标签上做全局优化。

书上第 387 页说，纹理布局特征先用十七个方向滤波器组滤一遍，再把响应聚成三十类 texton。这些响应再用偏移矩形区域、按联合提升训练，得到一元势。书上第 388 页说，TextonBoost 的 CRF 框架后来扩成 LayoutCRF；Winn 和 Shotton 加了约束，能认多个实例、处理遮挡；Hoiem 等人又接进完整三维模型。先看局部纹理像什么，再让整幅图的结构来纠错，从一块块像什么，走到整间屋子该长什么样。

书上第 388 页说，全卷积网络让一个神经网络直接做逐像素标注。最早的网络分辨率差、边界松，后来四招把精度和分辨率拉上来：末端加条件随机场、反卷积上采样、U-Net 的细层跳连。编码器一路缩小看全局，解码器一路放大还原细节，跳连把没丢的浅层信息接回来。可以想成描一张大画：先退远看整体轮廓，再走近补细节；跳连就是照着原图描，不凭记忆。分辨率下降会丢细节，上采样只能放大，不能凭空补回。

书上第 388 页说，现代语义分割常建在特征金字塔网络上，用自顶向下的连接把语义信息灌到高分辨率图。PSPNet 用空间金字塔池化，把不同尺度的特征聚起来；UPerNet 同时用特征金字塔和金字塔池化，不只标物体类别，还标材质、部件和纹理。书上第 389 页的图 6.34 画了它的多头结构：场景头做分类，物体和部件头吃融合特征，材质头看最细一层，纹理头不参与微调。HRNet 全程保留高分辨率特征图，在不同分辨率的通道之间交换信息。一头管是什么，一头管边界在哪。多尺度解决物体大小不一，多头解决标签种类不一。

书上第 389 页说，语义分割最早在 MSRC 和 PASCAL VOC 上训练测试；后来有城市街景的 Cityscapes，还有 ADE20K，室内外场景，一百五十种类别和部件标签。Broden 把 ADE20K、Pascal-Context、Pascal-Part、OpenSurfaces、可描述纹理等数据集联邦起来，标签从物体语义扩到材质和纹理。书上第 390 页的表 6.2 列了训练测试分割算法的数据集。数据从几个类别扩到万物加材质，标签越细，模型越能说清这是什么做的。数据集决定标签空间，标签空间决定模型能回答什么。

书上第 390 页说，分割最有希望的应用之一在医学，把解剖组织分出来，后面才能做定量分析。图 4.21 用带方向边的二值图割，把肝脏从骨头和肌肉里分出来；图 6.35 是脑部扫描的肿瘤分割。在成熟优化和深度学习之前，这类活要靠人一片片 X 光片手工描边。早期用马尔可夫随机场和随机森林，后来转向深度学习。书上第 391 页还提到 MICCAI 这类专门会议和医学图像期刊，是找参考的好地方。

书上第 391 页说，实例分割要找出图里所有相关物体，并给可见区域产出像素级掩码。一种思路是先做已知物体的实例识别，再把三维模型反投影回场景；这条路只对已知的刚体模型管用。对人有柔性模型：先把图预分割成大小块，再拿块去和模型部件匹配。对高度可变的类，还可以按特征对应给位置和尺度投票，再推断物体范围。先识别再套模型，难点在模型库要覆盖所有形状。

书上第 391 页说，深度学习来了以后，研究者把区域提议或图像预分割，接上卷积的第二阶段，推出最终实例掩码。突破出现在 Mask R-CNN。它沿用 Faster R-CNN 的区域提议网络，但在框精修和分类之外，再加一条预测物体掩码的分支。原来两个头，现在三个头：框负责在哪，类别负责是谁，掩码负责精确到每个像素。区域提议负责找候选，第二阶段把候选变成像素掩码。

书上第 392 页的图 6.36a 画了结构：区域提议网络先给候选，三个分支分别出类别、精修框、画掩码。多分支多输出，每条监督损失的权重都要仔细平衡。还可以再加分支，比如按关键点画掩码，做人体关键点检测，图 6.37 是例子。Mask R-CNN 之后，换更强的骨干还在继续涨分；COCO+LVIS 联合识别挑战和鲁棒视觉挑战是看最新结果的地方。一条损失太强会压住另一条，三个头要商量着练。掩码比框细，损失函数也要按像素来算。

书上第 392 页说，也可以把像素掩码换成随时间演化的闭合轮廓，也就是 snakes，Peng 等人在 2020 年这么做过。为了让边界更准，Cheng、Girshick 等人 2021 年提出 Boundary IoU，用边界交并比替代常用的 Mask IoU。掩码看面积对不对，边界指标看轮廓贴不贴；面积分对了，边还可能毛糙。

书上第 392 页说，语义分割回答每个像素是什么东西，实例分割回答有几个、各占多大。第 393 页把两者合起来逐像素做，就是全景分割：所有物体正确分开，剩下的背景也正确标类。要设计一个同时平衡两边的全景质量 PQ 指标，得仔细琢磨。COCO 已加了全景任务；图 6.38 的全景特征金字塔网络，就是在 FPN 上加实例和语义两条分支。漏一个物体、错一片背景，都要扣分。全景把两类任务放进同一张输出图，冲突要一起裁决。

书上第 394 页说，识别和场景理解变强，智能修图也跟着变强。Photo Clip Art 能从网络照片里认出并分割行人等物体，让用户贴进自己的照片。Hays 和 Efros 的场景补全，要擦掉一大块再填上：传统做法是平滑延拓或从图里别处借像素；网络图多了以后，干脆找另一张图来当像素来源。他们先算每张图的 gist 找颜色构图相近的，再用图割最小化梯度差，最后用 Poisson 融合贴回去。补出来的屋顶、帆船，边界才不露馅。

书上第 395 页说，另一种玩法是从单张照片推三维结构。Criminisi 等人检测消失点，让用户画墙这类基本结构，反推三维几何。Hoiem 等人的自动照片立起，处理更有机的场景：先用分类器把每个像素判成地面、垂直面或天空，再把超像素分成区域；最后沿垂直面和地面的边界把图折成一块块平面，去掉天空，就成了 pop-up。Saxena 等人更进一步，直接推每个像素的深度和朝向。像儿童立体书，翻开就站起来。单张图没有视差，只能靠消失点、边界和先验知识。

书上第 395 页说，人体姿态，头、躯干、四肢的位置和朝向，也可以看成一种分割任务。从 Felzenszwalb 和 Huttenlocher 2005 年的开创工作起，二维三维姿态估计快速发展。书上第 396 页说，深度网络成了找关键点的主流；图 6.42 是 OpenPose 的实时多人二维姿态。最新最难的 DensePose，要把人体每个像素对应到三维表面模型上的点，作者给了 COCO 里五万人的密集标注。关键点只标几个关节，DensePose 是给整个人贴皮。关键点给关节坐标，密集姿态给表面坐标，粒度不同。

把这一集串起来：语义分割给每个像素贴类别，实例分割给每个物体一张掩码，全景分割把物体和背景一起标，密集姿态把人体像素映射到三维表面。方法从 TextonBoost 的手工特征加 CRF，走到 FCN、U-Net 的端到端，再到 Mask R-CNN 的三头并行和 Panoptic FPN 的双分支。分割是检测的下一站，不只画框，还要画边界，还要理解每个像素是什么。下一集讲视频理解：单张图看完了，时间轴上的人和动作怎么读？
