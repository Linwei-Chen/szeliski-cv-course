# E005 口播稿 · 概率速通：噪声的语言

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

数学工具箱第五站，概率速通。前四集把线性代数和微积分装进了背包；这一集补上最后一块拼图：不确定性。视觉里没有干净的数据——每个像素、每次匹配都带着噪声。十分钟，讲清四个词：随机变量、期望、方差、似然，给附录 B 开路，给后面的机器学习铺路。

先回答为什么需要它。原书 940 页：图形学是正向问题——给定物体、相机和光照，模拟出图像；计算机视觉通常相反——给定图像，反推产生它的场景，这叫逆问题。比如标定：已知三维点，反推相机矩阵。原书脚注还给它分了类：从带噪输入估计连续量，叫回归问题。逆问题难在测量永远带噪声，所以原书写道：除非对可能的误差来源建模，否则不能确信算法合理。这门语言，叫概率。

第一个词：随机变量。讲者解释：把一次还没发生的测量打包成变量，再用分布描述它可能取哪些值、各占多少机会——分布就是个函数，输入候选值，输出机会大小。离散型像骰子，取值一到六，各六分之一；连续型像噪声电压，任何实数都可能，用概率密度描述。附录 B 里的噪声 n 就是一个连续随机变量。顺带埋颗种子：两个独立骰子点数之和的分布，等于两个分布的卷积——第七集见。

第二个词：期望。离散求和、连续积分：每个取值乘概率再加总，得到长期平均。一枚均匀骰子的期望是三点五——不在任何取值上，但抛一万次，平均值会稳稳收敛到它，这就是大数定律。还有一条好用的：期望线性，和的期望等于期望的和——它保证噪声的平均性质能逐项传递。对噪声最要紧的假设是零均值：单次偏高偏低猜不准，长期平均却是零。

第三个词：方差。它量散开程度：偏差先平方再取期望。为什么非平方不可？偏差有正有负，直接平均会互相抵消只剩零；平方才留得住散开的信息。开根号得到标准差 σ，与原数据同单位。正态近似下的经验读法：约 68% 的机会落在正负一倍 σ 内，95% 在两倍内。顺带一提：均值和方差定了，高斯分布就定了——两个参数包办一切。书里的协方差矩阵 Σ，就是方差的多维版。

主角登场：高斯分布，钟形曲线。为什么误差默认长这样？原书 945 页：若噪声是大量微小误差叠加——如硅成像仪的热噪声——高斯就是合适的模型。讲者补直觉：独立小扰动叠加趋向钟形——中心极限定理的直觉。原书紧接着提醒：多数测量混有离群值，得换长尾模型（B.3）。记住关键形状：密度正比于 exp 负的平方偏差——稍后代进似然的就是这一项。书里写成 n 服从 N(0, Σ)，式 B.7：均值定为零，协方差 Σ 定胖瘦。

把测量写成一行，式 B.5：y 等于 f(x) 加 n。x 是待估的未知状态，f 是测量模型，把未知映射成该有的读数，n 是噪声。原书 941 页：这就是从未知走到含噪测量的正向过程——这一行是后面一切的骨架：似然、能量、加权平均，全都从它出发。记号约定出自 943 页：带波浪的 ỹ 是脏观测，戴帽的 ŷ 是模型预测。若噪声不独立——比如整幅图同乘一个增益——原书建议：并进状态向量当干扰参数，需要的话再丢。

视角翻转。似然 L 等于 p(y｜x)，式 B.6；噪声相互独立，所以总似然是连乘。同一个公式两种读法：固定 x 看 y，它是观测的分布；固定 y 看 x，它就成了似然——哪个参数值最可能产出眼前这批观测？讲者类比：箭已经中靶，反推射手站在哪个位置。这一步反转，是从概率通向估计的桥，后面每一集都踩它过河。

把高斯噪声代进去，得到式 B.8：每个测量贡献一个指数项，指数上是马氏距离的平方——残差 y 减 f(x)，用 Σ 逆加权，原书 942 页，与式 5.32 同源。等马氏距离的曲线是等概率椭球：特征向量定方向，特征值开根号定半轴，式 B.10。协方差各向同性时，它退化成平方距离除以 σ²，式 B.9。注意形状：预测离观测越远，指数罚得越重；前面那串系数与 x 无关——比似然大小，只看指数上的平方残差。

对 L 取负对数，式 B.11：能量 E 等于二分之一乘加权平方残差和，再加常数 k。对数干了两件事：连乘变连加，指数变二次型；常数与 x 无关，比大小可以扔。眼熟吗？这是加权最小二乘——等方差时就是上一集的最小二乘；平方和目标不是拍脑袋定的，是高斯假设下的推论。让 L 最大的 x 叫最大似然估计；原书 944 页提醒：分布多峰时要小心，可能得推迟决策、等更多测量。

式 B.13 里，每个残差都乘着 C 等于 Σ 逆。原书 943 页给它三个身份：权重，乘在残差上的系数；Fisher 信息矩阵——一个测量含多少信息、多强地约束估计；置信度，字母 C 的来历。方差越小，话语权越大。信息矩阵还可以奇异、甚至为零：缺失的测量不约束解。原书举的例子：用一条边做测量，沿边方向的位置分量方差无穷大或极大——约束只在垂直方向。待会儿实验里你会亲眼看到：σ 一比四，话语权就差十六倍。

上实验：两台传感器估同一个真值 3.0。A 准，标准差 1，读出 2.20；B 糊，标准差 4，读出负 2.30。左图各画一条能量曲线：A 的陡，B 的缓——B 那条平，正是它话语权低的几何含义：换个 x 它的能量几乎不变，等于没说什么。联合能量是两者相加，谷底落在 1.93——被准的 A 拉了过去。这个谷底有解析名字：信息加权平均，式 B.20——16 乘 yA 加 yB，再除以 17。

这套加权到底赚多少？重复两万次：简单平均的误差 std 是 2.05，加权平均只有 0.98——理论值 2.06 对 0.97，窄了约 2.1 倍。这正是一笔信息账：A 的信息量是 B 的十六倍，B 的一票只有 A 的十六分之一——糊传感器不是扔掉，是降权。反过来只信 B、扔掉 A，方差就是 16——融合把它压到约十七分之一。再看中心：两种估计的误差均值都约等于零——零均值噪声经过线性运算，期望还是零。方差有价，均值免费。

收个尾。概率这门语言，四个词就够起步：随机变量是对象，期望是中心，方差是散开，似然是观测投给 x 的票。三条暗线贯穿整个附录 B：噪声零均值，独立所以连乘，高斯所以平方惩罚。下一集，给这张票再加一张先验牌——贝叶斯与 MAP。

想读原书：附录 B 开篇，第 939 到 945 页——逆问题、测量方程、似然、负对数似然与信息矩阵，式 B.5 到 B.13；加权平均 B.20 在 945 页，椭球在 942 到 943。课后作业：把实验代码里 B 传感器的标准差从 4 改成 0.5，让它反而比 A 还准，重跑看谷底偏向谁、加权平均的方差变成多少。下一集：贝叶斯思维，先验、后验与 MAP。
