# E033 口播稿 · 第 3 章的书单与主题：阅读指南怎么用

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集结尾说，这一集过一遍第 3 章末尾的阅读指南，为综合实验课做准备。书上第 178 页，这一节叫补充阅读：想深入图像处理，有几本流行教材可读；这个领域最负盛名的会议和期刊，是 IEEE 图像处理国际会议和 IEEE 图像处理汇刊。这一节没有新公式，也没有新图，它是作者给读者开的书单。怎么把书单用起来，就是这一集要讲的事。

书上第 178 页开出的教材书单有五本：Gomes 和 Velho 一九九七年，Jähne 一九九七年，Pratt 二零零七年，Burger 和 Burge 二零零九年，Gonzalez 和 Woods 二零一七年。书单一段一个主题：合成、滤波、形态学、金字塔、变形，大多对得回正课。五本不必逐本读完，书单不是从头念，是按主题去查。

这张书单引了多少文献？把书上第 178 到 179 页的括号引文逐条数：一个括号里一个年份算一条，分号隔开的分开数；同作者同年的两篇，字母编号并作一条。数下来八段主题，共七十三条引文；有一条在两段里各出现一次，去掉重复是七十二个不同条目；年份从一九八二年跨到二零一七年。八段条数画成右图，柱顶就是条数。

图里两种颜色。蓝色的六段，正课都讲过，柱底标着对应的正课集号；灰色的两段，教材与顶会刊是这一节开头的书单，本集导读讲的就是它；另一段灰色的非线性金字塔，下面单独交代。

书上第 178 页第二段讲图像合成算子：开山之作是 Porter 和 Duff 一九八四年；Blinn 一九九四年给了更细的教程；Smith 和 Blinn 一九九六年最早让图形学界注意到这个话题；Wang 和 Cohen 二零零九年写了篇深入的综述。合成是把一张图带透明度叠到另一张图上，第 13 集讲过这种叠加和玻璃反射的直接相加。

书上第 178 到 179 页讲线性滤波，只有两条：Freeman 和 Adelson 一九九一年，可分离、可导向的定向带通滤波器的出色入门；Perona 一九九五年，怎么把任意滤波器近似成一串可分离分量之和。可分离第 16 集讲过，滤波拆成横竖两趟；可导向第 23 集见过，滤波方向可以任意转。

书上第 179 页讲非线性滤波，说这块文献又广又多样，双边滤波、迭代算法、变分方法、引导滤波都算；双边滤波从 Tomasi 和 Manduchi 一九九八年起，引导滤波收在 He、Sun 和 Tang 二零一三年。这一段共二十条，是引文最多的一段：双边五条，迭代八条，变分四条，引导三条。双边滤波第 17 集讲过，用来保边去噪。书上给非线性滤波开了二十条线索，给线性只点了两条。

书上第 179 页讲图像形态学，说这儿有几条好参考：Haralick 和 Shapiro 一九九二年、Serra 一九八二年、Serra 和 Vincent 一九九二年、Soille 二零零六年等等。这一段共七条。形态学就是腐蚀膨胀那套，正课第 18 集讲过；做二值图像处理的，按图索骥就够用。

书上第 179 页讲金字塔与小波：金字塔和金字塔融合的经典论文，是 Burt 和 Adelson 一九八三年写的；最早把小波引进计算机视觉界的，是 Mallat 一九八九年；后面还有成串的教程综述、图形学的多分辨率处理、视觉里的多尺度定向滤波和去噪。这一段共十九条。第 22 集金字塔、第 23 集小波与融合，源头就是这两组论文。

书上第 179 页有一段承上启下：金字塔通常用线性滤波搭，较新的工作改用非线性滤波，更能保住细节和其他显要特征；代表工作分视觉和计算摄影两边。这里说的金字塔，就是第 22 集讲的那套。这一段共五条，视觉两条，计算摄影三条。这五条正课都没有按篇讲过；其中 Fattal 二零零九年那篇的思路，第 23 集讲小波时一句带过；这条路第 22 集也沾过边，书上第 158 到 159 页的局部拉普拉斯滤波，就是在塔的构造里做非线性处理。

书上第 179 页最后一段收在变形与 morphing：图像处理这边有 Wolberg 一九九零年；图形学那边管这叫纹理映射，其中有 Williams 一九八三年；收尾的 morphing 是 Beier 和 Neely 一九九二年。这一段共十一条：图像处理四条，图形学五条，morphing 两条。纹理映射书上第 168 页说过，是把图像贴到曲面。MIP-map 就是 Williams 提出的，上一集讲过，书上第 172 页，预先缩好一串小图，按远近挑一张。Beier 和 Neely 的线段变形，用成对线段指定两张图怎么对齐，上一集讲 morphing 时专门讲过他俩的方法。

最后看正文的主题对应，右图。书上第 3 章正文七个主题，正课从第 13 集走到第 25 集。先看上四行：点运算两集，改值域；线性滤波两集，卷积；非线性与二值形态学两集，中值、双边、腐蚀膨胀；傅里叶变换两集，把图搬进频域。四段，八集。

再看下三行：插值、金字塔、小波加融合三集；几何变换一集，改定义域；加上本集导读，一共十三集。除了开头的教材书单和非线性金字塔这两段，其余六段书单都能对回具体的集。

这张图怎么用，三句话。想补基础，按主题回正课对应集重看；想深入，先教材打底，再按主题段查书单，书单是人名加年份，照着搜就行；想动手，书上第 180 页翻过去就是习题区。这些习题留给下一集的综合实验课，把第 2、3 章的动手题挑几道做透。下集见。
