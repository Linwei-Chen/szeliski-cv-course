# E059 口播稿 · 人脸识别：机器最拿手的识别任务

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集讲完分类和检索。这一集从书上第 363 页开始：在计算机被要求做的各种识别任务里，人脸识别大概是最成功的一个。书上同一页还说，连人自己都不太分得清不熟悉的脸；可计算机在小范围的家人朋友之间认人，已经走进了消费级相册应用。认人这件事，人和机器的强项并不在同一个地方。一个对陌生脸容易犯难，一个守着小圈子很稳，这就是它率先落地的原因。

书上第 363 页列了一串用途：人机交互、身份核验、桌面登录、家长控制、病人监护。从解锁电脑到看护老人，人脸确实方便。但同一页紧接着提醒，这项技术也有被滥用的可能。用途越广，边界越要清楚，谁来管、怎么管，要先问明白。方便和风险是同一件事的两面，讲用途时也要讲清限制。这也是人脸识别和别的识别任务最大的不同。

难点在哪？书上第 363 到 364 页给出三个字母：姿态、光照、表情，合称 PIE。识别器最好在大范围变化的 PIE 条件下训练，才算见过世面。书上第 364 页的表 6.1 列了家底：LFW 有五千七百四十九位网络名人；YouTube Faces 有一千五百九十五人、三千四百二十五个视频；MegaFace 有一百万张网络人脸；IJB 有三万一千三百三十四张脸、三千五百三十一人；WIDER FACE 有三万二千二百零三张检测图。数据集越滚越大，考的就是换个角度、换盏灯，你还认不认得。同一个人的脸，换个姿势、换种光、换个表情，像素就会大变。本页示意图是程序生成的，没有用原书原图。

最早的路线很直接。书上第 364 页说，先找眼睛、鼻子、嘴巴这些有辨识度的特征点，再量它们之间的距离。另一支把灰度图投影到低维子空间，也就是特征脸；同时用主动外观模型，把形状和外观的变化一起建模。一条量点，一条学整体。量点靠人工设计，学整体靠统计，两条路后来合到了一起。这些特征点后来也被叫作基准点，几个点的位置关系，就是最早的身份依据。

为什么要一起建模？书上第 365 页说得很清楚：人脸的长相和可辨识度，既靠形状，也靠颜色和纹理；特征脸抓住的主要是后者。同一页还提醒，头一转，姿态就变了，识别时得先把姿态的影响扣掉。只记脸色不记脸型，换个角度就容易吃亏。形状管轮廓和五官位置，纹理管颜色和明暗，两样都在变。所以只靠特征脸不够，形状这一半必须补上。

书上第 366 页举了一个很有说服力的实验。Rowland 和 Perrett 先手工描出五官轮廓，用这些轮廓把每张脸校正到标准形状；再分别分析形状和颜色，看它们偏离平均脸多少。结果，某些形状和颜色的变形，能和年龄、性别这些个人特征对上号。同一页的结论是：形状和颜色，对这类特征的感知都重要。他们不是直接比原图，而是先把脸拉到同一个几何框架里。脸型和脸色，得一起算。

沿着这条思路，书上第 366 页列出一串建模工具。主动形状模型，管形状怎么变；三维形变模型，管整张脸的三维结构；弹性束图匹配，把特征点上的局部滤波响应和形状模型绑在一起。三件工具分工不同，后来都成了人脸建模的常用零件。工具越多，能描述的脸的变化就越细，但也越依赖对齐。主动形状模型先学轮廓点怎么摆，三维形变模型再给脸加上深度，弹性束图匹配则在关键点周围撒一张小网。

集大成的是主动外观模型，简称 AAM。书上第 366 页先给定义：它同时建模两样东西，形状怎么变，纹理怎么变；纹理先归一化到标准形状再分析。同一页给出两条式子：形状等于平均形状加形变，纹理等于平均纹理加形变，而且两者共用同一组外观参数。拉一个参数，脸型和脸色一起动。外观参数一变，形状和纹理按各自的基一起变，不会各走各的。本页示意图是程序生成的，没有用原书原图。

这套模型怎么用来认人？书上第 367 页说，可以算一个身份子空间，把身份的变化，从光照、姿态、表情这些干扰里分出来。AAM 在识别里最主要的用法，其实是对齐，把脸摆到标准姿态，再交给传统方法去认。同一页还讲了最重要的扩展：建三维形状模型，能从单目视频建，也能从多视角视频建，对大幅度转头更稳。对齐做好了，后面的分类或比对就只需要关心身份本身。先把脸摆正，再谈认人，这一步后来被深度方法继承。

书上第 368 页，两张图版展示了这条演进。一张是三维 AAM 做头部跟踪：视频帧上估出偏航、俯仰、翻滚三个角度，再套上可变形网格。另一张是 DeepFace 的前端化：先用六个、后来用六十七个基准点，把侧脸掰正，裁成一张正脸。角度估得准，网格才贴得住；基准点找得准，正脸才裁得正。前端化的目的只有一个，把姿态这个最大的干扰项先拿掉，后面的比对才有意义。

书上第 368 到 369 页讲 DeepFace 的架构：一上来就是前端化，接着是若干局部连接层。注意，不是卷积层，卷积核可以随位置变；最后接两层全连接，再做 K 类 softmax 分类。同一页还说，深度网络在人脸识别上开始大规模奏效，DeepFace 是早期代表之一。局部连接层保留空间位置的概念，不像全连接层那样一开始就把位置打散。先把脸摆正，再用一张会变形的网去读，工程味很重，但有效。

后来的系统开始做减法。书上第 369 页说，有些新方法干脆省掉前端化，改用数据增强，合成更多姿态的输入。同一页还推荐了 Masi 等人的教程与综述：训练集、测试集、前端化、数据增强，还有训练损失，全都梳理了一遍。数据够了，手工的前端化就可以放下，这是深度学习反复发生的剧本。数据增强省掉的是手工对齐，不是省掉对姿态变化的要求。综述把训练损失单列一节，也说明大家已经意识到，最后拼的是损失怎么设计。

书上第 369 页说，Schroff 等人和 Parkhi 等人用三元组损失，学一个低维嵌入空间，让这个空间不随人数膨胀。同一页还讲到 ArcFace：在单位超球面上量角度距离，再加一个角度间隔，把同一个身份挤得更紧。也可以先把每张脸的特征向量缩到一样长，只看方向；方向越近，脸越像。训练时学分类，考试时只比距离。书上第 370 页的图 6.18 画了典型架构：训练时用海量标注人脸，约束深度网络，优化分类损失；测试时把分类层一扔，网络就当特征提取器用。嵌入空间里，同一个人的距离近，不同人的距离远，比对就变成量距离。本页示意图是程序生成的，没有用原书原图。

说回日常。书上第 369 页说，数码相机自动找脸，帮对焦；视频会议找脸，把镜头对准发言人；相册和照片分享网站，几乎都带人脸整理。找到脸、让人打标签，日后找某个人的照片就方便，也能自动分享给朋友；在 Facebook 上，给朋友打标签还是最受欢迎的功能之一。对用户来说，这些功能大多藏在后台，看到的是自动整理好的相册。人脸识别最先变成日用品的形态，是相册。

当然，脸也有难找的时候。书上第 369 页说，脸太小、转过去、被挡住，都不好认。给出的办法是组合起来看：人脸识别，加上行人检测，再加上衣着识别，三样一起看。书上第 370 页再补一层：把人的识别和位置、活动、事件这些上下文合起来，还能再涨一截。单看脸失败的场景，多几种线索往往就能补回来。认不出脸，就看人、看衣服、看他在哪儿、在干什么，线索越多，身份越清楚。

收个尾。这一集走了一条很长的路：从量五官距离，到特征脸；从形状加纹理的主动外观模型，到三维前端化；再到 DeepFace 和 ArcFace，用损失函数把同一张脸挤到一起。一条主线是：先量点，再学形状，最后学一个能把同一张脸挤到一起的向量。识别和检测分工不同：识别回答是谁，检测回答脸在哪里。书上第 370 页话锋一转：给定一张图，比如一张合影，难道要对每个可能的子窗口都跑一遍识别吗？下一集，对象检测登场，先看人脸检测怎么把找脸做成专门的探测器。
