# E040 口播稿 · 参数不确定度：协方差告诉我们「有多确定」

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集把门槛和轮数两笔账算完了，结尾留了一个问题：答案算出来了，它有多确定？换一批数据重跑，答案会晃多厉害？这一集补上这笔账。原书附录 B.6 专门讲这件事。这个晃法，数学里叫协方差，是这一集要讲的东西。本集分三步：先看最简单的情形怎么算；再动手验一验这条公式灵不灵；最后看算不动的时候怎么办。三步都围绕同一个问题：估出来的参数，误差有多大。

书上第 952 页说，除了算出最可能的估计，很多应用还需要知道这个估计的不确定度。最一般的办法，是给所有未知量算一个完整的概率分布，但这通常算不动。完整分布要描述所有参数的联合变化，参数一多，计算量和存储量都撑不住。只有一个特例好办：线性的估计问题加高斯噪声。这时整体的能量函数是一个二次型，后验分布就是一个多维高斯，它的协方差可以直接从噪声加权的海塞矩阵的逆算出来。二次型的能量面像一只规整的碗，碗口开多宽，高斯就摊多宽；整只碗的形状，一个矩阵就写得下，所以协方差有现成式子可算。

书上第 945 页给出 B 点一九这个式子：把每个测量的测量矩阵转置，乘上测量协方差的逆，再乘测量矩阵，全部加起来，整体取一次逆，剩下的就是后验协方差。直线拟合里，每个测量的测量矩阵只有一行，两个数：横坐标 x 和一。这两个数，是每个点分别拽斜率、拽截距的力气；整批点怎么站，直接写进这个式子。书上第 952 页说，协方差矩阵的逆，在这种简单情形就等于海塞矩阵，它还有个别名，叫信息矩阵。反过来读，协方差大，就是这批测量把参数拽得不紧，答案自然晃得厉害。这个式子的输入只有测量矩阵和测量噪声的协方差，估计值本身不进公式。

拿本集数据代进去。胜出的票集是十五条内点，精拟合出一条线：斜率零点五四，截距零点九六。按 B 点一九这个式子算，协方差给出：斜率的标准差约零点零三，截距的标准差约零点零七。翻成带宽，斜率晃动范围正负零点零六，截距正负零点一四，下一段验一验这个式子。带宽取正负两个标准差，后面的覆盖率实验就用它当判据。噪声宽度按造数据时的零点一五代入；实操里它得估，后面专门讲。这套票集是门槛零点三的胜出线挑出来的，拿它反过来报不确定度，不是一次独立的估计，这一点先说明白。斜率和截距强负相关：斜率估大一点，截距就得小一点来补，相关系数负的零点八三。

光有公式还不够，我们动手验了验它。实验把本集十六个真内点的横坐标全部固定不动，比胜出票集多一个，那一个是被门槛挡在外面的自己人。在这十六个点的布局下，按同一个式子现算出实验用的带宽，然后只重新抽噪声，跑四百次，每次重新拟合一条线。横坐标不动，只换噪声，这样比较的才是同一条公式。固定布局，是因为这条式子回答的是：测量布局给定时，答案有多可靠；换布局就是另一个问题了。外点不进这个实验，外点一进来，高斯假设本身就破了，考的就不是这条公式了。结果：斜率的估计值落在正负两个标准差带里的，三百七十九次；截距落在带里的，三百八十二次。九成五上下，和理论上该罩住的频率对得上。这条公式说的频率是真的，前提是噪声宽度已知。

书上第 952 页说，即便在这种简单情形，完整的协方差矩阵也可能大到算不动、存不下。比如大规模的运动恢复结构，一个大的稀疏海塞矩阵，它的协方差通常是稠密大矩阵。稀疏的东西一取逆就变稠密，规模一大就存不下。这时通常只报估计量的方差，或者个别参数的简单协方差，比如某个三维点的坐标、某台相机的位姿。想看得更透，可以做特征值分析，找出主导的不确定方向。整张表存不下，就只存自己关心的那一行：地图点报地图点的，相机报相机的。

本集数据虽小，主方向也看得见：最大特征值方向与绕数据质心转线方向，夹角余弦零点九九。线绕着质心晃，就是最主要的晃法。书上第 952 页说，后验能量不是二次型时，比如非线性最小二乘，或者加了鲁棒罚函数的版本，往往仍能在最优解附近估一个海塞矩阵；克拉默-拉奥下界就取它的逆。局部海塞可能低估能量面有多宽，但协方差不会比这个局部二次近似算出来的更小。下界听上去扫兴，其实是句实话：带再窄也窄不过这条下界，最多就这么准，实际只会一样或更晃。线性高斯情形等号成立，非线性情形一般只会更宽。

这条公式还有另一半：噪声宽度。线性情形它不改协方差的公式，只进权重里。可实操里噪声宽度未知，得从残差估。本集数据：残差的标准差被外点拉到零点四三；换成残差 MAD 乘一点四的稳健估法，估出零点二八；真噪声宽度是零点一五。外点没有改那条公式，线性情形协方差只看横坐标布局；它污染的是噪声宽度的估计。噪声估大了，带就报宽了；估小了，带就报窄，看着比实际更准，更危险。MAD 这把尺子，前面几集用过；它只稳不神：线被外点拉偏过，零点二八仍比真值高出一截。残差里混进一个大外点，平方会把它的影响放大；绝对值只按大小排，影响就小一些。

书上第 952 页说，很多计算机视觉应用干脆不算不确定度，但算一算常常有用，至少能对估计有多可靠多个直觉。有些应用必须算：比如卡尔曼滤波，要把新的测量和已有的估计最优地融合起来，靠的就是这个不确定度。新旧两份估计，各有各的晃法，谁更笃定就多听谁一点；这笔账得拿不确定度来算。至少能知道这个估计靠不靠得住，后面决策要不要留余量。这一页开篇那句的脚注还补了一句：在经典的摄影测量里尤其如此，报告精度几乎总被视为必须。

两道作业。第一道，自己造一组已知斜率、截距、噪声宽度的数据，按这个式子算一次后验协方差，把斜率和截距的标准差报出来；带宽就用这批横坐标按同一式子现算；再做固定布局的重抽实验，数一数估计值落进正负两个标准差带的比例，对照九成五。第二道，把噪声宽度换成残差 MAD 乘一点四的估计，再算一遍协方差、画一遍带，看看带宽变了多少，想想为什么 MAD 版对个别大残差更稳。第一道考的是公式本身灵不灵；第二道考的是噪声估不准时，答案跟着晃多少。两道都用本集同一套数据口径，方便和上面的读数对照。

这一集收成三句话。第一，估计值旁边要配一句有多确定。第二，线性高斯情形，协方差就是噪声加权海塞的逆；正负两个标准差的带，实测罩得住九成五，前提是噪声宽度已知。第三，非线性情形，拿最优解附近的海塞的逆当不确定度的下界。书上第 945 页说，测量是非线性的时候，整个方程组得用非线性最小二乘迭代着解，原书指向附录 A 点三。下一集拆开看，这种迭代具体怎么走。这三句分别对应 B.19、覆盖率实验和克拉默-拉奥下界。
