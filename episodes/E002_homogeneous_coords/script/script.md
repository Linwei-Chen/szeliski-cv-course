# E002 口播稿 · 齐次坐标：让「平移」也变成乘法

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集结尾我们留了个坑：旋转是乘法，平移是加法，两件事不合拍——想把一张图绕自己的中心转一下，公式马上变得又长又丑。今天，我们用一块拼图把坑填上。它的名字叫齐次坐标。

这里是数学工具箱第二集。「齐次」这个词，是说方程里每一项的次数都一样——先别管名字，想法朴素得出奇：给每个点，多发一张写着 1 的工牌。这一集是后面所有几何课的地基——成像几何、图像变换、全景拼接，全靠它把一连串动作拧成一条矩阵链。

先回忆问题出在哪。上一集说过，矩阵是空间的动作。旋转这个动作，矩阵干得干净利落：新坐标等于旋转矩阵 R 乘上旧坐标。可平移呢？新坐标等于旧坐标加上一个 t——它是加法，挤不进乘法的俱乐部。一个纯乘法，一个必须加，代数待遇都不一样。

待遇不同，麻烦就来了。绕图像中心旋转，老写法分三步：先减去中心坐标，做旋转，再加回去。乘一次、加两次，公式又长又丑，顺序错一点，整张图就转飞了。合并成一步也行，但每换一个中心就得重推一遍公式，串的动作越多越乱。有没有办法，让平移也享受乘法待遇？

办法朴素到离谱：给平面上的每个点多加一格。一个点本来用两个数描述，x 和 y；现在在后面添上第三格，先写 1。位置信息一点没变，点还是那个点，只是出门随身带一张写着 1 的工牌。

看右边这根向量：三个数，前两个是位置，第三格正好是 1。添了格子的向量，正式名字叫增广向量。先记住一个细节：工牌上写 2、写 3 也行，前两格跟着同比放大就行，反正倍数不算数——这条规矩，马上正式登场。

给这套写法上规矩。原书第 36 页：齐次坐标里，只差一个非零倍数的两组数，算作同一个点——三格全是 0 不算任何点；想换回普通坐标，把前两格统一除以最后一格就行。第三格是 1 的时候，除法是空操作，前两格直接就是 x 和 y。

反过来，第三格是 0、前两格不全为 0 的点也很特别：没法做这次除法，没有任何普通坐标能对应。原书给它起了名字，叫理想点，也叫无穷远点。先记下这个名字——几分钟后，它带来本集最漂亮的彩蛋。

魔术时间。这是平移的 3×3 矩阵：左上角是 2×2 单位矩阵，第三列上面两格放平移量 tx 和 ty，最后一行是 0 0 1。用上一集的配重法算：拿 x、y、1 当配重去混合三列——第三列的配重恒为 1，所以平移量被原样加了进去。

算出来的结果是：第一格 x 加 tx，第二格 y 加 ty，第三格还是 1。注意，矩阵内部的乘加一步都没少——变化在于：平移不再是单独的一步加法，它和旋转一样，被吸收进同一个矩阵。这个矩阵在三维里仍是线性动作，落回二维，才显出平移的样子。

那上集说的「线性映射钉死原点」的短板呢？它还在，但卡不到我们了。我们的点全都住在第三格等于 1 的这层楼上，而这层楼上没有任何一点是三维空间的原点。准确地说，每个点其实是穿过原点的一整条射线，这层楼只是我们挑出来的代表；最后一行是 0 0 1 的矩阵，把楼层原样送回楼层——在楼上看，就是平移。这是讲者的解释，不是原书原话。

更妙的是原书的两句话。第 40 页说：给平移矩阵补上一行 0 0 1、变成满秩的 3×3，就能用矩阵乘法串联变换，也能求逆。第 41 页再把话说开：这些二维变换，都可以看成作用在齐次坐标上的 3×3 矩阵。上一集练的配重法和矩阵连乘，从这里开始天天用。

兑现上一集的承诺。绕图像中心旋转，齐次写法是三个矩阵连乘。注意读法：矩阵链要从右往左——最右边的 T(−c) 先把中心挪到原点，中间 R 旋转，最左边的 T(c) 再把中心挪回去。离点最近的先动手。「先乘再加」，从今天起退休。

顺便说一句，三维世界用的也是同一招：三维点写成四个数，增广形式最后一格还是 1。以后讲三维重建的课，满屏都是这种四格向量。套路相同，细节留到三维几何那集。

空口无凭，上代码。本集实验分三步：第一步，用「先减中心、旋转、再加回去」的老写法转一张图；第二步，用齐次矩阵链 T·R·T⁻¹ 重做一遍；第三步，把平移、旋转、缩放串成一条四矩阵长链，看代码能干净到什么程度。

结果在这：左边老写法，中间齐次矩阵链，两张输出完全一致——同一张图，两种人生。右边那条长链，平移、旋转、缩放、再平移，四步动作就是四个 3×3 矩阵乘起来再作用一次。这就是后面几何课里天天要写的样子。

彩蛋时间。先补两块铺垫：直线 ax + by + c = 0 也能写成三个数 (a, b, c)，叫直线向量，乘个非零倍数还是同一条线；再借一个本集新工具——叉积，两个三格向量叉一下，得到一根新的三格向量。

然后是原书第 37 页的漂亮结果：两条直线的交点，等于两条直线向量的叉积；过两点的直线，也等于两个点向量的叉积。算出来的还是齐次坐标，除一下第三格，就是交点的位置。不用自己消元——叉积替你把方程组解好了。

为什么这么灵？叉积结果和两条直线向量的点积都是 0，而点积为 0，恰好就是「点在线上」的那条方程。所以它同时落在两条线上；两条线不重合时，这样的点只有一个。这个工具，后面讲对极几何还会再见到。

那平行线呢？普通坐标里它们永不相交。可拿两条不重合的平行线一算，交点第三格恰好是 0，正好落在无穷远点上——这个点的前两格，还正好编码了直线的方向。现实里平行的铁轨，拍成照片却交于一点，那是透视把无穷远点搬到了画面上，具体留给 E015。

最后看一眼全景图。原书表 2.1 把二维变换排成一份族谱：平移，2 个自由度；刚体变换，也叫欧氏变换，3 个，保长度；相似变换，4 个，保角度；仿射变换，6 个，保平行；射影变换，8 个，保直线——3×3 有 9 个数，但整体乘个倍数不算数，所以是 8。越往上越特殊，保住的越多。主菜在 E014 上桌，今天混个脸熟。

收个尾，两句话带走。第一句是记忆锚：给点添一格，倍数不算数，让平移也变成乘法。第二句是为什么：线性映射钉死三维原点，而我们的点住在第三格等于 1 的楼层上——看到最后一行是 0 0 1 的 3×3 矩阵，就想想那层楼。

课后怎么走？两条路。第一条，读原书：先读 §2.1 第 36 到 37 页的点、线与叉积，再读 §2.1.1 第 40 到 42 页的平移矩阵和变换族谱表。第二条，跑通本集代码，把旋转角改成负三十度——注意图像坐标 y 轴朝下，屏幕上看起来是顺时针——验证链式写法是不是一处改、全局生效。
