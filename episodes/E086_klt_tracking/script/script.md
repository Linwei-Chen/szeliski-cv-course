# E086 口播稿 · 跟住它：KLT 特征跟踪的工程之道

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集把整张图的运动压成一组参数；视频里常常只关心一个点：这个角、这只眼睛、这块贴纸，下一帧去哪了。这一集讲 KLT：先在第一帧挑好特征，再在后续帧的小窗口里跟住它。做法是记住长相，下一帧在附近找，不用每帧重新认人。有三个问题：什么样的点值得跟，跟丢了怎么发现，跟久了为什么会漂。跟踪只处理小窗口，代价比全图检测低。

书上第 452 页说，除了在每张图里独立找特征再匹配，还可以先在第一张图找一组可能的特征位置，再到后续图里找它们的对应位置。这种先检测再跟踪的做法，在视频里更常用，因为相邻帧的运动和外观变化通常很小。检测加匹配每帧都要在全图重复检测和描述，计算量大；先检测再跟踪把大头放在第一帧，后面只做小搜索，所以实时系统偏爱它。第一帧选错点，后面再努力也白搭。第一帧选点要准，这是先检测再跟踪的代价。

书上第 452 页说，实践中，两个方向都有高梯度的区域，也就是自相关矩阵两个特征值都大的区域，能提供稳定的对应位置。实验里，角点块的最小特征值三点九二，边缘块只有零点一零七，平坦块零点一一七；边缘块最大特征值八点零二，说明它只在一个方向有约束。角点是两条边都卡住，边缘是一条边卡住、另一条能滑，平坦区是哪边都能滑。KLT 要的是角点。选特征看最小特征值，比只看梯度幅值稳。

看这张图：左边是角点、边缘、平坦三种块的两个特征值；右边是局部搜索和三层金字塔在大位移下的误差。角点两个特征值都在四左右，边缘一大一小，平坦两个都接近零点一；所以看最小特征值就能筛掉边缘和平坦。右边先留个悬念：十像素的大位移，局部正负三的搜索误差十三点六零一像素，三层金字塔误差零；原理后面讲。选特征时别只看梯度幅值，要看两个方向是否都被约束住。弱方向约束不住，位置就会沿那个方向滑。

书上第 452 页说，后续帧里，找对应块平方差低的位置通常就够用；但亮度变化时，显式补偿或归一化互相关更稳；搜索范围大时，用金字塔由粗到细更快。平方差假设长相不变，亮度一变就失准；NCC 只看形状，不看整体明暗。大位移还有另一个麻烦：局部小窗口根本看不到真值，得像上一集那样先降采样、再逐层细化。平方差还有一个隐含假设：窗口里每个像素权重相同；如果窗口里有遮挡或运动边界，少数外点会把结果拉偏。工程上会加权重、换鲁棒损失，或者先做前后向一致性检查。跟踪不是只算一次，每一帧都要重新算。

书上第 452 页提出一个工程选择：跟长序列时，是继续和最初检测到的模板比，还是每一帧在匹配位置重新采样模板？前者怕外观变化，比如透视缩短；后者怕特征从原位置慢慢漂走。书上还点明：小的配准误差会累积成马尔可夫随机游走，时间越长漂得越远。固定模板像拿第一张照片认人，重采样像每天更新照片；一个怕变样，一个怕认错后将错就错。工程上常见折中是隔几帧更新一次。两条路各有各的错法，选哪条看序列和外观。

实验用八十帧、每帧移动零点一五像素的合成序列。固定模板最终误差约零点零一七像素；每帧重采样模板、加一点点噪声，误差累积到十四点零八像素。这不是说重采样一定不能用，而是说它把当前估计写进了模板：估错一点，下一帧就拿错的样子继续找，误差会滚雪球。工程上还可以用仿射模型把外观变化解释掉；更新越勤，越要小心漂移。误差不是线性增长，是随机游走式累积。

看这张图：左边是跟踪窗口，红框里两个方向都有纹理；中间是固定模板与每帧重采样的误差曲线；右边是仿射细化的残差下降。中间蓝线几乎贴着零，红线一路涨到十几像素，这就是将错就错的直观样子。右边残差从约零点一降到零点零零六，说明仿射参数能把旋转缩放解释掉。三张子图分别回答：跟谁、怎么漂、怎么补。估计一旦写进模板，后面的搜索就沿着错的方向走。

书上第 453 页说，更好的办法是用仿射运动模型，把后来的图像位置和最初模板比较。Shi 和 Tomasi 先用平移模型比较相邻帧，再把平移估计当作初值，初始化当前帧与基帧之间的仿射配准；特征只在跟踪失败的区域重新检测。这套跟踪器后来就叫 Kanade–Lucas–Tomasi，也就是卡纳德–卢卡斯–托马西跟踪器，简称 KLT。KLT 的循环是：预测位置、局部搜索、仿射细化、检查残差；残差太大就丢掉这个点，过一段时间再在跟踪失败的区域补新点，比如纹理太弱、遮挡或运动太快的地方。跟踪点不是越多越好，稳定和覆盖同样重要。这个循环每一帧都跑一遍，不是只在开头跑一次。

实验把目标帧的亮度乘一点八、再加零点一五的偏置。原始平方差搜索的位移误差零点一七一像素；每个候选位置先拟合增益和偏置再比，误差降到零点零六一像素，改善约二点八倍。这就是书上说的显式补偿亮度变化：不假设灰度相等，允许整体变亮变暗。工程上还可以用归一化互相关；它等价于先做线性亮度校正再比形状，代价是多算一点统计量。亮度变化就是乘性增益加加性偏置，拟合两个数。

看这张图：左边蓝框是只估平移的角点，绿框是仿射 KLT，红框是真值；右边是两种模型的角点平均误差。只估平移，角点平均误差四点四零二像素；仿射细化后零点零一一像素，几乎贴住真值。这就是为什么 KLT 不满足于平移：旋转、缩放、透视缩短都会让窗口外观变，仿射给了它六个自由度去解释。自由度不是越多越好，但这里六个刚好。平移只有两个参数，解释不了旋转和缩放。

书上第 452 页把大范围搜索指向金字塔：先用低分辨率匹配给初值，再逐层细化。实验里十像素的位移，局部正负三的搜索只能到边界，误差十三点六零一像素；三层金字塔在粗层覆盖正负十六像素，最后误差零。局部搜索只在家门口找，人已经搬走了当然找不到；金字塔是先看大范围，再看小范围。跟踪大运动时，先问最大位移有多大，再决定搜索范围和层数；范围不够，后面再精细也没用。金字塔每降一层，能覆盖的位移就翻一倍。

书上第 453 页说，Shi–Tomasi 之后长出很多后续：Beardsley 等人把扩展特征跟踪和运动恢复结构结合，从视频增量建稀疏三维模型；Kang 等人把相邻网格块的角点连起来增加稳定性；还有人改进了虚假匹配剔除和特征选择。书上第 454 页又提到学习式跟踪：先用样本块和它们的仿射变形训练分类器，再在整张图里快速找匹配特征，所以能支持更快的运动。一条路是把几何约束加得更紧，另一条路是把长什么样学出来。跟踪器还要和后面的几何估计一起设计：给运动恢复结构用的点，要求长期一致；给增强现实用的点，要求低延迟。两条路的目标一样：让对应点在更长时间里稳定。

书上第 454 页把快速特征跟踪的一个应用叫表演驱动动画：跟踪用户动作，交互式变形三维模型。书上第 455 页的例子先画好眼睛和嘴巴的控制线，运行时由人脸跟踪器定位这些特征；动画系统用最近邻特征外观匹配决定播哪张图，再用三角重心插值做形变，最后把头的位置和朝向也算出来。这套系统的难点不在跟踪单个点，而在让几十个点同时稳定；控制线一抖，动画就会穿帮。工程上会加平滑、加丢失重检，还要处理遮挡和表情突变。最近邻匹配是在预先画好的图里挑一张。

把这一集收成一张工程清单。第一，选双方向都有梯度的点，别选边缘和平坦；第二，相邻帧运动小就用局部搜索，大就用金字塔；第三，亮度会变就做增益偏置补偿或用归一化互相关；第四，长序列别盲目每帧重采样，固定模板和更新模板各有利弊；第五，外观形变大就上仿射，但初值仍要从平移来；第六，跟踪失败要能发现并重新检测。每个开关都对应一个失败模式，先想清楚数据，再选组合。最后一条最容易被忽略：要知道自己什么时候错了。残差突然变大、前后向跟踪对不上、特征跑到窗口边缘，都是失败信号。先把数据看清楚，再决定拨哪几个开关。

带走三句话：好特征是双方向都被约束的角点；跟踪是在小窗口里找最像的块，漂移来自把错误写进模板；仿射 KLT 用平移给初值、用六个参数解释形变。下一集换一条路线：让网络直接从两帧学出稠密光流；RAFT 会把相关体加迭代细化做成端到端。这一集的由粗到细、亮度不变、遮挡处理，在深度学习里换了个名字又出现。KLT 把跟踪拆成可检查的几步，每一步都能单独调、单独测。
