# E060 口播稿 · 人脸检测与行人检测：从滑窗到级联与 HOG

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集讲人脸识别，先找脸、再认脸。这一集从“找”开始。书上第 370 页开门见山：给一张图，比如一张合影，最笨的办法是对每个可能的小窗口都跑一遍识别，又慢又容易错。书上给的出路是造专门的检测器，只干一件事，快速找出“这里可能有东西”的区域。识别回答“是谁”，检测先回答“在哪、多大”。这一集看三站：人脸检测、行人检测，最后交棒给多类检测。

书上第 371 页说，要认脸，先得知道脸在哪、多大。逐像素、逐尺度地跑识别，理论上可以，实际太慢。人脸检测研究做了几十年，可以分成三派：特征法、模板法、外观法。特征法找五官，再看排布；模板法拿整张脸去套；外观法不解释五官，直接让分类器看“像不像脸”。三派的区别，说到底是怎么表示一张脸。

三派各有各的脾气。书上第 371 页说，特征法先找眼睛、鼻子、嘴巴，再检查它们摆得合不合理。第 372 页说，模板法比如 AAM，能应付姿态和表情变化，但要求初始位置就在真脸附近，所以不适合当快速检测器。外观法在图上扫小矩形块，先粗筛候选，再用更贵但更挑的级联细判。为对付尺度，还要建图像金字塔，每层扫一遍。这页的示意图是程序生成的，不是原书原图。

外观法要靠标准答案喂出来。书上第 372 页说，最早的 Sung–Poggio 和 Rowley 两套系统，先收集标注好的脸块，另外收集确定没有脸的块，航拍图、植被图都行。接着把脸图做镜像、旋转、缩放、平移，造出更多样本，让检测器别怕这些变化。同一页的图 6.20 是 Rowley 的结果：五十七个真阳性里，混着一个假阳性。训练检测器，既要教它什么是脸，也要教它什么不是脸。

第一套用聚类加 PCA。书上第 373 页说，Sung–Poggio 把脸块和非脸块各聚成六簇，一共十二簇，每簇拟合一个 PCA 子空间。再用 DIFS 和 DFFS 两种度量，每个簇各算两条马氏距离，十二簇共二十四条，送进一个多层感知器。DIFS 量的是新块投进子空间后离这簇脸中心多远，DFFS 量的是投影丢下的误差多大。可以先理解成把脸分成十二个款式，新块来了，量它离每个款式多远，再让一个小网络做判断。

Rowley 的做法更直接。书上第 373 页说，不用先聚类，直接把二十乘二十的灰度块喂给神经网络，用大小不一的手工感受野同时抓大结构和小细节。这里的感受野，是窗口大小由人设计，不是学出来的。网络对金字塔每层的每个重叠块，输出“这里是脸”的概率。同一个脸附近会有很多块同时响应，所以再加一个合并网络，把重叠的检测揉成一个。先让每个位置表态，再把意见合起来。

第三套换支持向量机。书上第 374 页说，Osuna 等人用 SVM 分类同样的预处理块。SVM 在特征空间里找一组最大间隔的分界面，把脸和非脸分开。如果线性边界不够，就用核把特征升到更高维。它的思路是既要分开，还要分得宽：边界两边留出缓冲带，遇到新样本更稳。

让人脸检测走进普通相机的，是 Boosting。书上第 374 页说，Viola 和 Jones 把 Boosting 引进视觉。做法是训练一串越来越挑的简单分类器，再把它们的输出混起来。强分类器等于弱学习器加权投票，符号决定是不是脸。弱学习器通常就是阈值函数，也叫决策树桩，只看一个特征、一个阈值、一个方向。一个专家不靠谱，就请一群各看一点的专家投票。

Viola–Jones 的特征选得巧。书上第 374 到 375 页说，它不比单个像素，而比矩形区域的亮度差：两到四个矩形，白的减灰的。第 375 页的图 6.22 给了两个例子：第一个特征量眼睛和脸颊的亮度差，第二个量眼睛和鼻梁的亮度差。一旦预计算了积分图，任意矩形差分只要 4r 次加减，r 是矩形个数。积分图是一张速查表，把“一片区域有多亮”变成几次查表。本页示意图是程序生成的，不是原书原图。

有了弱分类器，还要会排练。书上第 375 页说，Boosting 的关键是逐步挑弱学习器，并在每一阶段后给训练样本重新加权。AdaBoost 按这一阶段有没有分对来调权重，再用阶段平均错误率决定每个弱分类器的最终票权。为了更快，可以把分类器串成级联：每一级只用少量测试，就把大量非脸挡在门外，同时尽量放行所有可能的脸。第一道只查最明显的，可疑的才进下一道。

人脸检测没有停在 2000 年代。书上第 375 到 376 页说，后来有特征级联、可变形部件模型、聚合通道特征、神经网络。WIDER FACE 基准汇集了更多新结果，包括 RetinaFace，它把特征金字塔和 RetinaNet 这些检测器的想法合在一起。从手工特征到深度网络，套路没变，还是粗筛加精判，只是每一级的本事都换成了学出来的。

镜头转到行人。书上第 376 页说，早期检测研究盯着脸，但行人、车辆同样受关注。有的方法延续快和省，有的转向准，把检测看成通用类别识别的难版本，要尽可能精确地定出位置和范围。人脸检测像找证件照，行人检测像在街景里找走动的人，背景更乱、姿态更多。书上前面还给过一个例子：只靠人脸会漏人，加上头发和衣服才找全，检测不能只靠脸。

行人检测的代表作是 HOG 加 SVM。书上第 376 到 377 页说，Dalal 和 Triggs 用一组重叠的方向梯度直方图描述子，送进支持向量机。每个 HOG 把梯度按方向投票、按幅值加权。它和 SIFT 很像，但 SIFT 只在兴趣点算，HOG 在规则重叠网格上算；描述子用更粗的网格归一化，而且只在一个尺度、固定朝向上算。为了抓住人轮廓附近的细微方向变化，方向桶用得很多，中央差分也不做平滑。HOG 不看“这是什么点”，它看“这一小块里，边都朝哪边”。本页示意图是程序生成的，不是原书原图。

HOG 之后，SVM 学出一张哪里重要的权重图。书上第 377 页说，把高维连续描述子送进 SVM 训练，图 6.23 画出每个块里最强的正权重和负权重，以及加权后的 HOG 响应。结果是人的头、躯干、脚附近正响应多，毛衣中间和脖子附近负响应多。看人的轮廓，头、身子、脚这三处要当真，中间一片反而别太当真。

再往前走，是部件模型。书上第 377 页说，Felzenszwalb 等人在 HOG 行人检测器上加可变形部件。每个部件在整体模型下面两层的金字塔上训练和检测，部件相对父框的位置也学出来。训练框画得不准怎么办？把父框的真实位置当成隐变量，训练和识别时都推断；部件位置也隐，所以不需要部件标注，能半监督地练。这个系统的扩展版进了 2008 年 VOC 检测挑战的前两名。整体给个大概，部件再各自微调。

书上第 378 页还给了更细的姿态：Rogez、Rihan 等人 2008 年用随机森林在 HOG 上算出行走相位和各个关节位置，输出完整三维姿态，更接近三维人体跟踪；有视频时，光流和运动不连续性能帮大忙。第 378 到 379 页说，Caltech 行人基准和综述盘点了 2012 年前的算法，包括积分通道特征、号称“西部最快”的行人检测器、Poselets 这类三维姿态方法；之后 CityPersons 等数据集继续刷新。一条线很清楚：从“有没有人”，走到“人在什么姿态、往哪走”。下一集，通用对象检测登场，R-CNN 家族怎么把“找候选”交给网络，YOLO 又怎么把检测变成一次回归。
