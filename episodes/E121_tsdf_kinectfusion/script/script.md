# E121 口播稿 · 深度图融合与 TSDF：KinectFusion 的当年明刀

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集从一个问题开始：一帧深度图只能拍到物体的一面，怎么把很多帧叠成一个完整模型？书上把多帧深度图或距离图的对齐和合并放在 13.2.1 节，叫 range data merging，核心工具是截断符号距离函数，英文缩写 TSDF。深度图每个像素给的是一个距离，不是颜色。把距离变成体素里的正数和负数，就能把多帧证据一层一层累起来。这一集只讲融合和 TSDF，ICP 配准留给下一集。我们从一个深度图开始，不假设相机已经会跟踪；跟踪是下一集的事。

书上第 821 页说，三维配准最常用的技术是迭代最近点 ICP。书上第 822 页说，另一种更常用的做法，是计算一个截断符号距离函数，去拟合所有三维数据点。range data merging、TSDF、KinectFusion 这三个词连成一条线：先对齐，再把深度图融进体素，最后从体素里提面。这一集先把融讲透，配准的匹配和求解留给下一集。书上第 821 页也提醒，ICP 只能找到局部最优，全局初值要靠描述子。range data merging 的重点，是把多次观测放进同一个坐标系，不只是给单帧去噪。

先看一个体素。相机看到表面在深度 d，体素自己在深度 z，用 d 减 z，就得到沿这条视线的符号距离。表面之前是正，表面之后是负，这正好对应书上第 831 页说的内负外正。这个正负号不是装饰，它决定零交叉落在哪里。符号反了，表面就会被推到截断带外面，后面的融合全跟着错。如果相机换了朝向，要先把体素坐标变到相机坐标，再算 d 减 z。d 是相机到表面的距离，z 是相机到体素的距离；两者单位一致，减出来才是距离差。

书上第 822 页说，截断符号距离函数拟合所有三维数据点。完整的距离场很大，实际有用的只有表面附近一层。所以只保留负 τ 到正 τ 的窄带，τ 叫截断距离。书上第 822 页还说，VRIP 用游程编码区分空、已见和变化体素，只在表面附近存符号距离。空、已见、变化是三类体素标签；空空间不必逐个体素存，表面附近才存距离值，这样窄带才省得下来。截断既省内存，也把远处噪声挡在门外。但 τ 太小会漏表面，太大又会把错位糊进来。游程编码把连续同类体素压成一段。

书上第 822 页说，每幅距离图先算加权符号距离，再加权平均融合。同一个体素会被很多帧看到，每次观测都有一个 sdf 和一个权重 w。融合就是新的 TSDF 等于旧值乘旧权重，加新观测，再除以旧权重加一。权重可以封顶，避免老观测永远压住新观测；这样既保留历史，又能跟上新帧。实际系统还会按深度质量和入射角给权重，本实验为了看清公式，统一给 1。这一步把很多张深度图压成一个体素里的一个数，也是 KinectFusion 能实时跑的关键。如果新观测明显不可靠，可以给低权重甚至 0，这样它不会污染已有模型。

看图。左图是精确符号距离，中间是单视角 TSDF，右图是四视角融合。书上第 830 页说，三维表面可以用三维体表示的内外函数来构造；书上第 831 页说，指示函数 F 小于 0 在里面，大于 0 在外面。单视角只覆盖 33 个方位，四视角覆盖 72 个方位。绿点是零交叉，虚线是真实圆。一帧深度图只能给你半圈，融合多视角才补得全；单视角的半圈不是算法失败，是物理上没看到。图里只画零交叉，要提三角面，还要再接一步 Marching Cubes。四视角不是随便拍四张，而是相机绕物体一圈，保证每个面至少被看到一次。

看图。左图把每个方位的零交叉半径画出来，右图比较单帧和 20 帧平均。四视角的半径误差是 0.001375。单帧噪声的半径标准差是 0.0339，20 帧平均降到 0.0236。四视角解决看不全，多帧平均解决看不稳，两件事不是同一个收益。左图纵轴故意放大，所以千分之一量级的偏差看起来很大；真实误差只有千分之一量级。还要注意，20 帧平均是同一视角，四视角是不同视角，两个实验不能混成一个。标准差看的是同一批方位上的波动，不是和真实半径的平均偏差。

实验里把符号翻转，零交叉只剩 14 个方位，半径误差变成 0.0495。把远处未观测体素的权重保持 0，它就不会污染表面。TSDF 不是把体素填满就有表面。权重为 0 的地方要当没看见，不能当空，也不能当实。符号、截断、权重这三件事，任何一件错了，零交叉都会跑偏。所以工程上先保证深度图质量和位姿，再谈融合。真实系统更常见的坑，是深度符号约定或者法向朝向搞反，不一定像实验里这么明显。权重为 0 的体素在提面时也不该参与投票，否则会把未观测区当表面。

看图。深度帧进来，先做位姿跟踪，再把这一帧融进 TSDF，然后提面或渲染，给下一帧提供当前模型。书上第 824 页说，KinectFusion 把类 ICP 的 DTAM 和实时 TSDF 体融合结合在一起。跟踪回答相机在哪，融合回答模型长什么样，两个问题交替迭代。跟踪会拿当前模型渲染出的深度图，和当前帧对齐。KinectFusion 的主循环就是这四步；实际工程里还要 raycast、GPU 并行和稀疏体素。跟踪和融合互相喂：跟踪错了，融合会把错位写进模型；融合糊了，跟踪也会漂。

书上第 824 页说，TSDF 体融合在 13.5.1 节有更多细节。但翻到书上第 830 到 831 页，正文讲的是内外函数、符号距离和 Poisson，没有给出截断和权重的完整公式。书上第 831 页确实给了符号距离在规则网格上的查询和 Marching Cubes，但没给 TSDF 的权重更新。所以这一集的 τ、w 和加权平均，是按 TSDF 的通行定义整理的。书上给的是名字、用途和符号距离的定义，不是完整实现。这条边界要说清，不能把通行做法说成书上的原句。定义可以引，工程公式要自己标清楚。

体素越细，表面越准，但内存和计算按三维体积涨。截断 τ 越大，越能容忍位姿误差，但窄带越厚；τ 越小，越省，但容易漏掉表面。书上第 824 页还提到，Octomap 用八叉树和概率占据，Voxel Hashing 和 Chisel 用空间哈希压缩 TSDF。八叉树在远离表面的地方用大格子，哈希只给表面附近的块分配内存，目的都是不被空空间吃光。工程上不是把分辨率拉满，而是让分辨率、τ、哈希策略一起匹配场景。一张桌子扫描和一间房扫描，参数不会一样。体素网格是规则格子，哈希按块挂表，八叉树自适应分层。

这一集的主线是：深度帧先变成体素里的截断符号距离，再用权重累加成 TSDF，最后提零交叉得到表面。下一集讲 ICP，回答多视角点云怎么先对齐；没有配准，融合就会把错位糊成一团。记住三件事：深度图给观测，TSDF 存证据，零交叉给表面；跟踪和融合是一对循环。第 13 章的主线是采集、配准、融合、表面，这一集完成第三步。下一集会讲 point-to-point、point-to-plane 和鲁棒权重，这里不重复。顺序上先讲点云配准，再回到融合，不能反。
