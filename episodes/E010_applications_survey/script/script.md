# E010 口播稿 · 计算机视觉应用大盘点：工业与消费两大类应用

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集结尾我们说，计算机视觉早就落地了：从 OCR 到自动驾驶，视觉都在创造价值。这一集，我们就把这张应用清单整个走一遍——原书第一节的后半部分，一口气列了十九个真实应用。看完全集你会明白：这张清单不只是炫技，它藏着这本书整本的方法论。

本集我把它分成三段。第一段，工业应用十一种，从 OCR 到生物识别；第二段，消费级应用八种，就在你自己的照片和视频里；第三段最重要——原书为什么如此重视应用？因为它决定了这本书讲技术的方式：先有问题、再选技术，还是先有技术、再找问题？两种教法，天壤之别。

原书说：好消息是，计算机视觉今天已经在大量真实应用里工作着。为什么这么重视？原书给了两个理由：第一，这些应用学生本就熟悉，非常能激发学习兴趣；第二，也是更深的——应用能给开放问题加上约束。讲者翻目录还可以发现：标着 Application 的小节散布全书，比如第 3.4.2 节「Application：锐化、模糊与去噪」。本集，就是这张总地图。

工业清单第一组，认字与质检：光学字符识别，认手写邮编，还有车牌自动识别；机器检测——用双目视觉加专用照明，快速测量飞机机翼、车身零件的公差——公差，就是允许的尺寸偏差；铸钢件缺陷，用 X 光成像来找。讲者解读：这两组的共同点是成像可控、任务清晰——视觉最经典的战场。

接着看零售与仓储。零售——自动结账通道和完全无人商店，靠的是物体识别；仓储物流——自主送件的配送机器人、驮托盘的搬运车，还有机械臂抓取零件。讲者解读：这两个场景的共同点是环境结构化、任务边界清楚——把「看懂一切」收窄成「认出这一件」，正是它能大规模落地的秘密。

再看医疗与自动驾驶。医学影像——把术前和术中的图像配准对齐，还有对人群脑形态的长期追踪，研究衰老；自动驾驶——点对点跨城行驶，以及自主飞行。原书引用的文献，从 2008 年一直排到 2020 年。讲者解读：这一组容错极低——估错了，代价不是返工，是事故。

然后是建模与特效。摄影测量——从航拍和无人机照片全自动重建三维模型；电影工业的匹配移动——把计算机生成图像合成进实拍镜头：跟踪源视频里的特征点，估计相机的三维运动和场景形状，《侏罗纪公园》就是一例；它还需要精确抠像，好把新元素插进前景和背景之间。讲者补充一句：从此，镜头里看到的世界，未必真的发生过。

工业清单的最后三项：动作捕捉——演员身上贴反光标记点，多台相机围拍，把动作录给计算机动画；监控——看入侵者、分析高速路车流，甚至盯着泳池防溺水；指纹识别和生物特征——访问认证，也用于司法鉴定，同一个技术的两种严肃用法。原书还推荐了 David Lowe 的工业应用网站：清单远不止这十一个。

列完清单，原书说了一句很清醒的话：这些应用都极其重要，但大多属于相当专用的图像与狭窄领域。然后笔锋一转：除此之外，还有大量消费级应用——就在你自己的照片和视频里。而这一半离我们最近：不用产线、不用无人机，拿自己的照片马上就能体验。专用与消费，正是应用版图的两半。

消费清单第一组：全景拼接——把重叠照片缝成一张无缝全景，第 8.2 节；包围曝光——强光和阴影下的几张不同曝光，合成一张完美曝光，第 10.2 节；图像渐变——把一个朋友的照片平滑变成另一个朋友。讲者补充：其中全景和多曝光合成，很多手机相机已经内置。

第二组：三维建模——把一张或多张快照，变成物体或人的三维模型，第 13.6 节；视频匹配移动与防抖——自动跟踪参考点，把二维图片或三维模型插进视频，或者用运动估计去掉抖动，第 11.4.4 与 9.2.1 节；照片漫游——在一大堆照片之间三维飞行浏览，比如你家内部。讲者注：原书正文把三维建模指向 Figure 1.5d，那张图注写的却是手机 AR——图文互指略有出入，以正文为准。

第三组：人脸检测——让相机对焦更准、图像搜索更相关，第 6.3.1 节；视觉身份认证——家人坐到摄像头前，电脑自动登录，第 6.2.4 节。原书说，这些应用学生再熟悉不过——有趣、跟自己有关，非常能激发学习兴趣。在我看来，一门以数学量大著称的课，靠这些例子接上地气。这门课选例子，也照这个思路。

现在回答第三段的问题：原书为什么如此重视应用？p.8 给出工程哲学：应用能用来表述并约束视觉里那些天生开放的问题——所以要从手头的问题倒推合适的技术，而不是抓住你听过的第一个技术就上。上一集埋的先验与约束，在这里落地。讲者提醒：反过来，先抓技术再找问题，是初学者最常见的弯路。

原书的流程五步：先写详细的问题定义，定下约束和规格；再查哪些技术已知可行；实现其中几个；评估性能；最后择优。配套两类测试数据：合成数据，验证正确性、分析噪声敏感性——对了才谈得上用；真实数据，要贴近最终的使用方式——讲者注：不然实验室里的漂亮指标，到现场全走样。用机器学习，还要数量够、无偏的训练数据。本集实验，演示其中「合成数据」这一环。

但原书强调，这本书不只是工程菜谱。它同时用科学的方式对待视觉的基本问题：为系统建立最好的物理模型——场景怎么形成、光怎么与场景和大气交互、传感器怎么工作、噪声与不确定性从哪来。然后把任务反过来：反演采集过程，得到对场景最好的描述。这套态度，第 2 章整个都在兑现——先立住物理模型，再谈反推。

统计方法，原书说它经常出场：用概率分布建模场景和带噪的采集过程；给未知量配上先验分布——这就是贝叶斯建模，附录 B；给估错配上损失函数，最小化期望风险。原书例子：机器人估计离障碍物多远，低估通常比高估安全——两种错误的代价不对称。脚注还点了一句：物理、几何、统计与优化，本身就是能迁移到别处的基本功。本集实验第二部分，就把这句话算成数。

最后一层：既然视觉大量是逆问题和未知量估计，原书全书重度强调算法。为什么鲁棒这么重要？原书说，很多视觉问题，太容易写出跟真实条件不匹配、或者根本没法稳定估计的数学描述——所以算法第一要对噪声和模型偏差足够鲁棒，第二要在运行时间和空间上足够高效。脚注补了一句：在某些情况下，深度神经网络也能加速过去靠迭代的老算法。书里的算法多是高层步骤清单，细节靠引文和习题补全。

实验：把工程方法论跑成代码。合成一个零件的边缘剖面，用 50% 交叉点做亚像素定位——这是机器检测里测公差的最小样板，也是 E008 采样知识的一次回场。第一问：零噪声时定位准不准？第二问：噪声加大，误差和误判率怎么涨？合成数据验证正确性、分析噪声敏感性——原书那两句话，一次做齐。

结果分三块——讲者设计的实验，参数是演示设定。零噪声时，整数与非整数真值都精确无偏——合成台先证明算法理想情况下是对的。σ 从 0.05 到 0.3 只大六倍，误差放大近三十倍，误判率从 0.6% 飙到 75%——假交叉让算法失去鲁棒性，正是 p.10 要 robust 的原因。右：一比四的代价（我设定）把最优估计压到 0.2 分位数、2.58 米——宁可低估，算成了数。

收个尾，三句话带走。第一句：应用分两大类——十一种工业、八种消费，共同点是把开放问题收窄，给先验和约束留出立足点。第二句：这本书的方法论是从问题倒推技术——先定义问题和约束，再选技术、做实现、评性能，配两类测试数据。第三句：工程之外是科学——物理建模加统计反演，损失不对称时，最优答案偏向安全。后面大部分章节，都是在为这十九个应用里的某一个补拼图。

课后怎么走？回到原书第五到第八页，把应用清单通读一遍，数一数：十一加八，一个不少。再读第八页工程方法那两段——「从问题倒推技术」，是作者自陈的做事方式。读完想一个问题：你的手机里，今天用到了清单里的哪几个？对着十九项数一数，你会发现自己已经在用这门课的半张地图。

留一道作业：把实验的公差从 0.25 像素改严到 0.1 像素，重跑一遍，看每个噪声档的误判率怎么变。再把低估和高估的代价对调，一比四改成四比一，看最优估计从 2.58 米移到哪里——它应该跑到均值上方，变成宁可高估。代码改两行就行。改完你会亲眼看到：公差越严，误杀越多；代价越偏，估计越偏——约束和风险，都是设计出来的。
