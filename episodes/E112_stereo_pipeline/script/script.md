# E112 口播稿 · 立体匹配流水线：代价、聚合、视差、细化

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

这一集把立体匹配拆成一条流水线。书上第 762 页说，稠密对应算法通常只做四步里的若干步：匹配代价计算、代价聚合、视差计算与优化、视差细化。四步不必是四个独立的模块。换一个代价、换一个窗口、换一个优化器，就是另一种算法。代价回答这两个像素像不像，聚合回答周围一小块像不像，视差回答哪个 d 最像，细化回答能不能更准、哪里不可信。全局法常常跳过聚合，直接用数据项加平滑项做整体优化。深度网络可能把几步合进一个网络。分析问题时还是按四步拆。四步可以跳步，也可以合并，这样拆只是为了看清每一步在解决什么。

第一步，匹配代价。书上第 764 页说，最常见的像素代价是平方差和绝对差 SAD。绝对差对异常值没那么敏感，平方差会把大的差异放大。两个都在灰度上算，光照一变就受影响。书上第 765 页说，census 变换把窗口里每个邻居和中心比较，编成位向量，对大幅、非平稳的曝光变化很稳。绝对差的代价是 ｜I_L−I_R｜，平方差是它的平方。平方会把 10 和 1 的差从 9 拉到 81，所以外点的话语权更大。census 不看绝对灰度，只看邻居比中心大还是小，整体变亮变暗不影响位向量。代价函数不是越复杂越好，要看图像有没有曝光差、噪声大不大、要不要实时。绝对差和平方差都很便宜，census 多一层位向量计算，换来的是对曝光变化的稳定。

看图。书上第 763 页用平方差举例：先算每个视差下的平方差，再在固定视差的窗口里求和，最后选聚合代价最小的视差。把所有视差的代价堆起来，就是视差空间图 DSI，横轴是 x，纵轴是 y，深度方向是 d。局部法在 DSI 上做窗口聚合，再逐像素选最小。全局法不聚合，直接用数据项加平滑项做整体优化。DSI 的大小是宽乘高乘视差范围。我们 640×480、搜索 0 到 170，就是 640×480×171 个体素，一共 171 个候选视差。范围越大，内存和计算越大。局部法每算一个视差都要存一张代价图，视差范围一涨，内存跟着涨。

第二步，代价聚合。书上第 766 页说，局部法在 DSI 上按支持区域求和或平均。支持区可以是固定视差下的二维窗口，也可以是 x-y-d 三维支撑。窗口越大，弱纹理越稳。窗口越大，边界也越容易混进另一个深度。同一页说，窗口要大到含足够纹理，又要小到不跨深度不连续。工程上还有可移动窗口、自适应窗口、双边加权、分割区域，它们都在稳和准边界之间找平衡。聚合是给每个候选视差算一个邻域支持分，窗口形状决定支持谁，权重决定谁话语权大。box filter 可以用积分图 O(1) 算每个窗口，这是常用加速。积分图把窗口求和变成几次加减，窗口再大，单个窗口的代价也不变。

第三步，视差计算。书上第 768 页说，局部法在每个像素选聚合代价最小的视差，叫 winner-take-all，也就是 WTA。WTA 很简单，但只在参考图里保证唯一。另一张图的一个点可能被多个点匹配，遮挡区尤其如此。所以局部法后面通常要加左右一致性检查、唯一性约束、中值滤波和补洞。不做后处理，遮挡边缘会出现明显错误。书上第 769 页说，遮挡区可以用左右一致性检查找出来。这些后处理属于第四步视差细化，下一页展开。WTA 的代价曲线上如果有两个差不多的谷，选哪个都合理，这就是重复纹理和弱纹理出错的原因。唯一性约束是一个左像素只能有一个视差，但一个右像素可能被多个左像素选中，所以还要做反向检查。

第四步，视差细化。书上第 768 页说，很多算法先得到整数视差，再做亚像素细化，可以用迭代梯度，也可以拟合代价曲线。最常用的是抛物线拟合：用 d 减 1、d、d 加 1 三个代价拟合一条抛物线，顶点就是亚像素偏移。书上第 769 页说，遮挡区可以用左右一致性检查找出来，再用中值滤波清掉孤立错误，用表面拟合或邻域分布补洞。细化决定深度图能不能用于渲染和测量。抛物线拟合假设代价在最小值附近是二次的。曲线很尖或很平，拟合出的偏移就不可信。补洞可以用最近邻、水平插值或表面拟合，不同填法只影响视觉效果，不会增加真实观测。细化能改善观感，也能标出哪里不可信，但改不了没有观测这件事。

看图，横轴是窗口边长，纵轴是视差误差。我们的合成纹理频率很高，几乎每个小窗口里都有足够的灰度变化。3×3 窗口内部误差只有 0.099 像素，9×9 是 0.182，21×21 是 0.111。边界误差从 3×3 的 5.77 涨到 9×9 的 11.43。这个结果和窗口越大越好的直觉相反，因为合成纹理本身已经够强，小窗口就够用。真实弱纹理场景才需要更大窗口。窗口大小没有固定答案，要看纹理、噪声和边界。书上的取舍原则比某个固定尺寸更重要。注意 21×21 的边界误差比 9×9 还小一点，这是这块合成纹理的边界恰好被大窗口的平均压住了，换个场景结论会变。

实验设置和上一集一样：640×480 合成双目，四层深度 1、2、4、8 场景单位，视差 160、80、40、20 像素，左右图加遮挡。我们比较绝对差和平方差，都用 9×9 窗口。再换 3、5、9、15、21 的窗口看取舍。最后做亚像素、左右一致性检查和补洞。所有统计都剔除遮挡像素和深度边界，否则边界的大误差会把平均拉偏。我们故意保留遮挡，因为真实双目一定有。把遮挡剔掉再比较，等于假装问题不存在。所有方法共用同一对图像和同一有效掩码，比较才公平。

看图。左上整数 WTA，右上亚像素，左下交叉检查判为无效的像素，右下补洞后的视差。交叉检查把遮挡区大面积标出：遮挡区错误率 94.3%，非遮挡区只有 0.2%。补洞把无效像素用同一行最近的有效视差填上，覆盖 97.3%。补洞只是填一个合理值，不是恢复真实深度。遮挡区真实深度本来就没有观测，填出来的值不能当成测量。交叉检查也不是万能的，它只能发现左右不一致，发现不了左右都错成同一个值的情况。所以还要置信度和后处理。补洞后视差图好看多了，但遮挡区的深度仍然是猜的，下游做三维重建时要给这些像素低置信度。

看结果。SAD 9×9 平均误差 0.182 像素，平方差 9×9 是 0.299。SAD 更好，因为它不被大差异主导。1 像素内准确率 99.8%。亚像素这次是 0.202，反而比整数 0.182 差。两者只差 0.02 个像素，并没有明显劣化，这是整数真值下的正常波动。亚像素不是没用，是我们的真值本来就是整数视差，抛物线拟合在尖锐的随机纹理上会被噪声带偏。真实场景的视差是连续的，亚像素才有收益，而且要在平滑、同深度的区域拟合，边界上不要做。如果换成连续深度场景，亚像素通常能把误差从半像素降到零点几个像素。前提是纹理平滑、拟合窗口同深度。

失败边界有几类。弱纹理区域代价曲线很平，WTA 随便选一个。重复纹理会出多个同样低的峰。遮挡区没有对应像素。镜面、曝光变化、运动模糊会破坏亮度一致性。深度不连续处窗口跨两个面。这些错误靠换一个代价函数解决不完，要组合手段：census 或互信息抗曝光，自适应窗口保边界，左右一致性抓遮挡，中值滤波去孤立点，补洞填空洞。还要知道哪些像素不可信，别把补出来的值当测量。运动模糊会把左右图的特征拉成条，匹配窗口对不上。这时先做去模糊或提高帧率，比换代价更有效。工程上先问哪些像素可信，再问深度是多少。

工程选型看场景。要实时、纹理强，绝对差或平方差加小窗口就够。曝光变化大，用 census 或互信息。弱纹理多，用更大窗口、自适应权重或全局法。要边界准，用交叉检查、分割或深度学习。书上第 763 页说，SGM 介于局部和全局之间，用一维优化近似二维代价。SGM 在工业界很常用，因为它在速度、内存和效果之间比较平衡，下一集专门讲它。没有万能参数，只有针对场景的组合。SGM 用多个方向的一维动态规划累积代价，既保留边界，又比全局优化便宜。它不是精度最高，但性价比高。算力足够时，全局法或深度网络可以更好；要在嵌入式上跑，SGM 和块匹配更现实。

这一集收成三件事。稠密匹配是代价、聚合、视差、细化四步，零件可以换。窗口大小是在弱纹理稳定和边界准确之间取舍，合成高频纹理上小窗口反而更准。WTA 只保证参考图唯一，遮挡要靠左右一致性检查和补洞，补出来的值不是真值。下一集讲 SGM：它怎么用多条一维路径近似二维全局优化，为什么在工业界流行，代价和内存又在哪里。这一集拆开看每一步，下一集看它们怎么连起来。记住四步和三个坑：弱纹理、遮挡、边界。下一集见。
