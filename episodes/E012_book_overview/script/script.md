# E012 口播稿 · 本书地图与学习法：从依赖图到符号约定

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

第 1 章的最后一集。前面我们讲了概念、应用和五十年历史，这一集把整本书摊开来看：它怎么组织、该按什么顺序读、符号怎么约定——拿到地图，再上路。

本集四段：先看全书的一张章节依赖图，认出两个基座；再沿十三章逐个点名；然后是课表、工具链和延伸阅读；最后用五条符号约定收尾，顺便给第 1 部做个复盘。

先给一个解放性的消息：原书明说，有些章节与其他章只有松散耦合，不严格必要按顺序通读——想学几何与三维重建，不必先啃反射与着色。讲者按：地图的意义从来不是规定路线，而是让你敢跳。

这就是全书的地图：原书 Figure 1.12。十三个章节盒子，横轴从 2D 摆到 3D，箭头指依赖。讲者把它重绘并做了十五项断言校验，横位与箭头是我们的读图估计——先看全貌，后面逐层拆。

横轴的原话是 2D（what?）对 3D（where?）。讲者按图读出：偏图像一侧的，是图像处理、深度学习和识别；偏几何一侧的，是运动估计、运动恢复结构与 SLAM、深度估计和三维重建；成像、模型拟合、特征、对齐、计算摄影和渲染六章摆在两者之间——图注自称 rough，分界是讲者的粗读。

这个 what–where 借自人类视觉的双通路——原书引了 Goodale and Milner 1992——但图注里作者自己补了一句：不应太当真。讲者按：作者先给自己的比喻打了补丁，读图时别把横轴当定律。

原书图注说，优化和深度学习这类基础技术，被后续章节广泛使用——重绘图里，讲者把这两个基座涂成了深色：第四章模型拟合与优化，正则化和 MRF 的源头；第五章深度学习，第二版的全新章节。讲者按内容把整张地图读成三大模块：基座、2D 图像主线、3D 几何主线；识别和渲染是两大出口，成像章是公共入口——讲者按：这套模块分法与上一页按横轴位置的分法，是两套视角。

地图会随范式重画。第六章识别，第一版排在全书最后，因为它依赖分割、特征匹配这些中间表示；第二版把它提到前面——深度网络能直接学出中间表示。讲者按：上一集的时间线刚演示过「范式改写地图」，这里是第二回。

开始逐章点名。第二章图像形成，把成像拆成几何投影、光度与光学、传感器三件事；第三章图像处理，滤波、傅里叶、金字塔与小波、几何扭曲——几乎所有视觉应用的公共底层。

第四章模型拟合与优化：开篇是数据拟合与插值，然后变分方法加 MRF，顺路引出贝叶斯推断；第五章深度学习：从经典监督学习、前馈网络、卷积，一路讲到 3D、时序与生成网络。

第六章识别覆盖面最广：实例识别、全图分类、目标检测、语义与全景分割，再到视频理解和图文问答——六个小节，是当前研究火力最集中的方向之一。

第七章特征检测与匹配，正文说它是第八、十一两章和实例识别的地基；讲者读图：原书图上没有画七到十一、八到十一的直连箭头，依赖经由八、九两章中转——这是讲者的读图解读，正文另有直说。第八章对齐与拼接，先讲特征配准，再做全景拼接——原书特意说，它是期中项目的好题材。

第九章运动估计，核心是光流：从平移、参数、样条到逐像素，最后是分层与学习模型；第十章计算摄影，HDR、超分、编辑合成、纹理修补与风格迁移。

第十一章结构从运动与 SLAM：两帧、多帧，再到定位与建图，直通增强现实和自主导航；第十二章深度估计：立体匹配相当于已知相机的运动估计，还有从单张图推断深度的算法。

第十三章三维重建：shape-from-X 家族、主动测距、建筑人脸人体三类参数化模型，加外观建模；第十四章基于图像的渲染：视图插值、光场、视频纹理，最后停在新兴的神经渲染。附录 A、B、C 收着数学与数据集的补给。

怎么用这本书？原书把习题分了三类：书面作业、一周小项目，还有开放研究题——可以做成有挑战性的期末项目。作者还提醒：前提是你有时间——亲手实现并验证过的算法，长期看比从库里拉黑盒更值钱。

讲者按：这也是本课的设计——每集都有「亲手做实验」，代码只依赖 Matplotlib 和系统中文字体，跑得通、改得动，积少成多就是你的个人视觉库。

如果对编程语言没有强烈偏好，原书推荐 Python 加 NumPy 加 OpenCV。数组记号和线性代数是将来上 PyTorch 的地基；Jupyter 笔记本能把教程、示例和待补代码放在一处；想在云端跑笔记、训模型，脚注十指向 Google Colab。

课表方面作者很坦诚：一学期教完全书是项浩大工程，很可能不值得硬试——他给出了十三周的样例课表：第一周合讲一、二两章，四、五两章占去第三、四周，其余大约一周一章；斯坦福、伯克利、密歇根干脆把内容拆成两门课。

作者和 Seitz 的十周课里，本科版轻数学、重复习，研究生版深挖技术。讲者按：挑着教不等于丢覆盖——这正是跳读地图的用法。

对照我们自己：本课先铺八集数学工具箱，再用四集走完第 1 章，然后逐章展开正篇——讲者归纳：两者都是先打基础、再进专题。原书课表前四周：第一周讲一、二章，第二周第三章，第三、四周讲四、五章，随后才是各路专题。依据是 Table 1.1 的课表顺序。

最后是符号约定——讲者归纳成五条：向量小写粗体，矩阵大写粗体，标量斜体；向量默认列向量、右乘矩阵；常用记号 R 旋转、K 标定、I 单位阵；齐次坐标加波浪号；叉积矩阵写成方括号叉。

原书吐槽：别的教材的记号「五花八门」——原文俚语是 all over the map。讲者按：正因如此，这五条约定值得先立好——从下一集起，每个公式都按这套写。

想读得更深，原书开的书单：数学方向，Golub 与 Van Loan 的矩阵手册、Strang 的线代；机器学习方向，Bishop 2006——原书评它 wonderful——还有 Murphy 2012；深度学习入门，原书评 Glassner 2018 是很好的入门书；视觉方向，Hartley 与 Zisserman 等经典可作他山之石。原书自称自成一体：不做外部功课，也能完成基础习题——但预设你已熟悉线性代数、数值方法和图像处理。

第 1 部四集至此收官：E009 讲视觉是逆问题；E010 数了十九个应用、讲「从问题倒推技术」；E011 走完五十年；这一集装好地图。

数学工具箱八集已在前就位，正篇自第 2 章开始。讲者按：第 1 部完结，下一集起进入成像。

本集实验：把 Figure 1.12 重绘成可验证的图。十三个盒子标签人工誊录自原书 p.23；横位与箭头是讲者读图估计——原书没给数据表；代码跑十五项断言。

十四项数据断言加一项同步检查，全过：编号 2 到 14 各出现一次；依赖图无环、可拓扑排序；唯一入度为零的起点是第二章；终点是识别和基于图像的渲染；实测两个基座各出两条边；横位三段有序，偏图像、居中、偏几何。讲者按：这些是对读图数据自身的自洽检查；对照你手里的原书 p.23，看看讲者的读图和你的读法差在哪——这本身就是一次绝佳的读图练习。

收尾两件事。第一，读原书 §1.3 到 1.6，对照 Figure 1.12 读；第二，作业：在依赖图上画出你自己的学习路径——先 2D 侧还是先 3D 侧，给出依赖依据。
