# E008 口播稿 · 图像即函数：采样、量化与混叠

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

数学工具箱第八站，也是最后一站：采样与量化。上一集结尾说，带着卷积这块棱镜，下集见——现在兑现：连续的光，怎么变成一格一格的像素？偷工减料时，高频又会怎样假扮低频来骗你？十分钟，讲清图像即函数。

先看全景。原书图二点二三画出数码相机的完整流水线：场景辐射经光学与光圈，到达传感器；曝光由快门控制，感度由增益、也就是 ISO 决定；模拟信号经模数转换器 ADC 变成数字，得到 RAW；再进图像信号处理器 ISP：去马赛克、降噪锐化、白平衡、伽马曲线、压缩，最后封装成 JPEG。传感器分 CCD 与 CMOS 两族：CCD 像传水桶接力，把电荷一桶桶传到出口；CMOS 在每个像素内部就地读出——今天大多数数码相机用 CMOS。噪声会在多处混进来；讲者加一句解读：混叠的主现场，在采样这一步。

传感器参数，原书一口气列了七个：快门、采样间距、占空比、芯片尺寸、增益、噪声、ADC。本集挑三个几何参数细讲。采样间距：相邻感光单元的物理间距——越小越密、分辨率越高，但单元也越小，攒不住光子、更易噪。占空比：有效感光面积占可用面积的比例，越高越好——多进光，还少混叠；为什么，本集后半揭晓。早年间电子电路占了单元间的地皮；如今背照式加微透镜，已基本移除这个限制。还有芯片尺寸：卡片机是小底，单反接近 35 毫米全幅——芯片大，单像素更集光。

光变电之后还有三道关。第一道增益：传统视频相机由自动增益控制接管；静态相机做成 ISO 档位——利于暗光，常连噪声放大。第二道噪声：固定图案、暗电流、散粒、放大器、量化噪声；低光下光子计数稀疏，泊松模型可能比高斯更贴切。最后模数转换看标称几位、真正可用几位。JPEG 标称八位；部分单反 RAW 标称十六位——通常超过可用位数。位数不足什么样？右图把平滑渐变量化到二、四、八、十六级：级数越少条带越粗——这就是量化噪声的长相。

主菜：混叠。原书图二点二五画了两根正弦：蓝波频率四分之三，红波频率四分之五，都按采样率二采样——黑点一比，两组采样完全相同。这叫混叠：alias，本义是别名——同一组采样点，对应两个名字。为什么糟糕？看着采样，你根本不知道原来是谁：重构无从谈起。下面实验图是本集代码复现的：左半两根波与共同的采样点，代码验证两组采样逐点一致，偏差只有十的负十五次方量级。

有没有下限？香农采样定理：最小采样率，至少是信号最高频率的两倍——式二点一零三：采样率 fs 大于等于二倍 fmax。术语对齐一下：原书把信号里的最高频率叫奈奎斯特频率，把最小采样频率的倒数叫奈奎斯特率；而下文说的奈奎斯特极限，指的是采样频率之半——工程口语里最常用的就是它。脚注还严谨地补了一句：定理的精确版本是对带宽说的；拍照时没有调制信号，用最高频率足矣。右图是本集的防御思路预览：只要让全部频率站到 fs/2 虚线左边，折返假扮就无从发生。

那把感光单元铺满整个格子——占空比百分之百——混叠就消失了吗？没有。铺满确实压掉了一部分高频，但超过奈奎斯特极限的频率，只是变小了，照样混叠。图二点二五右图：过完百分之百的方盒，蓝波只剩三成，红波剩负百分之十八——负号是倒相：红波的采样，看起来成了蓝波的缩小反转版，这是图注原话给的数字。讲者核算一道：方盒宽取一——也就是两个采样间距——频响 sin πf 除以 πf，零点七五处正零点三、一点二五处负零点一八，与图注一致；宽若只取一个间距，得正零点七八、零点四七，不再倒相——图注数字依赖宽一这个约定。混叠没死，只是化了装。

平滑图像上的混叠还不够直观，看条纹。图二点二六的啁啾图，本集按从左到右越来越密复现。四倍降采样，三种滤镜：四分之一占空比的方盒——感光面很小——高频条纹直接变成肉眼可见的假纹；百分之百方盒，假纹淡了些但仍在；九抽头高质量滤镜，图注原话：彻底清除。九抽头的具体系数原书没给，实验代码用截断 sinc 代演，讲者选择，画面已标注。度量也算个数：右半区假纹振荡幅度，二十五占空比零点三五四，百分百方盒零点零六八，九抽头零点零一零——压到三十五分之一。

怎么预估一台相机混叠多少？点扩散函数 PSF：对理想点光源，像素传感器的响应。它由两部分卷积而成：镜头的模糊，加芯片的有限感光面积——原书脚注补一句，传感器前通常还压一片光学抗混叠滤镜。把 PSF 做傅里叶变换、取幅值，就是调制传递函数 MTF；混叠量，约为 MTF 越过奈奎斯特线之外的那块面积。图二点二七：散焦越重——模糊盘直径从半个间距到两个间距——混叠显著减少，但靠近极限的细节也陪葬。实验室量 PSF：针孔到像素级；亚像素靠倾斜阶跃边缘标定。

兑现上集那把钥匙。三点四节用一个实验定义傅里叶变换：把复正弦——e 的 jωx 次方——喂给滤波器，输出还是同频正弦，只是幅值变 A、相位挪 φ。逐频记录 A 与 φ，就是傅里叶变换 H(ω)，与 h(x) 成对出现——滤波器的频率指纹。于是卷积定理水到渠成：空域卷积，等于频域相乘——上集埋的话在这里落地。离散版叫 DFT，式三点五七；k 只在正负 N/2 内有意义——再大会和低频混叠，回收本集主题。快速算法 FFT，O(N log N) 次运算，蝶形结构。

有了频率语言，上集那批常用核可以体检了。表三点一把图三点一四各核的频响写成闭式：方块三，一加二倍余弦 ω 除以三；方块五、帐篷、二项式各有一条曲线。原书读表三句话：滑动平均不均匀地压高频，会振铃；二项式核——拉普拉斯金字塔里的高斯替身——高低频分得不错，但仍漏相当多高频，降采样后可能混叠；索贝尔先线性放大、后在高频衰减，细尺度边缘——相邻黑白条纹——就难以检出。实验代码把六条曲线全部画出来，与逐点 FFT 对照，最大偏差十的负十六量级。

压缩为什么爱用 DCT？它把能量扎堆在头几个系数。离散余弦变换，是傅里叶变换的实数变体，特别适合分块压缩：一维式三点六二，把 N 长的像素块与一组余弦做点积；二维式三点六三，横竖各一次，可分离、也是 O(N log N)。JPEG 把图切成八乘八的块独立变换、量化——第一个基函数编码块平均值。右图实验：每块只保留十六、六、三系数，噪声先没了，圆盘还在；丢到三系数，块边界显形——这就是块效应；JPEG2000、JPEG XR 改用小波或重叠变换来解。

收个尾。讲者总结一句话：采样，是把连续世界切成格子；混叠，是格子太粗时，高频假扮低频来骗你——防御只有一招：先低通，再采样。暗线：上集的卷积定理——空域卷积、频域相乘——在这里从一条性质，变成了防混叠的处方。

想读原书：二点三节数码相机，七十九到一百页——传感器七参数在八十一到八十四页，重点二点三点一节采样与混叠，八十四到八十七页，图二点二五到二点二七、式二点一零三；三点四节傅里叶变换，一百四十三到一百四十八页——式三点五二到三点五七、表三点一、DCT 式三点六二到三点六三；更早版本的傅里叶性质表，作者指路二零一零版的三张表。作业在代码里，三问：换频率与相位，看采样何时重合、何时倒相；把宽取一的方盒换成帐篷核，重算三成与负十八；自设计九抽头滤镜，比比假纹。
