# E065 口播稿 · 为什么需要“特征点”：跟踪、配准与检索的地基

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

前六集把识别这一章从头走到尾：分类、人脸、检测、分割、视频、语言。书上第 419 页说，特征检测与匹配是许多计算机视觉应用的基础零件。上一章回答看懂了多少，这一章换一个问题：两张图里的同一个点，怎么找、怎么对。书上同一页说，本章先看两对图，再想该找什么样的特征。这一集先把这些概念讲清楚，下一集从角点检测开始动手。

书上第 419 页给了两对图。第一对想把两张图对齐，无缝拼成一张全景。第二对想建立一组稠密对应，重建三维模型，或者生成中间视角。一个要拼起来，一个要立起来，第一步都是先找到能对上的点。两对图问的是同一件事：哪些点能对上。书上第 420 页的图 7.2 就问，这两对图该用什么特征来建立对应。

书上第 419 页先介绍特征家族。第一类是点，例子有山峰、楼角、门洞，还有形状特别的雪块。这类局部特征叫关键点、兴趣点，或者角点，用周围一小块像素的样子来描述。书上第 418 页的图 7.1 把点状兴趣点、描述子、边缘、直线、区域和分割排在一起，说明它们都能用来分析、描述和匹配图像。

第二类是边缘，比如山脊和天空的交界。书上第 419 页说，边缘可以按方向和局部外观来匹配，也常是物体边界和遮挡事件的信号。边缘还能连成更长的曲线和轮廓，轮廓可以一路跟踪。所以边缘提供的不只是位置，还有方向和边界信息。这条边界在两张图里都能看到。

边缘也能组成直线段。书上第 419 页说，直线段可以直接匹配，也可以拿来求灭点，进而求相机的内部参数和外部参数。从一条边，走到一条轮廓，再走到一组直线，信息越来越结构化。轮廓回答边界在哪，直线回答空间往哪退。这也是为什么边缘、轮廓、直线，和关键点一样，都是本章的主角。

书上第 419 页说，这一章会讲检测这些特征的实用方法，也会讲怎么在不同图像之间建立对应。点特征用途太广，7.1 节的算法值得读，更值得亲手实现。边缘和直线是补充信息，很适合描述人造物体的边界，但在短课里可以跳过。所以点特征是主课，边缘和直线是选修，先把主课学扎实。后面的角点和描述子，都建立在点特征上。

本章最后一部分讲自底向上的非语义分割。书上第 419 页说，这些方法曾经是识别和匹配的重要零件，现在大多被 6.4 节的语义分割取代。它们偶尔还用来把像素分组，让匹配更快、更稳。老工具没有消失，只是从台前退到了辅助位，需要快速分组时还会请它出来。这就是它今天的位置。

接着说对应点能做什么。书上第 419 到 420 页说，点特征能找到一组稀疏的对应位置，常常是求相机位姿的前一步；有了位姿，才能用立体匹配算更稠密的对应。这些对应还能用来对齐图像，比如拼全景、拼高动态范围照片、做视频稳像。它们也大量用于物体实例识别。稀疏的点先给出大致位置，稠密的对应再补细节。

关键点的一大优势，是即使有杂物遮挡、尺度变化、旋转变化，也还能匹配。书上第 420 页说，基于特征的对应方法从早期立体匹配就开始了，Hannah 1974、Moravec 1983、Hannah 1988 都是早期工作。后来它在图像拼接和全自动三维建模里流行起来，论文线索从 1970 年代的立体匹配，排到 2000 年代的拼接与运动恢复结构；Zoghlami 1997、Snavely 2006、Brown 与 Lowe 2007 都是代表。它不要求两张图一模一样，只要求那几个记号还在。

找特征点有两条主要路线。书上第 420 到 421 页说，第一条是在一张图里找特征，再用局部搜索去跟踪，比如相关或最小二乘。第二条是在每张图里独立检测，再按局部外观匹配。前者适合近视角、快速连拍或视频；后者适合大运动、大外观变化，比如全景拼接、宽基线立体和物体识别。一条是顺着找，一条是各自找完再比长相。两条路线没有绝对的好坏，只看场景。

书上第 421 页把关键点检测与匹配拆成四个阶段。检测，是在每张图里找在别的图里也可能匹配得好的位置。描述，是把关键点周围区域变成更紧凑、更稳定的描述子，好拿去和其他描述子比较。匹配，是在别的图里高效搜索候选；跟踪，是只在每个特征附近的小邻域里搜索，更适合视频。找得到、说得出、配得上、跟得住，四个词就是这一章的主干。四个阶段合起来，才是一次完整的对应。

检测阶段的关键，是换一张图也找得回来。书上第 421 页说，每张图都要搜出那些在其他图里大概率匹配得上的位置。所以检测不是找最显眼的点，而是找最稳的点。只在原图里显眼、换个角度就消失的，不算好特征。好特征像路标，从不同角度看还是认得出。稳定性比显眼程度更重要。

描述阶段，把关键点周围的区域转成一个更紧凑、更稳定的描述子。书上第 421 页说，这个描述子要能和其他描述子比较，所以越稳定越好。检测回答在哪里，描述回答长什么样；位置加长相，才能跨图对上号。描述子不必越复杂越好，关键是变化下还能比较。描述子的好坏，直接影响后面的匹配。

匹配阶段，在别的图里高效搜索可能的匹配候选。书上第 421 页说，跟踪是匹配的替代路线，只在每个已检测特征附近的小邻域里搜，所以更适合视频处理。全图找像大海捞针，跟踪像顺着上一帧的位置找；一个不怕大跳，一个擅长小步快跑。所以视频里常用跟踪，跨大视角配准时常用独立检测再匹配。搜索范围的大小，决定了它适合什么场景。

书上第 421 页说，这些阶段的一个精彩范例，是 Lowe 在 2004 年那篇 SIFT 论文，讲尺度不变特征变换怎么一步步做出来。想系统看替代方法，可以读特征检测和描述的系列综述；Shi 与 Tomasi 在 1994 年、Triggs 在 2004 年，也给了经典方法的回顾。SIFT 是把四阶段串起来的那条主线；后面两集，我们会把尺度和描述子拆开，一步步重走。

书上第 421 页的图 7.3 提醒我们，有些图块就是比另一些更容易定位、更容易匹配。平坦的雪地，放哪都像；一条直的边缘，沿着线滑动也像；只有拐角，横竖都有变化，才最容易钉住位置。这个直觉，下一集用结构张量算出来，从为什么需要特征点，走到角点怎么找。本章先把特征家族和四阶段讲清，后面的算法才有地方落脚。可定位性决定了匹配的精度。
