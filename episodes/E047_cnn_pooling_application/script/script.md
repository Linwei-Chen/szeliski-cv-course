# E047 口播稿 · 打开 CNN 的脑壳：感受野、池化与特征图演化

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集我们把卷积层拆开看了：局部窗口、多通道、权值共享，卷积怎么算已经清楚。但卷积网络不是只有卷积这一种层。书上第 295 页说，比部分卷积更进一步的是门控卷积：每个像素的遮罩不再由人给，而是由上一层用一个可学习的卷积加上 sigmoid 非线性自己算出来。这样网络不仅能学逐像素的置信度，还能把用户画的草图这类额外特征一起融进来。卷积负责提取特征，这一集讲它的搭档池化：把特征图变小，让网络看得更整。

这一集的范围是书上 5.4.1 节的池化和上池化，加上 5.4.2 节的数字分类应用。路线是：池化两件套、最大池化反传那把开关、把图再放大的转置卷积、缩放组合的 U 形网络，最后看 LeNet-5 当年怎么进银行的自动柜员机。下一集才是卷积网络的架构演进史，这一集先把积木攒齐。

书上第 295 页说，步长大于一可以用来降低某一层的分辨率，比如 AlexNet 的第一卷积层就用了步长四。当卷积核里的权重全都相同、加起来等于一，这就叫平均池化，通常按通道逐个来做。平均池化不是新层，它就是一次特殊的卷积：窗口里的权重全部一样，取个平均值。窗口跳两步，特征图边长就缩一半。每个输出数字的视野，就是它在原图上罩住的那一小块，也就是常说的感受野。

同一页说，一个被广泛使用的变体，是取方形窗口里的最大响应，这叫最大池化。常见的 stride 和窗口大小是 stride 二、二乘二不重叠窗口，或者三乘三重叠窗口。平均池化是大家都算上、取平均；最大池化是谁最强听谁的。窗口里只要有一个位置响应够强，输出就够强。屏幕上这张程序生成的示意图，就是二乘二窗口、步长二的做法：每个窗口留最大的那个数。

书上第 295 页说，最大池化层可以想成一种逻辑或：池化区域里只要有一个单元被点亮，输出就被点亮。它们还被认为能给输入带来一些平移不变性。然而大多数深度网络并没有那么强的平移不变性，这会损害它们的性能。Zhang 2019 年的论文对这个问题有很好的讨论，还给出了一些简单的缓解建议。开关并联，随便哪一路通电灯就亮，最大池化就是这么个并联开关。位置信息本身可能也是特征，一刀切抹掉反而变笨。

书上第 295 页问了一个常出现的问题：怎么通过最大池化层做反向传播？最大池化这个算子像一把开关，把某个输入单元转接到输出单元。所以在反向传播时，我们只需要把误差和导数传给那个响应最大的单元，前提是我们记住了当时是哪个单元最大。上一集全连接层反传是把梯度分给所有连线；最大池化更干脆：正向谁赢了，反向谁领走全部梯度，其他位置一分钱都拿不到。所以反传时要额外记一张胜者位置表。

同一页说，同样这套最大上池化机制，可以用来搭一个反卷积网络，在寻找最能激活某个特定单元的刺激时用得上，这是 Zeiler 和 Fergus 2014 年的工作。那张图在书上的可视化小节，本课程到后面讲到看懂网络在想什么的时候再回来兑现。现在你只需要记住：上池化和卷积的组合，就是把网络倒着跑一遍的探针。

书上第 295 页说，如果想要更连续的行为，可以构造一个对输入计算 Lp 范数的池化单元；当 p 推到无穷大时，它实际上就是对各分量取最大值。不过这种单元计算量更大，实践中用得不多，除了有时用在最后一层。在那里它叫广义平均池化，或者动态平均池化。把最大池化想成 Lp 家族的极端成员：p 越大越偏向只看最强，p 等于二就是平方和开根号的折中，推到无穷大就退化成最大值。

同一页说，在同一篇论文里，Springenberg 他们也展示了：用带步长的卷积代替最大池化，也能拿到有竞争力的结果。这句在现代网络里很重要。很多新架构不再单设池化层，直接用步长二的卷积一步到位：既降分辨率，权重还是学出来的。池化这个零件正在被卷积自己吃掉。但最大池化并没有消失，至少在它的原生场景里，它还是那个又快又稳的默认值。

书上第 296 页说，上池化可以近似地逆转最大池化的效果；而如果想逆转一个卷积层，可以看第 3 章学过的插值算子的可学习变体。最直观的理解方式：先在输入像素之间插入额外的全零行和全零列，再跑一次普通卷积。这个操作有时叫带分数步长的反向卷积，但更常见的名字是转置卷积，因为把卷积写成矩阵形式时，这个操作等于乘一个转置过的稀疏权重矩阵。卷积让图变小，转置卷积反过来让图变大：先撒零撑大，再用可学习的卷积核把零填成内容。步长在这里含义也反了：指定的是放大倍数。

同一页说，把降采样和升采样组合起来，就能得到各种多分辨率图像处理任务想要的网络，比如像素级语义标注、图像去噪与超分辨率、单目深度推断，还有神经风格迁移。先把网络分辨率压低再展开的想法，有时叫瓶颈，和更早的自编码器自监督训练一脉相承。书上第 298 页说，这类想法最早的应用之一是全卷积网络；它启发了大量后续架构，包括沙漏形的反卷积网络、Ronneberger 的 U-Net、带 CRF 精修层的空洞卷积网络，还有全景特征金字塔网络。书上第 297 页的图注说，除了瓶颈，U 形网络还有跳跃连接：编码和解码两侧同样分辨率的层直接连线。U 形图就看两个关键词：瓶颈，中间最细处把图压得最小；跳跃连接，细节抄近路回到解码侧。

书上第 298 页说，后面讲到去噪与超分辨率、单目深度推断、风格迁移的章节里，还会看到这类主干网络的更多用途。U 形结构不只在分割里用。凡是输入输出都是图的任务，几乎都是这个结构打底。卷积网络怎么看图，到这里就打开了：压下去提语义，放大来回细节。

书上第 298 页说，卷积神经网络最早的商业应用之一，是勒昆等人 1998 年的 LeNet-5 系统，就是上一集 Figure 5.33 里那个架构。它包含了现代卷积网络的大多数元素，虽然用的是 sigmoid 非线性、平均池化，输出端用的是高斯 RBF 单元而不是 softmax。这个网络在 1995 年前后由 AT&T 部署，用来自动读取存入 NCR 自动柜员机的支票，核对书写金额和键入金额是否一致；后来又并入 NCR 的高速支票读取系统。书上第 299 页说，这些系统一度处理着全美百分之十到百分之二十的支票。三件事：LeNet-5 比 AlexNet 早十七年；用的池化是平均池化，今天的默认最大池化当年不是首选；而且它不是论文玩具，是真在银行系统里跑生产的系统。

书上第 299 页说，如今 LeNet-5 架构的变体，仍是课程和教程里第一个被介绍的卷积神经网络。虽然当年训练它的 MNIST 数据集还在用，但更常见的是换更有挑战性的 CIFAR-10 或 Fashion MNIST 来做训练和测试。想亲手玩这个网络，可以试试卡帕西的浏览器演示，在网页里就能跑一个手写数字识别的卷积网络。留两道作业。第一道口算：一个四乘四的输入、二乘二的池化窗口、步长二，最大池化之后的输出是几乘几？第二道思考题：最大池化的反传只把梯度给最大的位置，如果窗口里两个位置并列最大，梯度该怎么分？去查查你手头框架的实现，和直觉对一对。下一集我们把 AlexNet、VGG、GoogLeNet、ResNet 四代架构排在一条时间轴上，看看错误率是怎么从四分之一掉到百分之三点几的。
