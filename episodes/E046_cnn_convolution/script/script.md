# E046 口播稿 · 卷积神经网络：为图像而生的归纳偏置

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集我们把梯度变成了更新：随机梯度下降、动量，还有 Adam 家族的优化器。到这一步，训练一个深度网络的所有零件其实都齐了。书上第 291 页说，前面几节还漏了可能是图像处理里最关键的一个部件：可以训练的多层卷积。前面讲的全连接层，每个神经元要跟上一层所有数字连线。一张图片几十万个像素，全连起来参数会多到学不动。全连接还有个更深的毛病：它把每个像素位置当成独立的输入。同一只猫出现在左上角和右下角，对它来说是两回事，得分别再学一遍。图像天生的两条规律，邻近的像素才相关，同样的模式挪个位置还是它，全连接层一样都没用上。卷积层就是为图像量身定做的接法，这就是“归纳偏置”的意思：把图像长什么样，提前设计进网络结构里。

书上第 291 页还说，卷积网络的想法因勒昆团队 1998 年的手写数字识别网络 LeNet-5 而流行。这个网络多层卷积和下采样交替，最后接几层全连接，输出十个数字各一个得分。更早的先驱是福岛邦彦 1980 年提出的类似结构，只是那时还没有梯度下降训练。卷积这个想法本身，比深度学习热潮早了几十年。

书上第 291 页说，卷积网络不再让一层的所有单元连到上一层所有单元，而是把每层组织成一张张特征图，可以想成一层层平行的平面或者通道。在卷积层里，加权和只在一个小局部窗口里做，而且所有像素用的权重都一样，就跟普通图像卷积一样是平移不变的。拿一个三乘三的小窗口，从左上角开始，窗口里九个数字各自乘上对应权重、加总，得到输出的一个数。窗口往右挪一格，再算一个；一行算完挪下一行，直到扫完整张图。每个位置用的都是同一套九个权重。这就是两条归纳偏置：看局部，每个输出只看输入的一小块；权值共享，同一套权重扫过整张图。

它跟图像卷积还有一个关键差别。书上第 291 页说，传统卷积对每个颜色通道用同一个滤波器，而神经网络卷积会把上一层所有输入通道的激活线性组合起来，并且每个输出通道各配一套卷积核。输入通道要融合，输出通道各自负责，每一张输出特征图都有自己的专属滤镜。右边这张示意图是我们程序生成的，不是原书图的复制：三张输入通道进，两张输出通道出，窗口在每张通道上同步滑动。

书上第 292 页说，每个输出通道配一个窗口乘输入通道数的核权重，所以一层可学参数总量就是窗口格数乘输入通道数乘输出通道数。原书图里的例子：六个输入通道、四个输出通道、三乘三的窗口，一共九乘六乘四，二百一十六个可学权重。本集实验复算，九乘六乘四等于二百一十六，对上了。计算量也是一笔账：卷积要在宽乘高每个像素位置都做一遍，所以每层的乘加次数就是宽乘高乘九乘六乘四。实验里十乘十的输入卷到八乘八，乘加一万三千八百二十四次，和公式严丝合缝。一个输出点要算九乘六乘四：窗口九个位置、六个输入通道各乘一遍，再给四个输出通道各来一套。四项相乘，就是这层的总账。通道数是平方级放大的，这也是后面网络设计里控制通道数的原因。

书上第 292 页说，这很好理解，因为卷积层的主要任务就是构造局部特征，再把它们用不同方式组合起来，得到更有区分度、语义更强的特征。还记得第 3 章手写的边缘检测器吗？卷积网络的第一层学出来的，常常就是这类东西，只不过滤波器的系数不再是手写的，而是训练出来的。底层学边缘和色块，中层学纹理和部件，高层学整块物体的部件，逐层组合，语义逐层升级。深层的网络能提取什么特征，原书 5.4.5 节有可视化，之后那集再细看。

书上第 292 页把这些直觉放在一起，把卷积层的加权和写成一条式子：输出通道上某个位置的值，等于把上一层所有输入通道、窗口里的每个偏移位置，各自乘上对应权重再加起来，最后加上这个输出通道自己的偏置。跟全连接层的加权和比，就是多了两层加法：一层加在窗口的九个偏移位置上，一层加在所有输入通道上，最后加一个偏置。记号看着吓人，其实每个位置乘哪个权重、每个通道占多少分量，全是可训练的。权重却只有一小撮，还得所有位置共用。

书上第 292 页还提醒一个细节：因为偏移是加到像素坐标上，而不是从坐标里减掉，这个操作严格说是互相关，不是数学意义上的卷积。不过这个区别通常被一笔带过。为什么无所谓？因为核里的权重是训练学出来的，它要翻转就自己翻转。原书脚注 37 说得直白：权重既然是学出来的，这个翻转就真的不要紧。

书上第 293 页说，在网络结构图里，通常标出卷积核大小和通道数，图像尺寸有时才标。有些网络，比如 GoogLeNet 的 Inception 模块，用一乘一的卷积。它其实不做卷积，而是在每个像素位置上把各个通道混合起来，目的常常是压缩特征空间的维度。一乘一卷积就是个逐像素的全连接，只混通道，不看邻居。

书上第 293 页说，因为同一个核权重在这一层的所有像素上都是同一套，这些权重其实是被共享的。如果画成全连接那种连线图，等于把所有像素之间的连线都捆成了同一组。这意味着要学的权重比全连接层少得多；也意味着反向传播的时候，核权重的更新量要把这一层所有像素的贡献加起来。这个差距有多大？本集实验算了同一任务：全连接要十几万根连线，具体是十五万三千六百；卷积只要二百一十六个权重，相差七百一十一点一倍。一条连线千处使用；训练时，千处的梯度沿着这条线汇成一笔。参数少，还不怕平移。

书上第 293 到 294 页说，要完整确定一个卷积层的行为，还得再指定几个参数。第一个是补边：早期的网络像 LeNet-5 不补边，图像卷一次就缩小一圈；现代网络可以选补边的宽度和方式，比如补零，或者复制边缘像素，跟第 3 章传统图像处理的选项一样。第二个是步长：卷积缺省每像素一步，但也可以每隔几行几列才算一次，比如 AlexNet 的第一层步长就是四；传统的图像金字塔构塔时步长是二。不补边会缩多少？三乘三的窗口，宽和高各缩两格。卷得越深图越小，边缘能参与的计算也越来越少；补上一圈，卷完尺寸就能保住。

书上第 294 页说，第三个是膨胀，也叫空洞卷积，在采样点之间插入空隙，跳过一些行列。原则上可能带来混叠，但好处是用更少的运算和参数，覆盖更大的区域。第四个是分组：缺省情况下每个输出通道都用上全部输入通道，但也可以把输入输出分成几组各自卷。一组就是常规卷积；组数等于输入通道数时，每个输入通道独立卷，这叫逐通道卷积。膨胀是看得更广：同样三乘三的窗口，隔一个点采一个，视野就从三格撑到五格。分组是各干各的，两者都是控制算力和参数的旋钮。

书上第 294 页说，想直观感受这些参数的效果，Dumoulin 做的一套卷积动图在网上可以找到，还有他和 Visin 的配套论文。另外有些应用，比如图像修复，输入图像会带一张掩码，标记哪些像素有效、哪些要补。这时可以用部分卷积，把输入像素乘上掩码，再按有效个数归一化。思路像我们第 3 章讲过的拉普拉斯金字塔那套算法，只不过权重换成了学出来的。原书脚注 38 还做了框架对照：PyTorch 里的二维卷积就叫 Conv2d。卷积层的机制到这就讲完了：算得快、参数少、还适合图像。图像越卷越小了怎么办？下一集讲池化，把图缩小还保住信息。

第一道作业，一个卷积层用五乘五的窗口、三个输入通道、八个输出通道，先口算这层有多少个可学权重，再用我们的小实验程序验证。第二道思考题：权值共享为什么天然适合处理图像里的平移？用一两句说说你的直觉。做完这两道，你对“归纳偏置”就不只是听懂，而是会算了。下一集，池化见。
