# E013 口播稿 · 三维世界如何压进二维平面：点、线、面与投影

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

从这一集起，我们正式进入第 2 章图像形成。原书把成像拆成三件事：几何投影、光度与光学、传感器采样——这一集只管第一件的前半。§2.1 的标题是几何基元与变换：三维世界要压进二维平面，先得把点、线、面这些词汇备齐，不然投影一来，就只能听天书。

本集四段：先说清楚，为什么全书的第一个正式小节是词汇表；再把 2D 的点、线和二次曲线过一遍；然后上 3D 的点、面、线——3D 直线是全场最不好写的角色；最后盘点一张词汇表，预告下一集。

原书说，几何基元是描述三维形状的基本构件。本节先引入点、线、面；曲线、曲面、体积留给后面的章节——曲线在第七章和第十二章，曲面和体积在第十三章。讲者按：词汇表不是缩水的目录，是全书的通用货币。

作者给学生留了话：学过计算机图形学的，可以略读本节——但射影深度和物体中心投影这两段可能是新的，它们在 §2.1.4 的后半。讲者按：图形学与齐次坐标就算两样都学过，也值得听这一集——上一部 E002 用比喻讲齐次坐标，从这集起，换成原书的正式定义。

2D 点，就是图像里的像素坐标。原书的非齐次写法是一对数，x 和 y，属于二维实平面；也可以立起来写成列向量——原书在导论里说过，这种记号默认是列向量。别小看这个约定：上一集讲过，列向量默认右乘——矩阵在左、向量在右。讲者按：后面的公式，都建立在这条约定上。

真正的主角是齐次坐标：给点添上第三个数，只差一个倍数就算同一个点——比如一、二、一和二、四、二，就算同一个点。除零向量以外，全体这样的向量，组成二维射影空间。每个分量除以最后一个数，就回到普通坐标；把第三个数固定写成一的版本，叫增广向量。上一部 E002 说的「添一格」，正式版本就在这里。

最后一个数是零的齐次点，叫理想点，也叫无穷远点——没有普通坐标对应，是射影空间为「无穷远」留的座位。上一部铁轨的例子：平行铁轨在现实中永不相交，射影几何说它们交于无穷远，交的就是这类点；照片里的汇聚点叫消失点，是这个无穷远点投到画面上的影子——透视把它搬进画面，投影那集再算。原书只有一句定义，铁轨和消失点都是讲者补的。

2D 直线也用三个数表示，直线方程是：增广向量和线向量做内积，等于 a x 加 b y 加 c，等于零——「点在线上」就是内积为零。讲者按：点与线在齐次世界里是对等的，这是本节最重要的结构，后面交点连线的算法都从它长出来。

把三元向量归一化，前两个数变成单位法向量，第三个数 d 是原点到直线的距离，重绘图在下一页。唯一的例外是无穷远线，零、零、一：它装着所有理想点，法向量根本不存在，没法归一化。

原书 Figure 2.2 的左半张，讲者照着示意重绘：单位法向量、原点到直线的距离，还有法向量与 x 轴的夹角——这条直线的三个身份，全在一张图上。右半张是三维平面，讲到 3D 的时候再对照着看。

法向量还能用角度写：用与 x 轴的夹角定方向，加上到原点的距离，这对数叫极坐标。原书特意点名：第七章的 Hough 变换找直线，用的正是这套表示。讲者按：词汇表不是孤立小节——第七章的伏笔，在这里埋下。

齐次坐标的甜头在代数：两条直线的交点，就是两个线向量的叉积；反过来，两点的连线，也是两个点向量的叉积。求交和连线，居然是同一个动作。讲者按：上一部 E002 的两个彩蛋，如今在原书的式 2.4 和 2.5 里各就各位。

多条直线求公共交点，或者多点拟合一条直线，叉积就不够了——讲者按：数据有噪声，得上最小二乘。原书把这件事指向第八章和附录 A.2；讲者按：习题 2.1，就是它的第一个练习场。

还有一族代数曲线：二次曲线，齐次方程是 x 转置乘 Q 乘 x 等于零。名字的由来：用平面去截三维圆锥，截出来的就叫圆锥曲线。原书说它在多视图几何和标定的研究里有用，但本书用得不多——词汇表里认识一下，不展开。

讲者实验：把词汇表算一遍。十九项数值断言，多数项配随机数、几项用固定特例：齐次缩放等价、增广往返、理想点检测、点在线上、归一化距离、点线与点面距离、叉积求交点与连线、极坐标和球坐标往返、三维直线两种写法互相换算、普吕克坐标的比例等价与二次约束。另有一项同步检查：四张输出图与幻灯片目录逐字节比对。

其中讲者认为最漂亮的一条：两条平行直线做叉积，前两个分量不全为零，第三个分量恰好是零——交点是理想点。「平行线相交于无穷远」，从上一部的比喻，变成了可以现场计算的事实。

实跑结果见图：左边两条相交线，叉积算出普通交点，三个分量都正常；右边两条平行线，叉积的第三分量是零，交点是理想点——图上两条线怎么延长都碰不上，交点却真实地存在于无穷远。十九项数据断言加一项同步检查，全部通过。

三维点：三个实数，或者齐次四元组；增广向量是四个数，最后补个一。三维平面：面向量是四个数 a、b、c、d，方程是增广向量与面向量做内积，等于零——和二维直线一个模子：点在面上，还是内积为零。讲者按：判从属靠内积——2D 点线、3D 点面，同一套结构。

归一化后同样得到单位法向量加距离，法向量垂直于平面，重绘图在下一页。无穷远平面也照样没法归一化。法向量还能用两个角度写成球坐标——原书补了句实话：它不如极坐标常用，因为对法向空间的采样不均匀。

原书 Figure 2.2 的右半张，讲者照着示意重绘：一张三维平面，法向量垂直于它，d 是原点到平面的距离。对照上一张二维直线的重绘图——直线和平面，在原书里本来就是一张图的左右两半；讲者按：数学上也只差一个维度。

到三维直线，画风突变——原书自己承认：它比二维直线和三维平面都不优雅。最直接的表示是抓两个点 p 和 q：线上任意一点 r，等于一减 λ 份的 p，加 λ 份的 q；λ 限制在零和一之间，r 就被夹在两点之间，正好是线段。

齐次版本允许第二个点跑到无穷远：它的最后一个分量是零，剩下的三个数正是直线的方向——直线方程变成起点加 λ 乘方向向量。讲者按：一个起点加一个方向，最省事的写法。

原书 Figure 2.3，讲者重绘：r 是 p 和 q 的加权混合，λ 从零滑到一，r 就从 p 走到 q；λ 出了区间，点跑出线段，但仍然在直线上——讲者按：线段与直线，就是同一个公式加不加限制的差别。

端点表示的毛病是自由度太多：两个端点六个数，而三维直线真正只有四个自由度。补救办法：把两个点分别钉在两张特定的平面上——比如近竖直的直线，取 z 等于零和 z 等于一的两张平面，每张平面记一个二维坐标，正好四个数。

这套双平面参数化不是数学游戏：第十四章的光场和 Lumigraph 渲染系统，就是用它来组织相机扫过物体时看到的所有光线——两张平面各记一个坐标，讲者按：四个数钉住一条光线。E012 点过名的光图，户口在这页。

想不偏不倚地表示所有方向的直线，用普吕克坐标：在线上任取两点，算一个四乘四的斜对称矩阵，取它的六个独立非零分量。它只有四个自由度——齐次性打掉一个，行列式为零带来的二次约束再打掉一个。

原书接着说：极小表示，对多数应用并非必需。方向有时可提前知道，比如建筑；再在可见段里找一点，或干脆用两端点——直线最常出现的样子，就是有限长的线段。讲者按：极小表示是数学洁癖，「够用」就行。深究，原书指向 Förstner 2005。

最后一个词条：三维二次曲面，齐次二次方程，二次曲线的三维版。球、椭球、圆柱都是它的特例，在多视图几何的研究里有用——本书同样不深究。词汇表，到这里正式清点完毕。

讲者归纳，盘点一张词汇表：二维点、二维线、三维点、三维面、三维线，五种对象，全都各有齐次写法；能归一化成「单位法向加距离」的，只有二维线和三维面；在二维里，求交与连线一律叉积——下一集，让这些对象动起来：二维变换族谱。

读原书：§2.1 开篇，三十六到三十九页，对照 Figure 2.2 和 2.3。作业：挑两条平行线，用叉积算它们的交点，确认第三个分量是零，写下这三个数。
