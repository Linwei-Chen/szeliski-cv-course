# E088 口播稿 · 视频防抖、慢动作与插帧：运动场的应用烟花

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

前面几集把运动估计做出来了，这一集看它怎么变成产品里的三件事：防抖、慢动作、插帧。防抖是把抖动的相机轨迹拉直；插帧是在两张图之间造一张；慢动作是把造出来的中间帧按时间铺开。三件事都靠同一个信息：每个像素或每个区域去哪了。运动估得准，画面就稳、就顺；估得不准，就会抖、会糊、会重影。这一集先讲防抖的三阶段，再讲插帧的运动和遮挡，最后看边界和失败模式。

书上第 573 页说，视频防抖是参数运动估计最广泛的应用之一；算法既跑在摄像机、相机这类硬件里，也跑在提升画质的软件包里。防抖不是把相机变稳，而是把已经拍抖的画面，用运动信息重新摆稳。它便宜、通用，所以手机、运动相机、后期软件都在用；也因为它只是事后重摆，边界和遮挡问题躲不掉。

书上第 574 页给出防抖的三阶段：运动估计、运动平滑、图像重采样。先估每帧相对参考的相机运动；再把轨迹里的高频抖动去掉，留下低频摇镜；最后按修正量把每帧重采样回去。先量出相机怎么抖，再画一条平滑的理想轨迹，然后把每帧挪到理想轨迹上。三步里最难的是第一步：估错了，后面越平滑越错。

书上第 574 页说，运动估计常用相似变换，处理相机的平移、旋转和缩放；难点是让算法锁住背景运动，不被独立运动的前景物体带偏。防抖要稳的是背景，不是画面里走过的人。前景一大、纹理一强，全局估计就会被它拽走。所以工程上要先分前景和背景，或者用鲁棒估计把外点压下去；这一步和前面 RANSAC、鲁棒损失是同一类思路。

书上第 574 页说，运动平滑要保留低频的慢变运动，再估计并去掉高频抖动；常用二次惩罚，但想要更真实的锁定或匀速虚拟相机运动，可以用 L1 最小化导数。二次惩罚像橡皮筋，抖得越远拉得越狠；L1 更像允许少数大修正，所以能保住匀速摇镜，不会把整条轨迹拉弯。选 L2 还是 L1，取决于你要顺还是要直；这是定性倾向，工程里还要看实时性和算力，不总是二选一。

书上第 574 页提醒：重采样会带来边界缺失，必须裁剪、用其他帧补，或者 inpaint；快速运动还会让帧模糊，可以去模糊，或从其他帧偷更清晰的像素。书上第 575 页说，如果相机在三维里大幅平移，比如边走边拍，更好的办法是做完整的运动恢复结构，重渲染一条平滑的三维相机路径。二维防抖是掰画面，三维防抖是换相机路径；后者更贵，但不会把画面掰到没边。

我们的实验合成了一段边走边抖的序列，全局平移估计平均误差零点零五二像素；因果移动平均平滑后，残余抖动从零点四一七降到零点零七九像素，压了五倍多。代价是要裁掉约一成八的画面：原图一百二十八像素见方，每边裁六像素，面积只剩八成二。抖动压下去了，但边界没了；裁多少、补多少，是产品取舍。这里只演示平移；真实防抖还要估旋转、缩放，甚至卷帘快门。

看这张图。左边红线是估计出的抖动轨迹，蓝线是平滑后的轨迹；右边是校正前后的残余抖动柱状图。红线上下摆，蓝线只保留慢变趋势；校正后抖动从零点四一七掉到零点零七九。注意蓝线在结尾略微滞后，这是因果平滑的代价：它只能看过去，不能看未来。工程上会做离线双向平滑，或者把最后几帧单独处理；在线防抖只能接受这点滞后。

书上第 593 页说，帧插值是把运动估计用到硬件的典型应用，用来把输入视频匹配到显示器的实际刷新率，在前后帧之间造新帧。最好的结果需要每个未知像素都有准确运动；但光有运动还不够，遮挡信息同样关键，否则前景颜色会污染被它挡住的地方。插帧不是简单把两帧叠一下；你得知道每个像素从哪来，在中间时刻该露谁。

书上第 593 页给出核心公式：如果同一个运动 u0 在 I0 的 x0 和 I1 的 x0 加 u0 都对得上，就说光流一致；把它搬到中间时刻 x0 加 t u0，颜色用 1 减 t 乘 I0(x0)，加上 t 乘 I1(x0+u0)，做线性混合。如果对应位置的运动会不一致，就必须判断哪个对、哪个被遮挡。一致的地方直接混，不一致的地方先判 visibility，再决定用谁的颜色。

我们的实验里，相机横移二十像素，前景棋盘再额外移二十像素；直接平均的 PSNR 只有十四点六分贝，光流插值到九十九分贝，因为合成数据上分层运动是精确已知的。只看前景遮挡区，直接平均掉到六点二分贝，光流插值仍然是九十九；差别就是重影和干净的差别。这是机制验证，不是真实图像质量；真实场景还要估流、判遮挡、处理边界。

看这张图：从左到右是前帧、后帧、直接平均、光流插值、真值。直接平均里能看见两个棋盘重影，因为前景在两张图里位置不同；光流插值把前景搬到中间，只剩一个。真值和光流插值几乎一样；这说明运动和遮挡的逻辑对了，不是说真实场景也能满分。看插帧结果，先看前景边缘和遮挡边界，那里最容易穿帮。

书上第 593 到 594 页说，更近的插帧用深度网络：有的用时空卷积，有的用网络算双向光流，再用上下文特征或软可见性图合并两帧贡献。Niklaus 和 Liu 的系统把输入帧编码成多分辨率深度特征，用双向光流前向 warp，再用 softmax splatting 合并，最后用解码网络合成图像。传统方法先估流再混；深度方法把估流、判可见、合并、合成放在一起学。

我们的实验把同一段运动在四分之一、二分之一、四分之三时刻各补一帧，帧率变成四倍；模糊后的相邻帧平均绝对差从零点零九九五降到零点零四四六，降到不足一半。慢动作的做法，是先造出更多中间帧，再按正常速度播；中间帧越准，慢动作越顺。如果中间帧有重影，慢放会把重影也放慢，所以插帧质量在慢动作里会被放大。

把这一集收成一张取舍表：防抖要裁边界，插帧要判遮挡，慢动作要中间帧准；三者都怕快速运动、无纹理、光照突变和卷帘快门。防抖和插帧都在改写像素的时间或空间位置，改得越多，越容易露馅。工程上先问：是离线还是在线？能不能接受裁剪？有没有深度和 IMU？下游是显示、剪辑还是测量？答案不同，方案不同。

这一集收一收。防抖是估运动、平滑轨迹、重采样，代价是边界；插帧是逐像素运动、遮挡、线性混合，难点是可见性；慢动作是插帧的时间版，质量会被慢放放大。下一集进实验课：把光流场画出来，再手写一个 Lucas–Kanade 求解器，亲手看窗口、梯度、迭代怎么影响结果。这一集讲应用，下一集把工具拿在手里；先知道为什么，再动手。下一集见。
