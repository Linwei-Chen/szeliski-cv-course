# E003 口播稿 · 导数、偏导与梯度：误差往哪边下山最快

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

数学工具箱第三集。上一集，我们把一连串几何动作拧成了一条矩阵链。可链条里的参数——转多少度、挪多少像素——最初是谁定的？答案是：让算法自己找。今天的主角，就是让机器学会自己调参数的数学工具：导数、偏导数，还有它们合体而成的梯度。

从一个具体任务说起：原书附录 A.2 讲最小二乘，举的第一个例子是用特征点对齐图像，求的是变换的参数——也就是上一集那类参数。为了看清本质，先拿最简单的直线练手：平面上四个测量点，拟一条 y 等于 m x 加 b。误差就是每个点的竖直距离，平方后加总——离得越远罚得越狠。

原书把这类误差写成统一的形式：E 等于所有残差的平方和。残差，就是观测值减去预测值，差多少记多少。别小看这条公式：把 m 和 b 当成平面坐标，把总误差当成高度，它就是一片起伏的地形——这是讲者的类比。参数调得好，站在低处；调得差，站上高山。

于是找最优参数这件事，变成了在地形里找最低点。山里有雾，看不见谷底在哪，只能看清脚下这一小块。那么问题来了：给定脚下的位置，往哪个方向迈一小步，高度下降得最快？要回答它，得先有一件测量坡度的工具。

先回到单变量的世界。导数是什么？在曲线上取两点连一条割线，把两点越靠越近，割线的极限就是切线。导数就是这条切线的斜率：瞬时变化率。斜率是正的，函数在往上走；是负的，在往下走；等于零，脚下平坦——这里往往是山顶，或者我们要找的谷底。当然也可能两者都不是，比如 y 等于 x 立方在原点。

可直线拟合有两个旋钮，一个导数不够用。偏导数的办法很朴素：一次只动一个，把其余全冻住。冻住 b，只拧 m，量出误差对 m 的偏导数；再冻住 m，只拧 b，量出对 b 的偏导数。∂ 这个符号就是在提醒你：这是多元函数里沿某一个坐标轴方向的坡度。

把这些偏导数按顺序排成一个向量，就是梯度。对直线拟合，梯度就两个分量：误差对 m 的偏导，误差对 b 的偏导。梯度有一个漂亮的几何意义：它指向函数爬升最快的方向。两个旋钮往哪边同时拧、误差涨得最快，梯度说了算。

在等高线图上看得更清楚。等高线是高度相同的点连成的圈，梯度不为零时垂直于等高线，指向上坡最陡的方向。想下山？倒着走：沿负梯度方向迈步，下降最快。这就是梯度下降。原书 A.5 的迭代法，比如走一连串「下山步」；其中的共轭梯度，原书把它算作梯度下降的一种。

为什么垂直方向就是最陡？相邻两条等高线之间的落差是固定的，垂直穿过去路程最短，同样的落差摊在最短的距离上，坡度自然最陡。往哪个方向走，梯度说了算。顺带一提：原书在共轭梯度那节，把一个叫 d 减 C x 的量叫作最陡下降方向——它和我们说的负梯度是同一个方向，这一步是讲者推导。d 和 C 是什么，下一段见。

那谷底怎么找？对线性最小二乘这种碗状的误差函数，谷底恰好是梯度为零的地方。画面里就是这两个方程：误差对 m 的偏导置零，对 b 的偏导置零。把它们联立，得到的正是原书 A.2 直接给出的正规方程；解它，就得到最优参数。完整的矩阵推导，下一集 E004 一次做干净。

麻烦在于，真实视觉问题里 f 对参数常常不是线性的，比如运动恢复结构（structure from motion）里成千上万个未知变量。原书 A.3 的做法：在当前位置做线性近似，用梯度导数——雅可比矩阵 J 等于 f 对 p 的偏导——解出一小步增量 Δp。讲者补充区别：梯度是偏导排成的向量，雅可比是好几个函数的梯度叠成矩阵。这一小步不等于沿负梯度走，怎么解 E039 细说。近似只在附近有效，走一步、重新近似、再走。

这一步迈多大？原书写得很实在：增量前头乘个系数 α，从 1 开始试，误差要是没降就减半再试——这是线搜索最简单的一种形式。讲者补充：在机器学习的梯度下降里，控制步长的系数通常叫「学习率」（learning rate）；原书的 α 是每步用线搜索现找的，思想相通，但不是一回事。

空口无凭，上代码。本集实验在一个碗状误差曲面上跑三条轨迹：蓝色从起点甲、绿色从起点乙出发，步长相同；橙色从起点丙出发，步长故意放大，越过稳定边界——看会发生什么。

看结果：蓝绿两条起点不同、步长相同，都一路锯齿着贴到碗底——起点没难住它们。橙色跟蓝绿比，起点不同、步长也不同，但既然起点不同的蓝绿都能收敛，发散的元凶就只剩步长。左图是等高线上的轨迹，右图是对数坐标的误差曲线——步长一大，误差不降反升，直接冲出图外。

实验里还埋了两道保险。第一，随机取两百个点，用中心差分算数值梯度，跟解析公式对照，最大差在小数点后十位——两条独立路径互相验证。第二，脚本打印了步长的稳定上限 1.66，它由碗最陡方向的弯曲程度决定：碗越弯，上限越小。橙色用的 3.57，越界，所以发散。

原书 A.5.1 把主角让给了共轭梯度：原话说它的收敛速度跟条件数的平方根挂钩，而不是条件数本身——换算成迭代步数，就是从大致正比降到正比平方根（讲者解读）。条件数就是碗有多扁：峡谷越窄长，条件数越大。来回横跳的画面，是讲者的补充演示。怎么下山，本身也是一门学问。

这一集的记忆锚，三句话：导数，是瞬时变化率；偏导数，是冻住其他旋钮后的导数；梯度，是偏导数排成的向量——上坡最陡的方向，下山请倒着走。再加上两条纪律：谷底处梯度为零；一步别迈太大。
