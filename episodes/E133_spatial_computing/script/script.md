# E133 口播稿 · 空间计算元年：IBR 思想在 VR/AI 视频里的落地

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

先从一个日常场景说起。3D 电影已经陪了我们十几年，可观众还是坐在固定位置。看视频的时候，如果能自己站起来，绕到侧面，会是什么体验？这就是自由视点视频要回答的问题。多台相机同时拍，观众在相机之间选视角。它不只是把视频做成 3D 模型，还要在每一帧、每一双眼睛上都保持正确。两只眼睛看到的画面略有差别，立体感就出来了。可以把它想成视频版的多机位直播，机位不由导演切，由观众自己选。这一集用 8 台合成相机做最小演示，需要说明，这不是真实的八相机采集，也不是完整的 VR 系统。

书上第 893 页说，立体匹配加上图像渲染的视图插值，是自由视点视频或虚拟视点视频的两个必要组件。除了逐帧重建和插值，深度图或代理还必须时间一致，否则画面会闪烁。立体匹配回答每个像素有多远，深度图就是每个像素的距离。视图插值回答新机位怎么画。时间一致回答相邻帧别乱抖。三个问题缺一个都不行。没有深度，插不出视差。没有插值，只能切机位。没有时间一致，画面就会闪。这三个词后面还会反复出现，先把它们分开。

同一页还提到一批早期系统。Virtualized Reality、Immersive Video、Image-Based Visual Hulls、Free-Viewpoint Video，都用全局三维几何模型当渲染代理。代理可以是表面，也可以是体积。表面代理给出物体的外壳，体积代理给出它占据的空间。Vedula 等人还计算 scene flow，也就是对应表面元的三维运动，用来做多视图视频的时空插值。这一路先重建全局几何，再在新视角渲染。好处是新视角可信，坏处是每帧都要重建，稳但重，对动态场景要求高。

书上第 893 页还讲了 Zitnick 的 Virtual Viewpoint Video。它给每幅输入图配一张两层深度图，能更准地处理遮挡边界上的混合像素。系统用 8 台同步摄像机，先用基于分割的立体匹配求每幅图的深度。两层就是前景一层、背景一层。边界像素既不是纯前景，也不是纯背景，而是两者按比例混合。只用一个深度，边缘会被切得像纸片。两层深度分别来自前景和背景，边界处两张图都要用。两层深度比全局网格轻，又比单层深度更能处理遮挡。代价是背景被前景挡住的部分要靠邻图补，好处是两层可以分别压缩、分别传输。

看图。上面是 8 台相机的一维阵列，中间是虚拟视角，红点是左右眼。下面是左相机、虚拟视角、右相机三幅图。同一根柱子，在左相机和右相机里位置不同，因为前景 Z=2、背景 Z=6，两层视差不一样。虚拟视角就插在中间。相机越密，能站的中间位置越多。左右相机之间的基线越大，视差越明显。但只有两层深度还不够，边缘和遮挡还要抠图，还要时间稳定。我们的 lab 只做一维平移，不做真实环形阵列。

书上第 894 页讲渲染。深度不连续的地方，背景层要沿前景后面的条带延伸，颜色从邻图中没被挡住的地方估计。条带补的是前景挡住、邻图还能看到的背景。自动抠图再估计前景边界像素的分数不透明度和颜色。渲染时，邻近相机的图层当成纹理三角形来画，前景按分数 alpha 合成到背景上，两幅结果按 z-buffer 比较后合并。普通图形硬件就能实时跑，还能在播放中改视角，或者冻结画面慢慢看。这条管线的关键词是分层、抠图、合成、比较。它把重建和渲染拆开，所以能实时。

看图。左边是硬边界，PSNR 34.64 分贝。中间是软边界，37.46 分贝。右边是目标。硬边界只有 0 或 1，边缘一移就出锯齿。软边界用分数不透明度，边缘按覆盖率混合，边缘误差下降 96.8%，整图 PSNR 提升 2.82 分贝。软边界按覆盖率算颜色，边缘不会一刀切。这里没有多一层滤镜，只是承认边界像素本来就是混合的。真实系统还要处理颜色溢出和透明物体。我们的 lab 假设背景层已知，真实系统要用邻图补条带。

书上第 895 页说，VR 头显普及推动了 3D 视频研究复兴。Google 的 Jump 用 16 台 GoPro 排成 28 厘米直径的环，拍完离线拼成一对全向立体 ODS 视频，观看时再为每只眼生成图像。ODS 有明显限制，不支持头部倾斜和平移，抬头低头时也给不出正确深度。后来的系统支持完整 6DoF，观众可以在有界体积内移动，每只眼都得到透视正确的图像。ODS 像站在原地转头，6DoF 才允许你往前走两步。前者便宜，后者要更多视角和离线重建。VR 不是一种格式，而是一串自由度。ODS 的立体感只在环上成立，离开中心就不对了。自由度越多，采集和重建越贵。

看图。左边是 24 帧的前景深度估计，红线逐帧抖，绿线是时间平滑。右边是逐帧 PSNR，红线上下跳，绿线更稳。深度抖动标准差 0.100，平滑后 0.030。静态背景的闪烁指标从 0.00060 降到 0.00004。平均 PSNR 从 36.89 升到 37.64 分贝。逐帧独立估计，就像每帧重新猜一次深度，背景会一闪一闪。时间平滑用的是前后帧的信息，单看一帧看不出来。它让相邻帧商量一下，画面才不闪。但这是离线平滑，实时系统还要考虑延迟和因果性。

书上第 895 页说，6DoF 需要离线多视图立体匹配，生成支撑自由移动的三维代理。同一页还说，镜头朝外可以拍演员活动，叫自由视点视频或体积表演捕捉。最新系统用深度网络做重建、表示、压缩和渲染，处理时变体积场景。朝内是观众在场景里，朝外是观众围着演员转。一个要环境，一个要人体，共同点是都要多视角、都要时间一致。重建出来的代理还要能支持观众在体积里移动。6DoF 的自由有代价，有界体积、离线重建、大量相机，都省不掉。真实系统还要处理遮挡、反光和运动模糊。

书上第 895 页说，大多数系统需要定制的多相机阵列，但也可以用一组手持视频，甚至一台移动的手机相机来构造 3D 视频。相机越少，越依赖算法去补没拍到的视角。深度网络可以从数据里学先验，但也可能把没拍到的东西编错。看一个空间视频系统，别只看演示。要问它有几台相机、要不要离线、能不能实时、自由度多大、边界在哪。相机越少，先验越重要，也越容易编错。先验决定了能补出什么。这一集讲的是原理，不是产品评测。

这一集可以收成三件事，它们连起来就是主线。自由视点视频用立体匹配加视图插值，在相机之间插出新视角。两层深度、边界抠图、z-buffer 合成，让边缘和遮挡更自然。时间一致性和 VR 自由度，决定它能不能让人真的走进去。下一集把第 13、14 章收在一起，回看三维重建和新视角的全景。记住三个词：相机阵列、两层深度、时间一致。下一集见。
