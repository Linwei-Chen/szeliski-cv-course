# E027 口播稿 · 傅里叶变换Ⅰ：把图像听成和弦

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集结尾说，这一站进频域：第 3.4 节，傅里叶变换，书上第 142 页起，把卷积搬到频域去看。这个承诺，今天兑现。

这一集走四步。先用一根纯音试探滤波器；再给傅里叶变换下定义；然后看 FFT 怎么把计算量降下来；最后给六个常用小核，各画一条频响曲线。

为什么要搬？书上第 142 页给了理由：用 FFT 做大核卷积，耗时与核的大小无关。核再大，代价也不跟着涨。这句话先记下，本集末尾兑现。

书上先问：怎么知道一个滤波器，对高、中、低频率各做了什么？办法很朴素：喂给它一个已知频率的正弦波，看它出来被衰减了多少。

输入正弦写成式 3.50：角频率 ω 等于 2π 乘频率 f，再加一个初相位 φi。频率决定振多快，相位决定从哪开始振。

记法从这里开始换。书上第 142 页说明：空间坐标改用 x 和 y，不再用 i 和 j；虚数单位写作 j。字母 i 让位给虚数，频域里 x、y 也正好分清横竖。

关键的一步：正弦波过线性滤波器，出来的还是同频正弦。频率不变，只是幅度变成 A，相位挪到 φo。这就是式 3.51。

为什么频率不变？卷积是平移加权和。一堆平移过的同频正弦，加起来还是这个频率的正弦。线性系统不会生出新频率。书上脚注还补一句：会生出谐波的是非线性系统。有发烧友专买电子管放大器，图它的暖声；也有人买数字处理器模拟这种失真。暖声就是谐波失真。

书上给这两个变化起了名字：幅度变化叫增益，相位差叫相移。往后，滤波器对每个频率只说两件事：多大声，晚多久。

更紧凑的写法是复正弦：把 cos 与 j 乘 sin 装进同一个指数，这就是式 3.52。这个恒等式就是欧拉公式。

复正弦过滤波器，输出很干净：只乘一个复数，幅度与相位一起带走，式 3.53。这个复数叫复数增益，一行就写完了输出、增益和相位。

增益与相移本来是两个数。打包成一个复数之后，后面的公式会紧凑很多。这是复数记法带来的方便。

傅里叶变换就在这里登场：逐个频率，把增益与相位登记成表。H 等于 A 乘 e 的 jφ 次方，式 3.54。

书上把话说透：H(ω) 就是频率 ω 的复正弦通过滤波器的响应。习惯上写成一对，这就是式 3.55。h 与 H，一个在时域，一个在频域，互相认领。

书上坦言，这个定义只是一份操作说明：喂正弦、量幅度和相位、换个频率再来。它给的是做法，不是算式。封闭公式有两条：连续域一条，离散域一条，看下一页。

连续域是式 3.56，沿整条 x 轴积分。离散域是式 3.57，逐项乘指数再求和，除以 N。这是以复指数为权的平均，k 取零时就是普通均值。书上说，这两条公式对核与对信号都适用。

离散版有个名字：DFT，离散傅里叶变换。注意 k 只在正负二分之 N 范围内有意义。更大的 k 会跟低频混叠。混叠在频域里也露脸了。

直观看三例。单位脉冲，谱是平的，所有频率都有。方波，谱是主瓣加旁瓣，中间高、两侧逐渐变低。纯正弦，谱只有两根线。频域把成分看得一清二楚。

按定义直接算 DFT，要 N 平方次乘加。FFT 把它压到 N 乘 log₂N：把变换分成 log₂N 级，每级只做 2×2 的小变换，再加几轮重排。

算一笔账。N 等于 8192 时，直接按定义求和要一秒半；换 FFT，不到十分之一毫秒，快上万倍。计时会随实现和预热协议波动，这里取中位读数。算法复杂度本身贡献约 630 倍，其余是实现常数。书上还提到，这种分级运算的图形像蝴蝶，所以叫蝶形运算。

书上还列了一串性质：叠加、平移、翻转、卷积、相关、乘法、求导、伸缩、能量保持。二版为了腾篇幅，把细节全删了，指向第一版 3.1 节的三张表。

把前面介绍过的六个小核逐个算频响，就是书上第 145 页的 Table 3.1：box-3、box-5、linear、binomial、Sobel、corner。六条曲线，六种频响形状。

书上点名批评滑动平均：对高频衰减不均匀，可能引起振铃。box-3 的频响在横轴读数三分之一处，也就是角频率 2π/3，直接翻到负值。负增益就是反相，偏高频的细条纹亮暗颠倒。这是书上所说可能引起振铃在频域上的一个对应。Sobel 先随频率线性增强，到更高频又衰减下来，所以难认细刻度边缘，比如相邻的黑白细列。

二项式核的权重是 1、4、6、4、1，除以 16。频响圆润，全程没有负瓣，零点只落在尽头。书上说，Burt 与 Adelson 的拉普拉斯金字塔，就拿它当作近似的高斯来用。但它仍留高频细节，降采样后可能混叠。这是给后集埋的伏笔。

现在兑现承诺：把卷积搬到频域看。卷积的谱，等于两个谱的逐频点乘积。书上的性质清单里列了卷积性质，二版没有展开内容。频域里没有滑窗，只有乘法；各频率各顾各，互不串音。严格说，频域乘积对应的是循环卷积；做普通卷积，要先补零。

机理回到式 3.53：每个频率的复正弦过卷积，只乘自己的增益与相位。既然每个频率各自独立，整段卷积就等于全部频率各乘各的。算总账，两次正变换加一次反变换，都是 N 乘 log₂N 级，和核有多大无关。做普通卷积先补零，补零后长度取信号长加核长，还是同一个量级。开头那句承诺，这里兑现。

负增益不是抽象数字。画面上那段频率的亮暗就颠倒了。box 核的负瓣，让偏高频的细条纹反相。这是书上所说振铃类伪影的一个频域来源，就在这条曲线上。

纯音试探，逐频率记账，FFT 提速，六条频响曲线。一维频域的听音，到此告一段落。二维的频域，下集接着讲。
