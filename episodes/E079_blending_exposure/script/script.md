# E079 口播稿 · 全景大战役 Ⅲ：曝光补偿与多频段混合的无缝魔术

> 本稿为课程口播整理，配合 [幻灯片](../slides/deck.html) 学习。

上一集把图投到同一个曲面上，位置对上了，可接缝还在：左边暗、右边亮，或者一条硬边。这一集解决混合：把重叠的像素混得看不出缝。做法是分频段处理，低频管曝光，高频保边缘。位置对齐是几何，混合是光度；几何对了，光度不对，全景还是假的。接缝不是一个点，而是一个过渡带，混合就在这个带里做文章。混合做不好，前面几何对齐也白费。先看原书把混合拆成哪几件事。

书上第 544 页说，接缝选好、不要的物体去掉之后，还要把图像混起来，补偿曝光差异和其他错位。接缝只决定用哪张图，混合决定两张图怎么过渡。曝光差是全局的亮度台阶，错位是局部的重影，两种毛病要一起治。如果只做平均，台阶会变成一条渐变的灰带，还是看得见。曝光差和错位要分开看，处理办法也不一样。所以混合是拼接质量的下半场。

最直接的办法是羽化：重叠区按距离给权重，离自己图中心近的多用，离边缘近的少用。书上第 544 页点出两难：想平滑低频曝光变化，就得多过渡；想保住高频边缘，过渡又不能太宽。过渡带太窄，曝光台阶还在；过渡带太宽，边缘被糊掉。一个固定的过渡宽度，很难同时满足两头。这就是后面要上金字塔和梯度域的原因，过渡带的位置也要选好。这就是后面要上金字塔和梯度域的原因，让不同频段用不同宽度。

把流程摊开。两张曝光不同、位置已经对齐的图，先在重叠区找缝，避开运动物体；再做曝光补偿，把亮度拉到同一水平；最后用羽化、金字塔或梯度域混合。顺序很重要：先补偿再混合，台阶才不会留在过渡带里；先混合再补偿，缝已经被抹开，很难收。顺序反了，后面再补也补不回来。本集按这个顺序讲，先看频段方法，再看曝光补偿。找缝那一步在上一集的对齐之后，本集不展开。

书上第 545 页给出拉普拉斯金字塔混合。它不用一个固定过渡宽度，而是把图像分解成带通的金字塔，每一层用自己的过渡宽度，层与层之间按频率分工。低频层慢慢过渡，负责把曝光差异抹平；高频层快速过渡，负责保住边缘和纹理。这像先铺大色调，再画细节：大色调可以柔，细节必须利。金字塔把不同频率拆开分别处理，并没有把图变模糊；越粗的层，过渡越宽。

要拆几层？书上第 545 页说，实际用不了很多层，少到两层，有时就够补偿曝光差异。层数越多，过渡越精细，但计算和调参也越麻烦；多数曝光差，两三层就能压住。层数要看曝光差有多复杂。如果差的是平滑的渐晕，低频层就够；如果差的是局部阴影，才需要更多层。层数选多了，过渡反而会变慢。先少后多，是工程上的稳妥顺序。

另一个方向是梯度域混合。书上第 545 页说，不复制像素，而是复制新图块的梯度。像素值决定这块地方多亮，梯度决定亮暗怎么变；复制梯度，等于把纹理和边缘搬过去，亮度基准留给后面解。然后在接缝边界给定精确匹配条件，解一个泊松方程，把梯度积分回像素值。这样接缝两侧的颜色可以对上，纹理又不会丢。它按梯度重建，不做颜色平均。

书上第 546 页说，除了直接解泊松偏微分方程，还可以最小化一个变分问题，让重建图像的梯度尽量接近目标梯度。离散化后，每一对相邻像素给一个梯度约束，堆成一个稀疏最小二乘问题。这就像让每个小方格的坡度都对上，最后整块地形就定了。但梯度只定相对高低，整体加一个常数还是解；所以要固定一个像素，或者把解往原图颜色轻轻拉。这个自由度不消掉，解会整体漂移。固定一个点，是为了消除整体的自由度。

书上第 546 页还提醒，用对数域做偏移，往往比加法偏移更合适，因为曝光差是乘法。亮度乘一个系数，取对数就变成加一个常数；在对数域里补偿，纹理对比不会被拉平。但复制梯度也有风险：接缝附近如果梯度太大，会造出双边缘，一条边被复制成两条。所以接缝附近的强梯度要小心处理。这两类误差要分开看。对数域管曝光，双边缘管细节，两者都要盯。

看这张对照：横轴是像素位置，纵轴是与真实信号的亮度差。硬拼接在接缝处有一个大台阶，整体误差约零点零九一；羽化把台阶摊开，但曝光差还在，误差约零点零八六；曝光补偿后再羽化，误差降到零点零零三；金字塔和梯度域也都到零点零零三。羽化只解决过渡，不解决亮度基准；补偿把基准拉齐，分频段再把过渡做细。三者各管一段，不能指望一个方法包打天下。误差单位与图上的亮度差一致。羽化只是把台阶摊开，并没有把亮度拉齐。

书上第 547 页说，金字塔和梯度域对中等曝光差已经够好；差得很大时，就要另想办法。中等差异像整体调了亮度，补偿一个系数就行；大差异往往不在整体，而在局部，比如镜头渐晕，中心亮、四角暗。局部差异用一个全局系数治不了，得估计一张空间变化的校正图。所以先判断差的是整体还是局部；判断错了，后面越补越歪。整体系数只能把画面统一调亮或调暗。这一页是从混合走向曝光补偿的分界。

书上第 547 页介绍了一个经典办法：迭代估计每张源图与混合结果之间的局部校正。先在分块上拟合二次传递函数，再把相邻块的传递函数平均，得到更平滑的映射；块与块之间用样条插值，算出逐像素传递函数。每张图平滑调整后，重新做一次羽化混合，再重复；通常重复三次。这像先粗调每块亮度，再把块与块之间抹平，最后逐像素细调。每一轮都用上一轮的混合结果。分块、平滑、迭代，是为了对付渐晕这种慢变化；三次是经验值，收敛了就停。

书上第 547 页说，最根本的办法，是把图拼在辐照度域：用每张图的曝光值，把它转成辐照度图，再拼成高动态范围图像。像素值是曝光后的结果，辐照度是场景本来有多亮；在像素域补偿，是事后修；在辐照度域拼，是回到源头。但这条路需要曝光值，也需要相机响应，工程门槛更高。所以实际系统常常先用局部校正，再考虑 HDR。把图拼在辐照度域，亮度关系更接近场景本身。能回到源头最好，回不去就把校正做细。

我们的实验做了十一项断言，全部通过。重点看这几个数：硬拼接整体误差约零点零九一，羽化约零点零八六，曝光补偿后约零点零零三；金字塔和梯度域也都在零点零零三；对数域估计的增益与线性拟合相差不到百分之一。这些数说明两件事：曝光补偿决定亮度基准，分频段决定过渡质量，两者缺一不可。读数来自一维剖面实验，只验证原理，不冒充真实全景的最终画质。

把工程清单收一收。第一，先找缝，避开运动物体。第二，先做曝光补偿，再混合。第三，中等差异用羽化或两三层金字塔。第四，要求高、纹理强，用梯度域，但盯住双边缘。第五，曝光差很大，考虑局部校正或辐照度域。顺序是找缝、补偿、混合、检查；检查看三样：接缝、重影、双边缘。先做便宜的检查，再上贵的模型。别一上来就上最复杂的方法，先把亮度基准拉齐；接缝还可见，先回头查曝光，不要先怪混合算法。

这一集把混合讲完了：羽化有低频和高频的两难；拉普拉斯金字塔按频段给过渡宽度；梯度域复制梯度、解泊松；大曝光差要局部校正，最根本是回到辐照度域。实验里，硬拼误差零点零九一，羽化零点零八六，补偿后零点零零三。下一集走出实验室，看手机全景和 360 相机怎么把这些算法塞进一次快门：自动找缝、自动补偿、自动混合，用户只负责转一圈。全景拼接和曝光补偿，最后都要落到一次快门里。原理讲清，下一集看工程。
